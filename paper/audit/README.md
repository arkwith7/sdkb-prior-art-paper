# 감사 기록 층 — 이동 대장

이 디렉터리는 **논문의 주장을 뒷받침하지 않는 작업 기록**을 담는다. 원고 개정 이력, 실행
로드맵, 방향 전환 트리거, 심사 대응 각본, 폐기된 세대의 판정표가 여기에 속한다.

**왜 나누었는가.** `paper/supplementary/` 는 심사자와 독자에게 나가는 자료이고, 이 디렉터리는
나가지 않는다. 두 층이 한 이름공간에 있는 동안 보충자료를 여는 사람이 미체크 작업
체크리스트와 심사 대응 각본을 먼저 보았고, 검사기 다섯이 전부 그 묶음을 대상에서 제외하고
있어 두 세대 낡은 판정과 금지 문구가 그대로 살아남았다.

**이관은 삭제가 아니다.** 내린 자료는 전량 이 디렉터리에 원문 그대로 있고, 아래 대장이 그
자리를 적는다. 판정·수치는 하나도 바뀌지 않았으며, 바뀐 것은 싣는 자리이다.

**이 디렉터리의 자료를 현행 논리의 근거로 인용하지 않는다.** 여기 있는 판정 서술 다수는
폐기된 세대의 것이며, 현행 판정은 [paper/verdicts.yaml](../verdicts.yaml)과 작업 정본이 진다.

## 조립 입력 층은 여기가 아니다

투고 파생본을 조립할 때 기계가 복사하는 표와 서지는 [paper/assembly/](../assembly/)에 있다.
그 층은 감사 기록도 보충자료도 아니며, 산문과 표의 경계를 지키기 위한 조립기의 입력이다.

## 이 층에 적용하지 않는 것

`make verdicts` · `make submission-check` · `make style-check` · `make glossary-check` 는 이
디렉터리를 대상으로 하지 않는다. 감사 기록은 **기록된 시점의 문장 그대로**여야 하므로 현행
판정 문구 사전에 맞추어 고치지 않는다.
