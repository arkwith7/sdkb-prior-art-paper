# EP5 · 제2 도메인(Brick) 이식 판정

> 자동 생성 — `make ep5`. 손으로 고치지 않는다(CLAUDE.md §1-7).
> **형식 층과 교차 태스크 층에 한정한 판정이다.** T1·T2 는 이식하지 않았으므로
> `accept` 는 null 이고 `Accept_partial` 만 남는다(사전등록 §6.2).

### 3.1 델타 shape 위반 내역 (규칙별)

- **d0→d1** — 70건 델타가 도입한 클래스에 rdfs:label 이 없다 · 31건 폐기 선언에 이행 지시(brick:deprecationMitigationMessage 또는 …Rule)가 없다 · 4건 델타가 도입한 ObjectProperty 에 rdfs:domain 이 없다 · 4건 델타가 도입한 ObjectProperty 에 rdfs:range 이 없다
- **d1→d2** — 45건 델타가 도입한 ObjectProperty 에 rdfs:domain 이 없다 · 45건 델타가 도입한 ObjectProperty 에 rdfs:range 이 없다 · 1건 델타가 도입한 클래스에 rdfs:label 이 없다
- **d2→d3** — 위반 없음
- **d3→d4** — 86건 델타가 도입한 ObjectProperty 에 rdfs:domain 이 없다 · 86건 델타가 도입한 ObjectProperty 에 rdfs:range 이 없다 · 5건 델타가 도입한 클래스에 rdfs:label 이 없다
- **d4→d5** — 2건 폐기 선언에 이행 지시(brick:deprecationMitigationMessage 또는 …Rule)가 없다 · 1건 델타가 도입한 클래스에 rdfs:label 이 없다

### 3.2 이행 조건 R/N 의 결과 — 두 조건이 갈리지 않았다

- 이행 재작성 **0건** — (N) 이 (R) 과 **동일한 그래프**를 냈다.
- 홀드아웃이 쓰는 폐기 항목 가운데 공식 기계 매핑이 없는 것: **Building, Floor, HVAC_Zone, Room, Zone_Air_Temperature_Setpoint**
- Brick v1.4.4 의 폐기 246건 중 기계 적용 가능한 alias 는 `Photovoltaic_Array → PV_Array` **1건**이고, 나머지는 자연어 이행 메시지뿐이다.

**따라서 §6.3 의 R/N 비교는 이 자원에서 정보를 내지 않는다.** 두 조건을 다 싣되
*'공식 이행 규칙이 회귀를 흡수한다'* 도 *'흡수하지 못한다'* 도 주장하지 않는다 —
적용할 규칙이 없었기 때문이다.
