# H2 — 개념 단위 vs **분류코드** 단위 조기탐지 (단측 부호검정 · §4.4)

여덟 셀 전부를 싣는다 — 유리한 셀을 고르지 않는다. **전부 기각 실패다.**

그러나 이 검정은 **성립하지 않는다**. 코드 대조군이 양방향으로 무효이기 때문이다:
(a) 현재 분류는 소급 재분류라 부당하게 이르다 — 3D NAND 전용 코드가 2008년 출원에,
GAA 전용 코드가 2012년 출원에 붙어 있다. (b) 당시 분류는 BigQuery 동결 스냅샷이
2017-10 부터라 해상도 바닥이 2017 이다 — 교정 창에서는 여섯 사례 중 넷이 동률이 된다.
이 무효성이 본 연구의 방법론적 발견이며 §5.3 에 자인한다.
