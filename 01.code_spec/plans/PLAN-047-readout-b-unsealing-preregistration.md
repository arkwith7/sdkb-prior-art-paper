## 2. 승계 조건 둘 — 개봉 사전등록이 반드시 인용해야 하는 것

### 2.1 D-32 — **이 코퍼스로 A층 §6 을 재산출하지 않는다**

현 코퍼스는 A층 후보 8건의 본문이 구 세대와 다르다(B층 질의로 승격되며 사이드카 청구항이

**8건의 차이가 A층 §6 수치에 얼마를 옮기는지는 미상**이다.

**그러므로 판독 B 는 B층 질의 200 의 판정이다.** A층 값이 필요하면 재측정이 아니라
**새 사전등록 아래 새 검정**이다(§1-3). 원고 §6.2–6.4 는 구 스냅샷 관측으로 남는다.

### 2.2 B층은 A층과 화제가 다르다 — **해석의 경계이지 판정 규칙의 근거가 아니다**

| | A층 1,000 | B층 200 |
|---|---:|---:|
| 문서당 개념 | 2.909 | **1.105** |
| 개념링크 보유 질의 | 977/1,000 | **117/200** |
| `H01L` 비중 | 14.8 % | **0.0 %** |

**온톨로지 결함이 아니라 표본의 성질**이다. 열린 질문은 *"판독 B 가 A층 결과를 재확증할 수
있는 표본인가"* 이며, **이 관측으로 ε·δ·주지표·K·가중치를 조정하면 §1-2 위반이다.**
개봉 전에 적어 두는 이유가 그것이다 — 결과를 본 뒤 이 표를 근거로 기준을 움직이면

> **미리 자인한다 — 판독 B 는 무효과로 끝날 수 있고, 그때 그것을 실패로 적는다.**
> 개념링크를 가진 질의가 117/200 이므로 온톨로지 팔이 신호를 낼 수 없는 질의가
> 83건이다. **이 자인은 결과를 완충하기 위한 것이 아니라, 결과가 나온 뒤 "표본이 나빴다"를
> 새로 쓰지 못하게 막는 장치**다(§1-2).

## 4. 동결 항목 B — T4 비열등 마진 (§6.8 판독값 **미참조** 도출)

**PLAN-038 §16.6-2 가 요구한 유일한 조건은 "결과를 보기 전에 규범적으로 정한다"이다.**
아래 도출에는 §6.8 의 어떤 값도 들어가지 않는다 — 들어간 것은 척도의 성질과 기존 마진의
전례뿐이다.

### 4.1 도출 규칙 셋 (규범적)

1. **T4 주지표는 인용 정확도(전체)다.** 결정적 채점이고(식별자 대조 · LLM 판정자 없음),
   분모가 질의 전량이라 팔 사이의 인용 건수 차이에 흔들리지 않는다. 조건부 정확도는 **보조**다 —
   분모가 팔마다 달라지므로 판정에 쓰지 않는다.
2. **마진은 새로 만들지 않고 승계한다.** 인용 정확도는 T1 의 Recall@100 과 같은 **[0,1] 비율**
   척도다. 이 연구가 이미 가진 비열등 마진은 **ε = 0.02** 하나뿐이므로 그것을 그대로 쓴다.
   **새 숫자를 만들면 그 숫자의 출처가 결국 결과가 된다.**
3. **환각률은 손해가 비대칭이므로 마진을 절반으로 둔다.** 근거 없는 식별자는 검토자를 잘못된
   문헌으로 보내므로 정확도 이득과 등가로 교환할 수 없다. → **η = ε/2 = 0.01**.

### 4.2 T4 판정식 (동결)

```
T4 = ( LB₉₅(Δ 인용 정확도(전체)) > −ε_T4 )  ∧  ( UB₉₅(Δ 환각률) < +η )
     ε_T4 = 0.02 · η = 0.01
     Δ = (새 팔) − (기준 팔) · 질의단위 paired bootstrap 10,000회 · 양측 · seed 고정
     회차 3회 평균을 점추정으로 쓰고, 회차 간 분산을 함께 보고한다(§1-11 비결정성 조항)
```

**보조 판독 셋은 판정에 들어가지 않고 보고만 한다** — 조건부 인용 정확도 · 근거 문장 일치
(결정적 하한) · 근거 불충분 선언 비율 · 질의당 평균 인용 건수(분모의 맥락).

### 4.3 이 동결이 T4 에 주는 지위 (🛑 결정 요청 ②)

PLAN-038 §16.5 의 발효 조건은 둘이었다 — ① C2′ 1회 완주(**확보 · A층**) ② 마진을 결과 보기
전 동결(**이 커밋으로 확보**). **그러므로 T4 는 이 커밋으로 발효 자격을 얻는다.**

다만 **승인식 `Accept` 에 T4 를 넣는 것은 CLAUDE.md §5 표의 개정**이므로 별도 승인 항목으로
올린다. 권고는 **분리**다 —

- **지금**: 마진 동결 + T4 를 "발효 자격 확보 · 승인식 편입 대기"로 표기.
- **판독 B 완주 후**: 자원 델타 위에서 T4 가 실제로 판정을 내는 것을 1회 확인한 뒤 승인식 편입.

**이유는 D-23 과 같은 종류다** — 지금 편입하면 **한 번도 자원 델타를 거부하거나 통과시켜 본 적
없는 게이트를 "가졌다"고 주장**하게 된다. §5 가 T4 에 대해 이미 경고한 문장이 그것이다.

## 13. 3단계 설계 — 동결 (2026-08-08 · **코드 변경 0 · 실행 0 · 봉인 미열람**)

### 13.0 설계 원칙 넷 (이 절의 모든 결정이 여기서 나온다)

1. **A층 경로는 바이트 단위로 불변이다.** B층은 **분기**로 붙이고, 기존 호출 경로의 기본값을
   한 개도 바꾸지 않는다. 회귀 테스트가 이것을 강제한다(§13.6 R1).
2. **봉인은 "열지 않았다"를 관측이 아니라 구조로 만든다.** 기본이 **거부**이고, 여는 데에는
   명시적 플래그와 사유가 필요하며, 열린 사실은 **추가전용 원장**에 남는다(§13.3).
3. **qid 는 정답이 아니라 분할에서 나온다.** 이것이 §12.0-1 차단의 해소이며, 판정식은
   불변이다(정답 ≥1 필터는 `evaluate()` 안에 그대로 있다).
4. **계측기는 손대지 않는다.** 모델·프롬프트·K·온도·`max_tokens`·회차·τ·α·w·RRF·토큰화는
   바뀌는 목록에 없다. 바뀌는 것은 **어느 질의를 넣고 어느 정답으로 채점하는가** 하나다.

## 18. T4 판정 산출 — 2·3단계 (2026-08-09 · 사용자 승인 · **판정 전**)

### 18.1 2단계 분석 — 실제 코드를 열고 본 것

| | 실측 |
|---|---|
| `rag/score.py` | 팔×회차 **집계만** 낸다. 질의 단위 레코드를 저장하지 않아 페어드 부트스트랩의 입력이 없다 |
| `analysis/bootstrap.py:74` | `paired_bootstrap` 는 **질의 단위 평균 차이**용이다(Recall 등). 인용 정확도는 **비율의 비율**(Σ정답인용 / Σ인용)이라 그대로 쓸 수 없다 |
| 동결식 §4.2 | Δ = (새 팔) − (기준 팔) · 질의단위 paired bootstrap 10,000 · 양측 · seed 고정 · 회차 3회 평균을 점추정 |

**핵심 제약 하나.** 인용 정확도·환각률은 **질의당 평균이 아니라 인용 식별자 전량을 분모로 하는
비율**이다(§11.4 동결 · `aggregate()` 가 그렇게 낸다). 부트스트랩도 **같은 정의로** 재계산해야
점추정과 CI 가 같은 것을 가리킨다 — 질의당 비율의 평균으로 바꾸면 그것은 **새 지표**다.

### 18.2 3단계 설계 — 동결 (결과 보기 전)

1. **표본 단위 = 질의(문서 단위 qid) · 페어드 · n = 198.** 두 팔이 같은 질의를 본다.
2. **회차 처리** — 질의별 계수(`n_cited`·`n_cited_correct`·`n_cited_out_of_context`)를
   **3회차 평균**한 뒤 부트스트랩한다(§4.2 "회차 3회 평균을 점추정으로"). 회차 간 sd 는
   §17.3 표대로 **따로 보고**한다(§1-11).
3. **재표집 통계량 = 비율의 재계산.** 리샘플된 질의 집합에서
   `Σ정답인용 / Σ인용` 을 팔마다 다시 구하고 그 차를 쓴다 — 점추정과 정의가 같다.
4. **분모 0 처리** — 리샘플의 Σ인용 이 0이면 비율이 정의되지 않으므로 **그 리샘플을 버리고
   버린 횟수를 보고**한다. 숨기지 않는다.
5. **난수** — `seed = config.SEED` · `n_boot = 10000` · 백분위 [2.5, 97.5] · 양측 p 는
   `analysis/bootstrap.py` 의 규약을 그대로 승계(부호 반대편 꼬리 ×2).
6. **판정식은 §4.2 그대로 · 재선택 없음.**
   `T4 = (LB₉₅(Δ인용정확도) > −0.02) ∧ (UB₉₅(Δ환각률) < +0.01)` · Δ = P1 − B3_rrf.
7. **보조 판독(조건부 정확도·근거 문장 일치·불충분 선언·인용 건수)은 CI 를 함께 내되
   판정에 넣지 않는다**(§4.2 말미).
8. **결정성** — 같은 입력·같은 seed 로 두 번 돌리면 바이트 동일한 JSON.

### 18.3 배치와 비목표

## 19. T4 판정 (2026-08-09 · 1회 · 조건 변경 0)

### 19.0 결론 먼저 — 넷

1. **T4 = 실패다.** 판정식 두 조건 중 **인용 정확도 비열등이 깨졌다** — `LB₉₅ = −0.0205`,
   임계는 `−ε_T4 = −0.0200`. **0.0005 차이다.** 환각률 조건은 통과했다(`UB₉₅ = +0.0059 < +0.01`).
2. **그런데 점추정은 P1 이 앞선다**(+0.0236). 실패의 원인은 성능 하락이 아니라 **구간의 폭**이다 —
   n=198 · 인용 식별자 약 330건이라 CI 가 ±0.044 로 벌어졌고, 그 왼쪽 끝이 마진을 0.0005 넘겼다.
   **"P1 이 생성 층에서 나빴다"가 아니라 "비열등을 이 표본으로는 보이지 못했다"이다.**
3. **마진을 고치지 않는다.** ε_T4=0.02 는 `67568c8` 에서 결과를 보기 전에 동결됐고, 0.0005 를
   위해 마진을 움직이는 것이 정확히 §1-2 가 금지하는 행위다. **아깝다는 것이 근거가 될 수 없다.**
4. **T4 는 이제 자원 델타 위에서 실제로 판정을 내려 본 게이트다** — §4.3 이 승인식 편입의 조건으로
   내건 것이 이것이고, **판정 결과가 실패인 것은 조건과 무관하다.**
