## 1단계 — 요구 정의

### 1.1 왜 이 검증이고 왜 이것 하나인가

| 후보 | 준비도 | 판단 |
|---|---|---|
| ① 근거 복원(유사 판단 사례의 문헌·논거 승계) | 정답(평가 출원의 요소–문헌 대응)이 **사람 대조 FAIL 추출기의 산출물**(좌표 0.80). 사람 확인 없이 채점 불가 | 보류 |
| **② 요소별 검색 계획 → 알려진 심사 근거 확보** | 정답 = 심사관 인용(외부 원천). 에뮬레이터·분모 규칙이 동결돼 있음(상류 `t4_freeze_v1.json` `0627e5d9`) | **추천** |

검색하지 않음"(10건 · 단일 평정 · 비율 아님)이었다. 검색 계획은 바로 그 단계를 바꾼다.

## 2단계 — 분석 (데이터 먼저)

### 2.1 독립 검증이 현재 표본으로 가능한가 → **불가**

| 집합 | 노출 이력 | 이 검증의 확증에 |
|---|---|---|
| train 600 | 하류 개발 · 상류 어휘 채굴 · 논증층 사람 표본 r1–r3 · T4 v1 문턱·가중 | 불가 (지식 원천으로만) |
| dev 200 | 상류 harvest · PLAN-005 주 판정 · 사람 표본 r4–r6 · **T4 v1 평가 + 미회수 분석 + 원인 표본(가설 출처)** | **불가** |
| test 200 | 하류 봉인 원장 55행(사전등록 판독·테스트 실행 혼재 · D-54) · 상류 미노출 | 불가 — 다른 시스템의 확증에 이미 개봉 |
| test_b 200 | 하류 원장 25행 · 정답 간선 도달 6/514 | 불가 |

→ **신규 평가 집합이 필요하다.** 기존 test 의 독립성을 가정하지 않는다.

### 2.2 신규 평가 집합(가칭 `test_c`) — 모집단과 확보 방법

- **모집단:** 한국 특허 출원 중 (i) 기존 1,000 + test_b 200 과 **출원·패밀리 불교차** (ii) 기존 질의와 같은
  반도체 IPC 틀(B층 동결 21코드 재사용) (iii) 거절이유통지에 **심사관 인용 문헌 ≥1** (iv) 출원일이 지식 원천
  (train 경계 2016-11-21 이전) **이후** — 권장 창: 2018-03 ~ 2020-12(test_b 창 2018-01-02~02-16 제외).
- **확보:** 기존 `collect/b_layer/` 경로(KIPRIS `getAdvancedSearch` → `getBibliographyDetailInfoSearch` →
  `priorArtDocumentsInfo`). 인용 필드는 원장에서 제거하고 봉인 qrel 로만 보낸다(B층 선례). PLAN-031 양식의 포함기준·
  호출 예산을 수집 전에 동결.
- **도달 가능성 사전 점검(B층 실패의 교훈):** 인용 문헌의 서지·청구항·초록 확보율을 **qrel 개봉 없이** 식별자
  해소율로 먼저 잰다. 문턱(예: 해소율 ≥ 0.8)을 수집 전 동결하고, 미달이면 판독을 열지 않는다.
- **후보 코퍼스:** 상류 동결 코퍼스(41,031 · `d8562693`) + 신규 인용 문헌 + **같은 IPC·같은 공개기간 방해문서**
  (인용 여부와 무관한 규칙 표집). 동결 코퍼스가 구성상 정답을 포함한다는 한계(상류 §3.1′-9)를 그대로 상속하므로
  **방해문서를 규칙으로 늘려 정답 밀도를 낮춘다** · 라이브 KIPRIS 표본 확인을 병행(범위 차이 보고, 성능 아님).
- **표본 크기(사전 산정 · 탐색값 기반):** 상류 T4 v1 dev 의 d−b 95% CI 반폭 0.037(n=197)에서 질의별 차의 SD ≈ 0.27.
  차 0.05 를 양측 α=.05 · 검정력 0.8 로 보려면 n ≈ 230. 반복 3회 평균으로 SD 가 줄 수 있으나 보수적으로
  **N = 250 출원(정답 ≥1)** 을 목표로 한다. 이 SD 는 다른 대비(d−b)의 값이므로 **추정**이다.

### 2.3 판단 지식의 원천과 형태

- **원천:** 상류 논증층의 **train 판단 3,664**(블록·논거 범위만 · 좌표·관계 미사용 — FAIL 범위 회피) + train 심사관 인용.
- **재사용 단위(문헌 ID 불포함):** 요소 유형(개념) → 개시가 자주 발견된 관점·IPC·표현 패턴 · 논거 유형(설계변경·
  예측가능 효과·결합 동기)과 요소 결합 형태. **문헌 식별자 수준의 재사용은 이 실험에서 금지**(그것은 후보 ① 근거 복원이다).
- **A③ 과 A④ 는 같은 지식 내용이다.** A③ 은 표·JSON 덤프로 프롬프트에 넣고, A④ 는 온톨로지 도구(개념 조회 ·
  요소 유형 → 지식 항목 질의)로 접근한다. 두 팔의 **지식 항목 집합 sha 를 동일하게 동결**한다.

### 3.3 후보 선택·정렬·중복 제거 규칙 (상류 `union_rule` 계승)

- 검색식 단위로 실행 → **패밀리 병합 중복 제거 합집합**을 계획 순서대로 채택, 합이 예산을 넘는 검색식은 사전 정의된
  축소 절차(상류 adaptive) 후에도 넘으면 **불채택**.
- **순위화 후 절단 금지**(Boolean 결과에 순위가 없다 — 랭커 효과와 섞인다) · 문헌 ID 순 절단 금지.
- 예산은 상한이지 목표가 아니다 — 실제 검토량을 함께 보고.

### 3.4 지표와 분모

| 구분 | 지표 | 분모 |
|---|---|---|
| **주** | 출원별 **회수율@200** = 채택 합집합 ∩ 심사관 인용 / 분모, 출원 평균 | **분모 A:** 코퍼스 안에서 해소된 비NPL 고유 인용 문헌(패밀리 병합) — 수집 후 qrel 개봉 전에 수를 고정 |

### 3.5 분할·시점·패밀리·노출 이력

- 지식 원천: train(출원 < 2016-11-21) · 평가: `test_c`(출원 2018-03~2020-12 권장) — **시점 분리 + 패밀리 불교차**.
- 후보 마스크: 공개일 < 평가 출원의 출원일(기존 F10).
- 개발: 프롬프트·도구는 **train + v1 dev** 에서만 조정(dev 는 이미 노출되었으므로 개발용으로 써도 새 오염은 없다).
- `test_c` qrel 은 봉인, **1회 개봉** · 개봉은 `open_sealed` 경유로 원장 기록. pytest 가 봉인 qrel 을 읽지 않도록
  고정 픽스처를 쓴다(O-14·D-54 재발 방지).

### 3.7 불확실성과 판정

- 출원 단위 paired bootstrap 10,000(시드 동결) · 3회 반복은 출원 내 평균 후 부트스트랩, 반복 간 분산은 별도 보고.
