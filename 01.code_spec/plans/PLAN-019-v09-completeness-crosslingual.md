## 0. 왜 이 계획인가 — 한 문단

C2(검색 유용성)의 §6 표·그림은 2026-07-28 로 전량 채워졌다. 그럼에도 원고는 두 곳에서 **주장을 완결하지
못한다.** ① 제목·초록·기여 2가 약속한 **T-gate(C3)가 코드로도 실측으로도 존재하지 않는다**(§6.5·§6.6
전량 `[기입]`, H1·H2 미검정). ② C2 의 부정적 결과 3건이 **진단에서 멈춰** 처방·검증의 폐루프가 없다
(§8.5 가 세 방향을 특정하고도 하나도 수행하지 않았다). 진보성은 이 두 루프를 닫을 때 생기고, 신규성은
실측이 이미 준 두 발견 — **태스크 결합**과 **교차언어 실명(失明)** — 을 서술이 아니라 데이터로 세울 때
생긴다. 이 계획은 그 둘을 작업 단위로 분해한다.

## 1. 착수 근거 실측 (2026-07-28 · 동결 run 재집계 · 새 검색 0)

**정본 산출물 = `paper/tables/ir_crosslingual_{dev,test}.md`** (`make crosslingual` · 코드
`analysis/lang_recall.py`). 세 진단 모두 **새 검색 없이** 동결 run·코퍼스에서 계산됐다. test 분할은 이미
개봉됐으므로(2026-07-27 확증 1회 완료) 아래는 **확증 검정이 아니라 기술통계·진단**이며, 그렇게 라벨해
보고한다. 아래 표는 생성물의 발췌다(수치 정본은 생성물).

### 진단 1 — 시스템은 외국어 선행기술에 사실상 실명이다
test 정답 479건 중 **139건(29%)이 비한국어**인데(정답 문서 단위 `자기문서 / 패밀리` 회수, K=100):

| 시스템 | ko 340건 | **en 128건** | ja 11건 ⚠ |
|---|---:|---:|---:|
| B0 BM25 | 0.526 / 0.529 | **0.000 / 0.023** | 0.000 |
| B2 Dense (Titan v2) | 0.347 / 0.353 | 0.062 / 0.078 | 0.182 |
| B3 Hybrid | 0.526 / 0.529 | 0.047 / 0.070 | 0.182 |
| **B5 Ontology-only** | 0.203 / 0.203 | **0.109 / 0.117** | 0.000 |
| P0★ | 0.594 / 0.597 | 0.047 / 0.070 | 0.000 |
| P1 | **0.603 / 0.615** | 0.055 / 0.078 | 0.000 |

한국어 질의 BM25 가 영어 정답을 **정확히 0건** 회수한다(test 0/128 · dev 0/206 = 두 분할 334건 중 0건).
우연이 아니라 구조다 — nori 토큰과 standard 토큰은 교집합이 없다. 패밀리 해상도로 올려도 0.023 이라
한국어 형제 공개를 통한 우회 회수도 거의 없다.

**신규 발견(착수 시 예상 밖) — 온톨로지 단독 팔의 비교우위는 정확히 교차언어에 있다.** B5 는 한국어에서
가장 약한 팔이면서(0.203) 영어 정답에서는 **전 시스템 최고**(0.109 = 14/128 · B3 의 2.3배)이며 dev 에서도
같은 순서가 재현된다(B5 0.092 = 19/206 > B3 0.053 = 11/206). 그런데 이 우위가 최종 시스템에 전달되지
않는다(P0★·P1 ≈ B3) — **재랭크가 B3 풀만 재정렬하므로 B5 가 찾은 외국어 문서는 풀에 없다.** 이는
§7.3 재랭크 천장의 가장 극명한 사례이자 W2 설계(온톨로지 기반 후보 생성)의 **측정된 근거**다.
→ §6.4 의 "교차언어 이득 +0.0140 (p=0.518)"은 **설명되지 않은 약점이 아니라 설명된 구조**가 된다.

### 진단 2 — "언어중립 개념층"은 데이터에서 반만 참이다

### 진단 3 — 외국어 후보 풀 편향 (정직 보고 대상)

## 3. 교차언어 축 설계 (W1–W2) — "번역 미구현"을 실험 결과로

### 3.1 W1 (진단 코드화 · 새 검색 0 · 동결 불변)
진단 1–3 을 `analysis/lang_recall.py` 로 코드화해 원고에 싣는다. **동결 설정·동결 run 재집계이므로
사전등록을 건드리지 않는다.** 산출 = `paper/tables/ir_crosslingual_{split}.md` + viz 입력 CSV.

### 3.2 W2 (번역·교차언어 실험 · 별도 사전등록 필요)
F8(질의 표현)·F13(토큰화)을 건드리므로 **기존 H1–H5 의 사전등록을 수정하지 않고** 새 절(§6.7)과 새
확증 가설 H6·H7 로 분리한다(CLAUDE.md §1-3). 개봉 전 이 문서의 §3.2–3.5 를 커밋 해시로 동결한다.

**2×2 설계**

| | 온톨로지 없음 | 온톨로지 있음 |
|---|---|---|
| **번역 없음** | B3 (동결) | P1 (동결) |
| **번역 있음** | X1 = B3 ⊕ 번역팔 | X2 = P1 ⊕ 번역팔 |

- **H6 (교차언어 회수).** 번역팔은 **외국어 정답 보유 질의**의 family Recall@100 을 유의하게 개선한다.
> **T-G 는 2×2 밖의 세 번째 요인이다.** 재랭크 천장을 여는 팔이므로 번역·온톨로지 두 요인과 교차하지
> 않고 **주 효과만** 검정한다(요인 3개 완전교차는 표본이 감당하지 못한다). 사전 순서: 2×2 먼저, T-G 는
> 그 위에서 단일 추가 비교.

- **H7 (대체재/보완재 — 신규 주장 H).** 번역 × 온톨로지의 **상호작용**을 검정한다. 언어중립 개념층이
  번역의 *대체재*면 상호작용 < 0, *보완재*면 > 0. 진단 2(en 개념 70%·ja 0%)를 근거로 **보완재를 사전
  예측**한다. 기각 조건: 상호작용 95% CI 가 0 을 포함하면 "대체·보완 판정 불가"로 보고하고 확정 주장을
  세우지 않는다.

**팔 구성 (권장 실행 순서 = 효과 크기 순)**

| 팔 | 방식 | 근거·비용 |
|---|---|---|
| **T-D 문서 번역** | 비한국어 문서 **1,306건만**(en 1,189 + ja 117) 초록+청구항 KO 번역 → 한국어 인덱스 합류 | CLIR 통상 최강. Tier 2 전례(Bedrock 16-way, ~6분) 규모 |
| **T-Q 질의 번역** | 질의 독립항(F8) KO→EN, Haiku 4.5 temp=0·프롬프트 동결(sha) · **SDKB userdict 275 표층형의 한↔영 대역어를 용어 제약으로 주입** → EN 색인 검색 → 원 ko run 과 RRF | CLAUDE 동결 사실의 "Haiku 질의 번역" 이행 |
| **T-C 개념 보강** | ja 0%·en 30% 결손 개념링크를 IPC/CPC 경유·번역문 재추출로 보강 | 진단 2 의 직접 처방. 온톨로지팔이 교차언어에서 죽은 이유 검정 |
| **T-G 온톨로지 후보 생성** | B5(개념 팔)를 재랭크 입력이 아니라 **후보 생성기**로 승격 — B3 풀에 B5 상위 N 을 합집합한 뒤 재랭크 | 진단 1 의 신규 발견(B5 영어 회수 = B3 의 2.3배)이 직접 지지. §8.5 (a)+(c) 를 한 번에 겨냥 |

### 3.3 지표 (사전 정의 — 여기서 틀리면 검정력이 죽는다)
전체 R@100 은 ko 정답에 희석된다(test en 128 vs ko 340).
- **주:** 외국어 정답 보유 질의(test n=100)의 **family Recall@100**
- **보조(신규·핵심):** **language-stratified recall** — 질의 단위가 아니라 **정답 단위** 회수율(§1 진단 1 형식)
- ja(n=11)는 `MIN_N=20` 규칙대로 **확정 결론 금지**

### 3.4 통계
dev 에서 프롬프트·융합 가중 고정 → **test 1회 개봉**. 질의단위 paired bootstrap 10k(F4)·95% CI ·
Holm(F6) · 효과크기(F7). 상호작용은 (X2−X1) − (P1−B3) 의 부트스트랩 CI 로 보고한다.

### 3.5 누출·타당도 통제 (사전 명시)
- 번역기 입력은 **질의/문서 텍스트뿐** — qrel·인용 간선·거절근거 미투입. 호출 로그 해시 저장
- temp=0 + 번역 캐시 sha256 → F16 결정성 유지. 번역문은 원문 파생이라 gitignore, **해시만 커밋**(§1-5)
- **풀 편향(진단 3) 사전 보고** + 완화 감도분석 2종: (a) 외국어 방해문서 보강 코퍼스 재측정(코퍼스 서명
  변경 → 별도 스냅샷·서명 기록) (b) "외국어 정답 vs 외국어 비정답" 상대 순위 진단
- MT 품질: 표본 50건 인간 검증(용어 정확도) 보고. 실패는 실패로 보고한다

## 4. 우선순위와 의존

```
W1(진단·무비용) ──> W6(신규성 재프레이밍)
W3(T-gate+leakage) ──> W4(결함주입·H1) ──> W5(CQ 추이·§6.6)
W1 ──> W2(교차언어 실험 · 사용자 승인 + egress 필요)
```
권고 순서: **W1 → W3 → W4 → W5 → W2 → W6 → W7**. W3–W5 는 제목이 약속한 증거이고, W2 는 그 게이트
위에서 T1/T2 로 검증받는 델타가 된다.

### 4.1 CQ 스위트 배정 — W3 사전등록 동결 (2026-07-28 · 사용자 승인)

T3 의 분모다. **결과를 보기 전에** 배정하고 동결했으며, 정본은 각 `.rq` 파일 헤더의 `# suite:` 다
(라벨 없음·오값은 러너가 에러로 막는다 — 분모가 조용히 바뀌면 게이트가 공허해진다).

| 스위트 | n | CQ | 근거 |
|---|---:|---|---|
| **pa** 선행기술조사(주 태스크) | 5 | CQ09·10·16·26·27 | 거절–선행기술 정답 경로 · 개념 기반 후보 · 재료 금기(IP-R&D) · 수출통제 노출 · FTO 청구항 준비도 |
| **em** 전문가매칭 | 6 | CQ11·12·17·18·20·28 | 스킬·문제·재료·장비·결함모드 축의 인력 매칭 + 특허↔역량 브리지 |
| **tf** 기술예측 | 5 | CQ02·03·04·05·06 | 시점 질의 · 개념/IPC 연도별 시계열 · 커버리지 공백 |
| **core** 공유 substrate | 12 | CQ01·07·08·13·14·15·19·21·22·23·24·25 | 세 뷰가 공유하는 매핑·계층·밸류체인·인과사슬·규제 축 |

**T3 는 {em, tf, core} 만** 판정한다 — pa 의 회귀는 T1 이 통계적으로 담당하므로 이중계상하지 않는다.
배정은 §4.10 교차결함(동의어 오병합 → CQ-EM · 계층 역전 → CQ-TF·EM)이 걸릴 수 있는 구조여야 하며,
W4 결함주입이 이 배정의 검출력을 실측한다. **검출 실패 시에도 배정을 사후 조정하지 않는다** —
처방은 CQ 세분화이지 스위트 재배치가 아니다(부록 F).
