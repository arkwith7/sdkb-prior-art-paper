### 2.2 자원의 **도달면**이 코퍼스의 한 조각에 한정된다 (실측)

CR-020 이 고친 것은 A-Box 의 개념 배정이고, 코퍼스는 그것을 **G₀·G₁·G₂ TTL 에서 읽는다**

## 4. 판정식

### 4.1 CR 검증기준 (J1 · J2)

```
CR-001B ⑤ = CR-020 ⑥ = (ΔR₁₀₀(B5) > 0) ∧ (LB₉₅(ΔR₁₀₀(P1)) > −ε)      # ε = 0.02

승인 규칙(적용은 하되 H2 로 읽지 않는다):
Accept(O→O′) = (L0 = L1 = L2 = L3 = pass)
             ∧ (LB₉₅(ΔR₁₀₀) > −ε)                                    # T1
             ∧ (max_s drop_s < δ)                                     # T2
             ∧ (∀f ∈ {em, tf, core}: pass_f(new) ≥ pass_f(old))       # T3
```

- **T1 은 누출 감사 통과를 전제로만 유효하다.** `make leakage` 위반이 0 이 아니면 T1 판정을
  산출하지 않고 실패로 보고한다(§1-4).
- **자원 가시성**(§2.1 2′)을 함께 읽는다. `resource_visibility.note` 가 `invisible` 이면 그
  실행의 ΔR₁₀₀ 은 측정된 0 이 아니라 **구성상 0** 이며, 통과를 근거로 쓰지 않는다.
- **도달면 한정(§2.2)을 판정문에 함께 적는다** — 결과가 어느 방향이든.

### 4.2 T3 — D-53 의 판정 (J3)

```
T3 = ∀f ∈ {em, tf, core}: pass_f(graph_v0 @ 013854b) ≥ pass_f(g0_cq31)
판정 규칙 v2 = 존재검사(rows ≥ expect-min) ∧ ¬회귀(rows < (1−τ)·base · 극성 up)
```

**기준 세대의 한계를 먼저 적는다.** D-53 ① 은 *"구 세대(`0a7ff15`)와 현 세대(`013854b`)"* 의
통과율 비교를 요구했으나, **`0a7ff15` 세대의 CQ 통과율은 동결 산출물로 남아 있지 않다.**
디스크에 있는 기준 세대는 `g0_cq31`(그래프 sha `a79a8a27…` · 상류 `d578bf3` 시절)이다.
그러므로 **기준선은 `g0_cq31` 로 두고, 세대가 D-53 의 명세와 다르다는 사실을 판정과 함께
적는다** — 기준을 사후에 고쳐 적지 않는다(§1-3 · CR-001B §12.2 와 같은 형식).

**이미 관측된 입력을 숨기지 않는다.** 현 그래프에서 `CQ18_patents_by_skill` 이 10행 → **4행**
임은 O-8 ③ 에서 이미 관측됐고 동결 상수로 갱신됐다. 아직 판정되지 않은 것은 **그 행 수가
판정 규칙 v2 아래에서 `em` 스위트 통과율에 무엇을 하는가**이며, **그 규칙은 PLAN-021 에서
동결됐다**(τ=0.05 · 극성 `up`). 규칙이 결과보다 먼저 있으므로 사후 조정의 자리가 없다.

**하락이 나오면 하락으로 적는다.** waiver 토큰은 쓰지 않는다 — 쓰면 그 횟수가 보고 대상이고,
이 자리에서 면제할 사유가 사전에 없다.

### 4.3 분할 — ⑤·⑥ 의 명세는 `dev` 이고 이 실험은 `test` 다

두 CR 의 검증기준은 `dev` 분할을 지정했다. **dev 의 O 팔을 구성할 수 없다** — 디스크의
`sys_*_dev.txt` 는 2026-07-27~28 산출로 O 팔의 자원 세대보다 앞서고, 구 스냅샷의 TTL 은
복원 불가다(§2.1 과 같은 사유). 이것은 PLAN-072 §12.2 가 이미 기록한 구조적 제약이며
**이번에도 해소되지 않았다.**

**그러므로 판정은 `test` 에서 산출하고 표기는 "조건 충족/미충족 · 명세 분할 아님"으로 적는다.**
기준을 사후에 `test` 로 고쳐 적지 않는다. **dev 를 명세대로 판정하려면 구 스냅샷을 상류에서
복원해 두 팔을 다시 만들어야 하며, 그것은 이 사전등록의 범위가 아니다**(별도 승인 사항).

## 7. 예상하지 않는다 · 사전에 밝히는 것

**기대치를 적지 않는다.** PLAN-072 가 `48971f8` 에서 관측한 값(`B5 +0.011616` ·
`P1 −0.001824`)은 **그 팔의 관측이지 이 실행의 기대치가 아니다** — 적는 순간 결과를 읽는
자가 된다(§1-2 · v0.9 인용 규칙 ②).

**사전에 밝혀 둘 구조적 사실 둘.**

1. **CR-020 의 델타는 코퍼스의 11.4 % 에만 그래프 경로로 닿는다**(§2.2). 그러므로 이 실행이
   `B5` 를 움직이지 못해도 그것은 *"축 교정이 무익하다"* 의 증거가 아니라 **도달면의 귀결**일
   수 있으며, 두 설명을 이 실험은 **가르지 못한다**.
2. **CR-001B 의 어휘 델타는 전 문서에 닿는다.** 그래서 관측된 움직임의 대부분이 어휘 쪽에서
   왔을 수 있고, 이 실험은 그것도 **가르지 못한다**(§0 ②).

**금지 문구.** 개선이 나와도 *"온톨로지 보강이 검색을 개선한다"* 로 쓰지 않는다(§0.8 ·
`test` 는 개봉된 표본이다). 악화가 나와도 *"온톨로지 보강은 무익하다"* 로 쓰지 않는다(§0 ⓐ).
T3 가 통과해도 *"게이트가 안전을 보장"* 으로 쓰지 않는다(§0.8 H2 행).
