동결 상수는 `retrieval/agent_frozen.py`. **`rag/` 에 넣지 않는다** — `rag/` 는 생성 층이고 "검색 로직 금지" 다. Bedrock 클라이언트만 `rag/generate.py` 에서 가져온다.

### D2. 판단 지식 원천의 반입 — **권고: 별도 고정 자산으로 vendor(주 스냅샷과 분리)**

- `make vendor` 에 **선택적 대상 하나**를 추가해 상류 `sdkb-abox-argument.ttl` 을 `data/external/sdkb_argument/` 로 복사하고 **자체 PROVENANCE**(파일 sha ·
  상류 커밋 · 상류 워킹트리 상태 · 복사 일시)를 남긴다. 주 스냅샷 `data/external/sdkb/PROVENANCE.json` 은 바꾸지 않는다.
- **왜 분리하나.** 주 스냅샷의 파일 sha 가 바뀌면 §2.1(전량 재측정)이 발동한다. 기존 파이프라인은 이 파일을 읽지 않으므로 그 재측정은 §2.1-2′ 의
  "비가시" 실행이 되고 증거가 되지 않는다. 파일럿만 읽는 자산을 별도로 두면 기존 판정의 조건을 건드리지 않는다.
- **적용 범위와 근거(사용자 승인 2026-10-17).** 이번 반입만을 이유로 기존 실험 전체를 재측정하지 않는다. 근거: CLAUDE.md §2.1 의 발동 조건은
  "`data/external/sdkb/` 의 파일 sha256 변경" 이고, 별도 자산은 그 디렉터리 밖(`data/external/sdkb_pilot/`)에 있어 주 스냅샷 `PROVENANCE.json` 이
  바뀌지 않는다. 기존 파이프라인(`corpus` · `index` · `retrieve` · `eval` · `gate`)은 이 자산을 읽지 않고, 기존 입력·코드도 바뀌지 않는다. **이 조건 중
  하나라도 깨지면**(기존 모듈이 별도 자산을 읽게 되거나 주 스냅샷이 바뀌면) §2.1 이 다시 발동한다 — 회귀 시험으로 고정한다.
- 원문이 담긴 파일이므로 gitignore 대상이다(§1-5) — 커밋되는 것은 PROVENANCE 와 집계뿐이다.
- 쓰는 범위: **train 출원(< 2016-11-21)에 속한 판단만** · 블록(`judgesClaim` · `judgmentScope` · `onGround`)과 논거(`hasRationale` ·
  `reliesOnCommonKnowledge`)만 · `locator*` · `refersToJudgment` · `includesDocument` 의 문헌 식별자는 항목에 넣지 않는다.

### D3. 지식 항목의 정의 — PLAN-094 §2.3 의 빠진 부분 (**파생 구현 승인 · 내용 미확정**)

**승인 조건(2026-10-17).** ① 아래 통계 칸은 최종 판단 지식이 아니라 **"심사 이력 집계 정보"** 로 부른다. ② 실제 사례 3–5개에서
**원문 판단 근거 → 적용 가능한 요소·조건 → 참고할 검색 행동 → 적용 한계** 의 연결을 먼저 확인한다. 근거가 부족한 연결은 검색 규칙으로 만들지 않는다.
③ 인용 문헌 언어 분포는 **제외**한다. ④ 반입 논증층이 이전 FAIL 산출물인지 · 교정본인지 · 검증된 부분집합인지 확인하고 사용 범위를 제한한다.
⑤ 평가 질의와 그 패밀리의 판단·인용 정보는 지식 생성에서 제외한다. ⑥ A③·A④ 는 같은 원천과 같은 파생 규칙을 쓴다.

항목 하나 = **(요소 유형) → { 거절 근거 분포 · 논거 유형 분포 · 공지기술 의존 비율 · 개시가 확인된 검색 관점 }**.

| 칸 | 만드는 법 | 쓰는 원천 | 넣지 않는 것 |
|---|---|---|---|
| 요소 유형 | 판단이 가리키는 청구항(`judgesClaim`)의 한정요소 개념(vendor 된 `claim_features.parquet` 의 `featureConcept`) | 주 스냅샷(이미 vendor) | 청구항 원문 |
| 거절 근거 분포 | 그 요소 유형을 포함한 train 판단의 `onGround`(신규성·진보성 등) 비율 | 논증층 | 출원 식별자 |
| 논거 유형 분포 | `hasRationale` 범주(설계변경 · 결합 동기 · 효과 예측 등) 비율 | 논증층 | 논거 원문 |
| 공지기술 의존 | `reliesOnCommonKnowledge` 비율 | 논증층 | — |
| 개시 관점 | 그 판단의 인용 문헌(`includesDocument`)이 가진 IPC 메인그룹 상위 k · 인용 문헌 언어 분포 | 논증층 + 코퍼스 메타 | **문헌 식별자 · 문헌 텍스트** |

- **최소 지지 수:** train 판단 ≥ n(결과 전 동결 · 초안 5)인 요소 유형만 항목이 된다.
- **인용 통계 재포장 경계:** "개시 관점" 칸은 상류 d 의 패싯과 겹친다. 그래서 거절 근거·논거·공지기술 세 칸을 핵심으로 두고, 파일럿 보고서에서
  **칸별 사용 빈도**(R10)를 따로 센다 — 그 차이가 지식의 내용이 무엇이었는지를 설명하는 자료가 된다(인과 아님).
- **언어 분포 칸: 제외(사용자 결정 2026-10-17).** 인용 문헌 언어 분포는 외국어 검색을 유도할 수 있어 PLAN-094 §2.4.4 ⑨ 의 구성 편향 가능성과 맞닿는다.
