## 1. 왜 고치는가

외부 독자(국문) 관점에서 파생본은 세 가지 이유로 읽기 어려웠다.

1. **도치·부정형 선행 문장** — "본 절이 묻는 것은 …이다" · "~이 아니다. ~이다" 형태가 절마다 첫
   문장을 차지해, 규격 S1(주제문 선행)을 형식상 지키면서도 결론이 뒤에 온다.
2. **작업 규약의 방어 서술 노출** — "이관은 삭제가 아니다" · "강등되었으나" · "규약이 요구하므로" 같은
   내부 작업 이력 어휘가 본문에 남아 독자에게 맥락 없는 문장이 된다.
3. **축약(PLAN-048·053)의 잔해** — 선행 목록이 사라져 지시 대상이 없는 "나머지", 출처 없는 수치, 그림과
   본문의 항목 번호 불일치.

## 3. 재구성한 절

- 국문 초록: 결과 셋을 "첫째·둘째·셋째"로 묶고, 한계 문단의 항목 순서를 논리 순(도메인→사례 수→원인→
  판정→기준선→질의 범위→후속)으로 정렬.
- §1 후반: 불일치 두 형태 → 검출 실패의 공통 이유 → 연구질문 → DSR 틀 → RQ → 기여, 순서로 일원화.
- §3 도입: 산출물 정의를 먼저, DSR 순환 설명과 표 2를 그 뒤에.
- §5.3: 비교군 O/O′의 정의를 먼저 제시한 뒤 통제 조건을 서술(원문은 통제 조건을 먼저 나열).
- §6.1: 세 관측에 확증 지위를 괄호로 병기하고 같은 무게로 읽지 않음을 도입에서 선언.
