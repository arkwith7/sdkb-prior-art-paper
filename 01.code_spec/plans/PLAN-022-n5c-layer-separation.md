## 0. 왜 이 실험인가 — 그리고 무엇을 주장할 수 없는가

W4b 는 H1′ 를 기각했으나 **기각의 원인을 구조로 특정**했다. 층 정의가 이렇게 돼 있다:

```
L3 = 전 스위트 {pa, em, tf, core} 28개 CQ 통과 수 하락       ← analysis/faults.py:310
T3 = 부분집합 {em, tf, core} 23개 스위트 통과율 하락          ← config.T3_SUITES
```

부분집합이 발화하면 상위집합도 반드시 발화한다. 실측이 이를 확증했다 — **T3 발화 ∧ L3 미발화
인스턴스는 τ ∈ {0, 0.05, 0.10} 전량(135개)에서 0건**이다. 따라서 H1 의 판정식 "교차결함이
L0–L3·T1·T2 를 통과하고 T3 에서만 검출된다"는 **CQ 를 아무리 세분화해도 충족될 수 없는 기준**
이었다. 기각된 것은 T3 의 유용성이 아니라 H1 의 판정 기준 설계다(원고 §6.5.2).

**이 실험은 층 정의를 바꿔 그 기준을 검정 가능하게 만든다.** 그러나 검정 가능해졌다고 기각이
취소되지 않는다:

| 라벨 | 규칙 | 지위 | 보고 |
|---|---|---|---|
| **H1** | CQ v1 존재검사 · L3 = 전 스위트 | **기각 — 확정.** 소급 변경 없음 | 표 7.1·§6.5 유지 |
| **H1′** | CQ v2 존재∧분포 · L3 = 전 스위트 | **기각 — 확정.** 사후 재설계·탐색적 | §6.5.2 유지 |
| **H1″** | CQ v2 · **L3 = pa 스위트** | **사후 재설계 · 탐색적.** 같은 데이터의 **3회차** 재판정 | §6.5.3 신설 · 확증은 차기 세대 델타의 몫 |

**같은 결함 데이터를 세 번째로 판정한다.** 이 순서를 숨기면 p-hacking 과 구분되지 않는다 —
§6.5.3 에 **"H1 기각 → 원인 진단 → 층 재정의 → 재판정"의 순서를 그대로 적는다.** H1″ 가 지지되어도
논문은 **"T3 는 주 태스크 감시가 놓치는 회귀를 잡는다"를 확증 결과가 아니라 재설계된 게이트의
설계 근거**로 쓴다.

### 0.1 이 재정의가 게이트를 약화시키지 않는다는 논증 (핵심 — 여기가 무너지면 실험 전체가 무효)

층을 좁히면 보통 검출력이 준다. **이 경우는 아니다 — 구조적으로 불변이다.**

```
현재:  L3 = {pa,em,tf,core}(28)  ⊇  T3 = {em,tf,core}(23)     합집합 = 28 CQ · 교집합 = 23
개정:  L3 = {pa}(5)              ⊥  T3 = {em,tf,core}(23)     합집합 = 28 CQ · 교집합 = ∅
```

**합집합이 같다.** 28개 CQ 는 개정 후에도 전량 실행되고 전량이 승인식에 들어간다
(`Accept = L0·L1·L2·L3 · T1 · T2 · T3` 의 곱이므로 어느 층에 붙든 하나만 실패해도 거부).
바뀌는 것은 **검출력이 아니라 귀속(attribution)**이다. 그러므로 이 재정의는 "게이트를 통과시키기
위한 완화"가 아니다 — **어떤 델타도 개정 전에는 거부되고 개정 후에는 승인되는 일이 없다.**
이 성질은 §5-1 에서 **테스트로 강제**한다(불변량 검사).

**의미도 개정 쪽이 맞다.** CLAUDE.md §5 는 T3 를 "**교차 태스크** CQ 비회귀"로 정의한다. 주 태스크
(pa)의 CQ 를 T3 의 분모에서 뺀 것과 같은 논리로, 주 태스크 CQ 는 L3(기능 검증)가, 타 태스크 CQ 는
T3 가 맡는 것이 층의 역할 분담과 일치한다. 현행 L3 가 전 스위트를 세는 것은 **T-gate 신설 이전에
쓰던 정의가 그대로 남은 것**이다(코드 주석에 근거 서술이 없다 — `faults.py:14` 는 규칙만 적는다).

**그럼에도 이것은 결과를 본 뒤의 변경이다.** 위 두 논거는 결과와 독립이지만(합집합 불변은 산술,
역할 분담은 CLAUDE.md §5 인용), 이 변경을 **떠올리게 만든 것은 W4b 의 결과**다. §6.5.3 에 그대로
쓴다.

## 1. 동결 규칙 A — L3 검출 표면 (사전등록 핵심)

```python
# config.py (신설)
L3_SUITES = ("pa",)                 # 주 태스크 기능 검증
T3_SUITES = ("em", "tf", "core")    # 교차 태스크 비회귀 — 불변
# 불변량: set(L3_SUITES) ∩ set(T3_SUITES) == ∅ ∧ set(L3_SUITES) ∪ set(T3_SUITES) == set(CQ_SUITES)
```

**L3 검출 조건(개정):** `pa 스위트 CQ 통과 수(v2 판정) < 기준선 pa 통과 수`.
- 기준선 pa 통과 수 = **4/5** (`data/processed/fault_baseline.json` · CQ27 은 G₀ 0행이라 원래 미통과).
- v2 판정 규칙(존재검사 ∧ 극성별 분포검사 · τ)은 [PLAN-021 §1](PLAN-021-w4b-cq-refinement.md) 그대로
  **승계한다 — 바꾸지 않는다.** 주 τ = 0.05 · 격자 τ ∈ {0, 0.05, 0.10} 전량 보고.
- **T3 는 한 글자도 바꾸지 않는다.** 이 실험의 조작 변인은 L3 하나다.

**CQ 는 재실행하지 않는다.** 판정에 필요한 것은 이미 격리본에 있다 — `cq_suite`(CQ→스위트 사상)와
CQ별 결과행이 `fault_baseline.json`·재판정 산출에 보존돼 있으므로, **스위트로 걸러 다시 세기만**
한다. 결함 재주입 0 · 격리본 0444 잠금 유지 · 정본 해시 재검증(`quarantine.verify_pristine`).

### 1.1 착수 전에 선언하는 예상 결과 (결과를 보고 고치지 않는다)

| 예상 | 근거 | 만약 빗나가면 |
|---|---|---|
| **L3 총 검출 수가 준다** | 분모가 28 → 5 로 좁아진다 | 예상대로여도 게이트 총검출은 불변(§0.1) — 그 불변을 표로 보인다 |
| **F04(CQ 경로 삭제)의 L3 검출이 약해지거나 사라질 수 있다** | F04 는 Process/SubProcess 의 `skos:prefLabel` 을 지운다 — pa 5개 CQ 중 몇 개가 그 라벨에 의존하는지는 **재판정 전이라 모른다** | 사라져도 그대로 보고한다. "L3 표적 결함이 L3 를 빠져나갔다"는 **불리한 실측**이며 §6.5.3 에 싣는다 |
| **T3 검출 수는 34/108 그대로** | T3 정의 불변 · 같은 격리본 | 달라지면 재판정 구현 오류다 — 즉시 중단하고 원인 규명 |
| **H1″ 교차결함 T3 단독검출 > 0 이 가능해진다** | 두 집합이 서로소가 되어 원리적 불가능성이 사라진다 | **0 이 나올 수 있다.** 그때는 "판정식이 아니라 F11·F12 가 실제로 타 태스크 CQ 를 건드리지 못한다"가 결론이며, **H1″ 도 기각**으로 확정 보고한다 |

**"가능해진다"는 "지지된다"가 아니다.** 서로소가 된 것은 필요조건일 뿐이다.

## 2. 동결 규칙 B — 중복제거 델타 유형 면제 (위양성 처방)

W4b 의 불리한 실측: 승인된 정상 델타 **N03(완전중복 개체 병합)이 τ=0 에서 3/27(11.1%) 거부**됐다
(사전등록 기준 5% 초과). 분포검사는 **행이 준 이유**를 구분하지 못한다 — 지식이 사라진 것과
중복이 정리된 것을 같게 본다. τ 를 올리는 것은 처방이 아니다(검출력 55 → 34 → 18 로 붕괴).

**면제 규칙(동결).**

```
델타는 유형을 선언한다: delta_type ∈ {generic, dedup}
delta_type == "dedup" 인 경우에 한해:
    ① 자동 검증: 제거된 모든 개체 b 에 대해, 병합 전 그래프에서
       out_sig(b) == out_sig(keep) ∧ in_sig(b) == in_sig(keep)   (IRI 제외 트리플 집합 완전 동일)
       — 하나라도 어긋나면 면제 **불승인**, 일반 델타로 판정한다.
    ② 검증 통과 시: 분포검사(regress)만 면제한다. **존재검사는 면제하지 않는다.**
    ③ 면제 사용은 로그에 남고 표 6.6 에 횟수를 보고한다(waiver 와 같은 규율 — 조용한 면제 금지).
```

- **정당성을 사람이 판단하지 않는다.** 트리플 동일성만 근거로 쓴다 — 라벨 유사도는 금지
  (PLAN-021 §3 의 `raon_tech` vs `raontech_inc` 함정: ASCII 정규화만 같고 서로 다른 회사였다).
- **면제는 dedup 이 실제로 지운 개체에만 적용되지 않는다** — 규칙은 델타 단위다. 이것이 느슨한
  쪽 선택임을 명시한다: dedup 을 선언하고 그 안에 다른 결함을 숨기면 분포검사를 빠져나간다.
  **그래서 §3 에 이 악용 시나리오를 결함으로 주입해 실측한다**(N03-adv).
- 존재검사를 남기는 이유: 중복 병합은 CQ 를 0행으로 만들 수 없다(중복이 아닌 개체는 남는다).

### 2.1 신설 검정 대상 — N03-adv (면제 악용)

면제 규칙을 넣으면 **그 규칙을 악용하는 결함**이 새로 가능해진다. 규칙과 함께 그 구멍도 잰다.

- **N03-adv**: `delta_type=dedup` 을 선언하되 병합 대상 중 일부를 **완전중복이 아닌 쌍**으로 채운다.
- **기대**: ① 자동 검증이 불일치를 잡아 면제를 불승인 → 일반 델타로 판정 → 검출. 검증이 통과시키면
  그것은 면제 규칙의 결함이며 **그대로 보고**한다.
- 이것은 결함(FAULTS)이지 정상 델타(NORMALS)가 아니다 — 위양성 분모에 넣지 않는다.

### 2.2 사전등록 판정 기준 (위양성)

- **정상 델타 N01·N02·N03 의 거부율 < 5%** (τ 격자 전량에서). N03 이 5% 를 넘으면 면제 규칙 실패.
- N03-adv 는 **검출되어야** 한다(면제 불승인 또는 층 검출). 미검출이면 면제 규칙의 구멍으로 보고.

## 3. 범위 밖 — 선행기술 CQ 청구항 수준 분해 (이번에 하지 않는다)

N5c 로 함께 이월된 세 번째 항목이다. **이번 실험에 넣지 않는다.**

이유: pa CQ 를 분해하면 **L3 의 분모(5개)와 기준선 통과 수(4)가 함께 바뀐다.** 그러면 H1″ 재판정의
변화가 (a) 층 분리 때문인지 (b) CQ 분해 때문인지 **분리할 수 없다.** 한 번에 한 변인만 바꾼다.
또한 CQ 추가는 세대 아티팩트 `cq_g0.json` 재동결을 요구하므로 표 6.6 의 세대 비교 규율
(같은 규칙끼리만 유효)을 건드린다.

→ **PLAN-023 후보로 이월.** 순서: 층 분리(본 계획) → 결과 확정 → 그 위에서 pa CQ 해상도.

## 4. 사전등록 판정식 — H1″

```
H1″:  교차결함(F11 동의어 오병합 · F12 공유 계층 역전)은
      L0·L1·L2·L3(pa)·누출감사·T1·T2 를 모두 통과하고 T3 에서만 검출된다.

지지 조건 (전부 충족):
  ① T3 단독검출 비율  n_t3_only / n_cross_instances  > 0        (주 τ=0.05)
  ② McNemar(L0–L3 검출 vs T-gate 검출 · 결함 단위 대응) 방향이 T-gate 우위
  ③ 정상 델타 거부율 < 5% (§2.2)
하나라도 불충족이면 H1″ 기각으로 확정 보고한다.
```

- **①의 임계를 0 초과로 둔 이유**: W4·W4b 에서 이 값은 0/18 이었다. 층이 서로소가 된 뒤에도 0 이면
  판정식이 아니라 결함 자체가 타 태스크 CQ 를 건드리지 못한다는 뜻이며, 그것이 결론이다.
  **비율의 크기에 대한 사전 예측은 하지 않는다**(표본 18 · 근거 없음).
- **검정 통계는 새로 만들지 않는다.** McNemar 는 W4·W4b 와 동일 구현·동일 대응쌍.
- τ 격자 3값 전량 보고. **주값은 0.05 하나**이며 다른 τ 에서 유리한 값이 나와도 주 결론을 바꾸지 않는다.

## 6. 이 계획이 스스로 금지하는 것

1. **τ·ε·δ·T3 분모를 건드리지 않는다.** 조작 변인은 L3 표면 하나 + 면제 규칙 하나.

4. **H1″ 를 확증 증거로 쓰지 않는다.** 3회차 재판정이며, 확증은 차기 세대 델타의 몫이다.
5. **불리한 실측을 먼저 보고한다** — F04 의 L3 검출 소멸 가능성, 면제 규칙의 구멍(N03-adv),
   그리고 T3 단독검출이 여전히 0 일 가능성.
