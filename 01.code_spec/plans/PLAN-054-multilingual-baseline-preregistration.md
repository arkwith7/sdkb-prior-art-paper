## 0. 이 문서가 하는 일 한 문장

**텍스트 기준선을 다국어 인코더로 강화하였을 때 이 논문의 결론이 유지되는지를, 결과를 보기 전에
구성·지표·보고 문장까지 못 박는다.**

**답할 질문은 하나다.**

> **텍스트 기준선을 다국어로 강화하여도 이 논문의 결론이 유지되는가.**

질문을 하나로 줄인 것은 절약이 아니라 설계다. "교차언어 커버리지"를 별도 질문으로 세우면 별도 절·
별도 표·별도 해석 문단이 따라오고, 그것이 PLAN-053 이 제거하려는 산만함의 발생 기전이다.

### 0.1 왜 이 실험이 필요한가 (실측 근거)

| | 실측 | 출처 |
|---|---|---|
| 한국어 질의의 어휘 검색이 영어 정답을 회수하지 못한다 | 확증 분할 0/128 · 개발 분할 0/206 (**합계 334건 중 0건**) | 원고 §6.4.4 |
| 알려진 양성의 상당수가 비한국어다 | 전체 qrel 2,321건 기준 **41%** · 확증 분할 479건 기준 **29.0%** (**분모를 혼용하지 않는다**) | 원고 §8.2 |
| **현 배제 논거가 후보를 덮지 못한다** | §5.3 은 특허 특화 인코더를 *"영어 전용이며 입력 길이가 짧아"* 배제하였다. **BGE-M3 는 다국어이고 8192 토큰이므로 이 논거에 걸리지 않는다** | 원고 §5.3 |

**세 번째 항이 이 실험의 직접 사유다.** 배제 논거가 후보 전체를 덮지 못하면, §6.4.4 의 `0/334` 는
*설계의 귀결*이 아니라 *기준선 선택의 귀결*로 재해석될 수 있다. 그 재해석이 성립하면 평가환경 자체가
교차언어 태스크에 부적합하다는 지적으로 확대된다.

### 1.1 이 실험이 생산할 수 없는 것 — 지위의 사전 확정

**확증 판정을 생산하지 않는다.** A층 봉인(`984f8ef3…`)과 B층 봉인(`127a138f…`)은 **둘 다 이미
개봉되었다.** CLAUDE.md §2.1 말미는 개봉된 표본 위에서 우월성을 다시 확증하는 것을 금지한다.
따라서 본 실험의 지위는 **탐색적 강건성 점검**이며, 산출물은 어떤 가설의 지지·기각도 진술하지 않는다.

**그럼에도 정당한 이유.** 본 실험이 답하는 것은 *"P1 이 더 좋은가"* 가 아니라 *"이 벤치마크의
기준선이 정당한가"* 이다. 후자는 **평가환경의 성질에 대한 기술적 주장**이며 봉인을 전제하지 않는다.
전자를 주장하는 순간 §2.1 위반이 되므로, §6 의 보고 문장을 결과 보기 전에 고정한다.

## 2. 왜 이 구성 조합인가 — 한 구성 = 한 주장

PLAN-053 §2 의 원칙을 신규 구성에 **먼저** 적용한다. **계산은 3개, 본문 게재는 2개다.**

| 구성 | 정의 | 지는 주장 | 본문 |
|---|---|---|---|
| **B6** | 다국어 밀집 단독 (BGE-M3 dense 모드 · FAISS IndexFlatIP) | **없음** — B7 의 부품 | ✕ (S5) |
| **B7** | **BM25(nori) + B6 의 RRF** — *다국어 강한 텍스트 기준선* | 기준선 적합성 | **표 7 에 1행** |
| **P1′** | 온톨로지 재순위화 over **B7 후보 풀** | 이득의 강건성 | **표 7 에 1행** |

**B7 이 없으면 이 실험은 무의미하다.** 현 최강 기준선 B3 는 `BM25 + Titan` 이다. B6 만 추가하면
*"약한 하이브리드와 비교하였다"* 는 반론이 그대로 남는다. 비교 대상은 **같은 융합 구조에서 인코더만
다국어로 교체한 구성**이어야 한다.

**P1′ 이 없으면 심사자의 진짜 질문에 답하지 못한다.** *"더 강한 기준선 위에서도 온톨로지 이득이
남는가"* 가 그 질문이며, 재순위화 코드와 평가 배선을 그대로 재사용하므로 추가 비용은 인코딩
1회분뿐이다.

**B6 을 본문에 싣지 않는 이유.** 단독으로는 어떤 주장도 지지 않는다. B6 의 언어별 회수는 §6.4.4
진단 2문장이 흡수하고, 전 수치는 S5 에 남는다.

## 3. 구성의 배선 — 기존 모듈과의 동일성 (🔒 동결)

`src/sdkb_paper/retrieval/dense.py` 실측: 문서 `text_main` · 질의 `claims_independent` · 1024차원
정규화 · **FAISS IndexFlatIP** · 텍스트해시 sqlite 캐시 · Titan v2 토큰 상한 8192(초과 2건 적응 절단).

| 항목 | B2 (기존 · 불변) | **B6 (신설)** | 동일한가 |
|---|---|---|---|
| 문서 텍스트 | `text_main` | `text_main` | **동일** |
| 질의 텍스트 | `claims_independent` | `claims_independent` | **동일** |
| 색인 | FAISS IndexFlatIP (정규화 → 내적 = 코사인) | 동일 | **동일** |
| 토큰 상한 | 8192 | 8192 | **동일** |
| 절단 규칙 | 초과분 적응 절단 · 로그 보고 | 동일 | **동일** |
| 결정성 | 결정적 · 텍스트해시 캐시 | 동일 | **동일** |
| 인코더 | `amazon.titan-embed-text-v2:0` (1024) | **BGE-M3 (dense 모드 · 1024)** | **여기만 다르다** |

**바뀌는 것은 인코더 하나다.** 이것이 이 실험이 대조 실험인 이유이며, 다른 것이 함께 바뀌면
관측된 차이를 인코더에 귀속시킬 수 없다.

### 3.1 모델 선정 근거 (🔒 결과 보기 전 고정)

**BGE-M3 를 dense 모드로만 사용한다.** 선정 근거는 우리 데이터가 아니라 공개된 다국어 검색
벤치마크 성능과 아래 세 요건이다.

1. **다국어** — 한국어 질의 · 다국어 문서(한 39,246 · 영 1,189 · 일 117)를 한 공간에 놓는다.
2. **8192 토큰** — 문서 중앙 2,255자를 절단 없이 수용한다. B2 와 절단 조건이 같아진다.
3. **단일 벡터 코사인** — B2 와 배선이 동일하다. **multi-vector·sparse 모드는 켜지 않는다** —
   켜면 인코더가 아니라 **검색 방식**이 바뀌어 대조가 오염된다.

**개발셋 성능으로 모델을 고르지 않는다.** 후보를 여럿 돌려 본 뒤 좋은 것을 고르면 그것이 §1-2 가
금지하는 선택이다. **모델은 이 커밋에서 하나로 고정된다.**

### 3.2 융합·재순위화 (🔒)

- **B7 = RRF(B0, B6)** — 기존 `hybrid.py` 의 RRF 를 그대로 쓰고 **상수 k 를 B3 와 동일하게** 둔다.
  어휘 검색 구성요소는 **기존 `sys_B0_bm25_*.txt` run 을 그대로 재사용**한다(재색인 없음 · 토큰화 불변).
- **P1′ = P1 의 점수식을 B7 후보 풀에 적용** — 가중치 \(w_b, w_e, w_c, w_h, w_f, w_r\) 은 **P1 이
  개발셋에서 선택한 값 그대로**이며 **재조정하지 않는다.** 재조정하면 새 방법이 되어 §2 전체를 다시
  탄다. 후보 풀 크기도 **상위 1,000건**으로 P1 과 동일하다.

## 5. 적격심사 — 인코딩 전에 통과해야 하는 다섯 🛑

**E1 · 자원 조건 확인 (가장 중요).** 디스크의 온톨로지 자원이 **O′(교정 후) 조건**이고 원고 §6 은
**O 조건**이라는 어긋남이 이미 기록되어 있다. **P1′ 을 O′ 자원 위에서 산출하면 표 7 의 P1 행과
비교 불성립이다.** 인코딩 전에 개념 축·그래프 서명을 확인하고, **원고의 O 조건과 일치하지 않으면
P1′ 을 실행하지 않는다.** 불일치 시 처리는 둘 중 하나이며 **결과를 보기 전에 고른다** —
ⓐ O 조건 자원을 복원하여 실행 · ⓑ P1′ 을 이번 범위에서 제외하고 **B7 만** 보고한다.

**E2 · 입력 서명 대조.** `ir_corpus_v09.parquet` `83eef760ed0a…` · `split.parquet` `f93c18d28857…`
가 실행 시점에 동일할 것.

**E3 · 기존 run 불변.** 실행 전후로 `sys_B0_*`·`sys_B2_*`·`sys_B3_*`·`sys_B5_*`·`sys_P0star_*`·
`sys_P1_*` 의 sha256 이 **바이트 단위로 불변**일 것. 신규 run 은 **새 파일명**으로만 쓴다
(`sys_B6_*` · `sys_B7_*` · `sys_P1prime_*`).

**E4 · 누출 감사.** `make leakage` 통과(금지 간선 0). 새 구성도 같은 검사를 탄다.

**E5 · 결정성.** 동일 입력 2회 실행 시 run 파일이 동일할 것. 로컬 GPU 는 **직렬 배치 인코딩만**
사용하며 병렬 워커를 올리지 않는다(VRAM).

**다섯 중 하나라도 실패하면 실행하지 않고 보고한다.**

## 6. 보고 규칙 — 결과를 보기 전에 문장을 고정한다 (🔒)

### 6.1 본문에 쓸 문장 (표 7 의 2행 + 아래 형식)

> 다국어 기준선(B7)에서도 부차 구성의 깊은 회수 이득은 **부호가 유지되었다 / 유지되지 않았다.**

**어느 쪽이 나오든 이 형식으로 쓰고, 그대로 싣는다**(§1-2). 결과가 불리하여도 마찬가지다 —
이 실험은 우리 결과를 방어하려는 것이 아니라 **기준선이 정당한지 확인하려는 것**이다.

### 6.2 결과 유형별 허용 문장 (§0.8 문구 사전 준수)

| 관측 | **허용** | **금지** |
|---|---|---|
| B7 > B3 (기준선이 더 강함) | "다국어 인코더로 융합한 기준선이 더 강하며, 본 논문의 이득은 그 기준선 대비 재평가되어야 한다" | 기존 §6 판정의 소급 수정 |
| B7 ≈ B3 | "인코더 교체로 기준선 강도가 유의하게 변하지 않았다" | "다국어 기준선이 불필요함이 입증되었다" |
| P1′ 이득 부호 유지 | "이득의 부호가 더 강한 기준선에서도 유지되었다(탐색적)" | "이득이 재확증되었다" · "강건성이 검증되었다" |
| P1′ 이득 소멸 | "이득의 부호가 더 강한 기준선에서는 유지되지 않았다" | 이 결과를 근거로 기존 H3 판정을 변경 |
| 외국어 회수 개선 | "다국어 인코더가 외국어 정답을 회수한다(하위풀 기저율과 함께 해석)" | **기저율 없는 단독 인용** |

**어느 경우에도 H3·H5·T1–T4 의 판정 기록은 바뀌지 않는다.** 본 실험은 별도 사전등록 아래의
탐색적 점검이며, 기존 판정은 각자의 사전등록 기록으로 남는다(§1-3).

### 6.3 후보 풀 편향의 필수 통제

**영어 문서의 72.5%, 일본어 문서의 70.9%가 정답이다**(원고 §6.4.4). 외국어 하위풀에는 방해 문서가
희소하므로 **거기서는 어떤 검색기든 좋아 보인다.** 따라서 언어별 회수는 **반드시**

1. 해당 하위풀의 **정답 기저율**과 나란히 보고하고,
2. **무작위 선택 참조선**을 함께 제시한다.

**이 둘 없이 언어별 회수를 단독 인용하는 것은 본 사전등록 위반으로 다룬다.** 통제 없는 인용은
통계적 착시를 성능 개선으로 보고하는 것이 된다.

### 6.4 분모 규율

`2,534`(인용 엣지) ≠ `2,321`(고유 정답) ≠ `2,211`(노드 도달) ≠ `584`(판단 연결)를 혼용하지 않는다.
비한국어 비율은 **전체 qrel 기준 41%** 와 **확증 분할 기준 29.0%** 를 구분해 쓴다.

## 9. 비목표

1. **RAG 방법 제안** — 하지 않는다.
2. **P0★ 의 재판정** — 하지 않는다. 사전 지정 주 구성의 판정은 기존 사전등록의 기록이다.
3. **가중치 재조정 · 후보 풀 확대 · 토큰화 변경** — 하나라도 하면 재측정이 아니라 **새 방법**이며
   §2 전체를 다시 탄다.
4. **B2 의 교체** — B6 은 신설이지 대체가 아니다. Dense 모델 동결(§1-3)은 유지된다.

   **이들에게는 그대로 유효**하다. 배제 사유를 §5.3 에 명시적으로 남긴다.
6. **확증 판정의 생산** — §1.1.

## 10. 실패 시나리오와 사전 처리

| 시나리오 | 처리 (결과 보기 전 확정) |
|---|---|

| B6 결정성 위반 | 원인 규명 전까지 결과를 쓰지 않는다 |
| B7 이 B3 보다 **강함** | 그대로 보고하고 §6.2 의 해당 행 문장을 쓴다. **기존 판정은 수정하지 않는다** |
| P1′ 이득 **소멸** | 그대로 보고한다. 이 논문의 결론은 *"이득은 조건부이며 경계가 있다"* 이므로 **논지와 모순되지 않는다** |
| 외국어 회수가 여전히 0 | §6.4.4 의 *"설계의 귀결"* 해석이 **강화된다.** 그대로 보고한다 |

**마지막 두 행이 이 사전등록의 요점이다.** 이 논문의 논지는 층 사이의 지표 불일치와 이득의 경계이지
"온톨로지가 검색을 개선한다"가 아니므로, **불리한 결과도 논지를 훼손하지 않는다.** 그것이 결과를
보기 전에 보고 문장을 고정할 수 있는 이유다.
