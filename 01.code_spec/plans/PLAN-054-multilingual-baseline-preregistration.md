## 0. 이 문서가 하는 일 한 문장

**텍스트 기준선을 다국어 인코더로 강화하였을 때 이 논문의 결론이 유지되는지를, 결과를 보기 전에
구성·지표·모델 버전·보고 문장까지 못 박는다.**

**답할 질문은 하나다.**

> **텍스트 기준선을 다국어로 강화하여도 이 논문의 결론이 유지되는가.**

질문을 하나로 줄인 것은 절약이 아니라 설계다. "교차언어 커버리지"를 별도 질문으로 세우면 별도 절·
별도 표·별도 해석 문단이 따라오고, 그것이 PLAN-053 이 제거하려는 산만함의 발생 기전이다.

### 0.1 왜 이 실험이 필요한가 (실측 근거)

| | 실측 | 출처 |
|---|---|---|
| 한국어 질의의 어휘 검색이 영어 정답을 회수하지 못한다 | 확증 분할 0/128 · 개발 분할 0/206 (**합계 334건 중 0건**) | 원고 §6.4.4 |
| 알려진 양성의 상당수가 비한국어다 | 전체 qrel 2,321건 기준 **41%** · 확증 분할 479건 기준 **29.0%** (**분모를 혼용하지 않는다**) | 원고 §8.2 |
| **현 배제 논거가 후보를 덮지 못한다** | §5.3 은 특허 특화 인코더를 *"영어 전용이며 입력 길이가 짧아"* 배제하였다. **다국어·장문 인코더는 이 논거에 걸리지 않는다** | 원고 §5.3 |

**세 번째 항이 이 실험의 직접 사유다.** 배제 논거가 후보 전체를 덮지 못하면, §6.4.4 의 `0/334` 는
*설계의 귀결*이 아니라 *기준선 선택의 귀결*로 재해석될 수 있다. 그 재해석이 성립하면 평가환경 자체가
교차언어 태스크에 부적합하다는 지적으로 확대된다.

### 0.2 왜 인코더가 둘인가 — 그리고 왜 이것이 모델 쇼핑이 아닌가

인코더가 하나이면 *"하필 그 모델이 약했던 것"* 이라는 반론이 남는다. 계열이 다른 둘을 쓰면 그
반론의 표면이 줄어든다. 다만 **둘을 돌린 뒤 좋은 쪽만 싣는 것은 §1-2 가 금지하는 선택**이므로,
아래 셋을 결과 보기 전에 못 박는다.

1. **둘 다 전량 보고한다.** 어느 쪽도 결과를 본 뒤 탈락시키지 않는다(S5 에 전 수치).
2. **본문 기준선 B★ 의 선정은 개발 분할로만 한다**(§4.2 규칙 · test·test_b 미사용).
3. **이득 진술은 test 에서 더 강한 융합 기준선 대비로도 함께 보고한다**(§8.2 보수 규칙). 이 규칙은
   우리 이득을 **작게** 만드는 방향이므로 유리한 선택이 될 수 없다.

### 1.1 이 실험이 생산할 수 없는 것 — 지위의 사전 확정

**확증 판정을 생산하지 않는다.** A층 봉인(`984f8ef3…`)과 B층 봉인(`127a138f…`)은 **둘 다 이미
개봉되었다.** CLAUDE.md §2.1 말미는 개봉된 표본 위에서 우월성을 다시 확증하는 것을 금지한다.
따라서 본 실험의 지위는 **탐색적 강건성 점검**이며, 산출물은 어떤 가설의 지지·기각도 진술하지 않는다.

**그럼에도 정당한 이유.** 본 실험이 답하는 것은 *"P1 이 더 좋은가"* 가 아니라 *"이 벤치마크의
기준선이 정당한가"* 이다. 후자는 **평가환경의 성질에 대한 기술적 주장**이며 봉인을 전제하지 않는다.
전자를 주장하는 순간 §2.1 위반이 되므로, §8 의 보고 문장을 결과 보기 전에 고정한다.

### 2.1 관찰이 드러낸 사실 넷 — 3단계에서 처리를 정해야 하는 항목

**OBS5.1 · 두 모델은 토크나이저와 백본 계열을 공유한다.** 둘 다 `XLMRobertaTokenizer` · 어휘
250,002 · 파라미터 566.70 M · 아키텍처 `bert` · 임베딩 1024 · 선언 컨텍스트 8192 이며, 코퍼스
41,223건의 토큰 길이가 **원소 단위로 완전히 동일**하였다. **§0.2 와 §3.2 는 "계열이 다른 둘"을
근거로 인코더를 둘로 하였으나, 관찰은 그 전제를 지지하지 않는다.** 이 사실은 결과와 무관하게
관측된 것이므로 사후 조정이 아니며, 3단계에서 ⓐ 전제 문장을 실측에 맞게 고쳐 그대로 진행할지
ⓑ 계열이 다른 후보로 하나를 교체할지 정한다. **여기서 임의로 고르지 않는다.**

**OBS5.2 · 절단 조건이 두 모델에서 비대칭이다.** 컨텍스트를 넘는 입력에 대해 `bge-m3` 는 값을
반환하고(암묵 절단) `snowflake-arctic-embed2` 는 HTTP 400 `the input length exceeds the context
length` 로 실패한다. 같은 문서·같은 `num_ctx` 에서 관측된 차이다. 또한 `num_ctx` 를 명시하지
않으면 두 모델 모두 **4096** 으로 적재되어 초과 문서가 354건(0.86 %)이 된다. **따라서 서버측
절단에 의존하지 않고 어댑터가 토크나이저로 결정적으로 선절단해야 하며**(§3.1 의 "B2 와 동일
규칙"), `num_ctx = 8192` 를 매 호출에 명시해야 한다. 8192 에서의 초과는 13건(0.032 %)으로
**E6 의 5 % 문턱은 통과**하나 B2 의 2건과는 자릿수가 다르므로 **E6 의 표기 조항이 발동한다.**

**OBS8.1 · 자원 조건 불일치 (E1 발동).** 디스크 `ir_corpus_v09.parquet`(sha `83eef760ed0a…`)의
개념 어휘는 **199** · 문서당 개념 **3.726** 이고, 디스크 성능표 `ir_performance_test.csv`
(2026-08-01)의 값은 **P1 R@100 = 0.4556 · B5 = 0.2282** 이다. 이는 PLAN-035 가 기록한 **O′ 팔**의
값이며, 원고 §6 이 인용하는 **O 팔**(어휘 141 · 문서당 1.545 · P1 = 0.4849 · B5 = 0.1800)이
아니다. **P1′ 을 이 자원 위에서 산출하면 표 7 의 P1 행과 비교가 성립하지 않는다.**
처리는 §7 E1 의 ⓐ·ⓑ 중에서 3단계에 고른다 — **결과를 보기 전에 고른다.**

**OBS8.2 · 동결 run 은 현 코퍼스 세대의 산출물이 아니다.** MANIFEST 대장 실측 — 코퍼스는
`3a5afe224ab1`(2026-08-08 01:07) → `83eef760ed0a`(같은 날 11:26) 로 재조립되었고, 디스크의
`sys_*_test.txt` 는 05:17 산출이므로 **이전 세대 코퍼스 위에서 만들어졌다.** 2026-08-15 재조립은
sha 가 `83eef760ed0a` 로 **동일하게 재현**되었으므로 코퍼스 자체의 결정성은 확인되었다.
**B7·B9 가 재사용할 `sys_B0_bm25_*` run 도 이 범위에 든다** — BM25 는 개념을 읽지 않으나 시점
유효 필터가 `publication_date` 를 읽고 그 컬럼이 재조립에서 6건 채워졌다는 기록이 있다(D-33).
3단계에서 **B0 run 을 재사용할지 현 코퍼스에서 재산출할지**를 정한다. 재산출은 토큰화·색인

### 3.2 모델 선정 근거 (🔒 결과 보기 전 고정)

**두 인코더를 dense 단일 벡터로만 사용한다.** 선정 근거는 우리 데이터가 아니라 공개된 다국어 검색
벤치마크에서의 위치와 아래 세 요건이다.

1. **다국어** — 한국어 질의 · 다국어 문서(한 39,246 · 영 1,189 · 일 117)를 한 공간에 놓는다.
2. **장문 수용** — 문서 중앙 2,255자를 절단 없이 수용한다(실측은 OBS3·OBS5).
3. **단일 벡터 코사인** — B2 와 배선이 동일하다. **BGE-M3 의 multi-vector·sparse 모드는 켜지
   않는다** — 켜면 인코더가 아니라 **검색 방식**이 바뀌어 대조가 오염된다.

**계열을 다르게 고른 것이 두 모델을 쓰는 이유다.** 같은 계열 둘은 같은 실패를 공유하므로 반론
표면을 줄이지 못한다.

**개발셋 성능으로 모델을 고르지 않는다.** 후보를 여럿 돌려 본 뒤 좋은 것만 싣는 것이 §1-2 가
금지하는 선택이다. **두 모델은 이 커밋에서 고정되고, 둘 다 전량 보고된다**(§0.2).

### 3.3 로컬 실행 제약 (🔒)

- **직렬 실행.** 인코딩 워커는 **1**이다. 두 모델을 **동시에 상주시키지 않는다**

  벡터가 같은 키를 공유하여 조용히 섞인다.

## 4. 판정·선정 규칙 (🔒 3단계 승인과 함께 동결)

### 4.1 지표

주지표는 **family-level Recall@100**, 신뢰구간은 **질의 단위 paired bootstrap 10,000회**이며, 보조
지표는 **nDCG@20** 과 **정답 언어별 회수**다. 이 실험은 어떤 임계에 대해서도 통과·실패를 선언하지
않는다(§1.1).

### 4.2 B★ 선정 규칙 — 개발 분할로만, 동점 처리까지 사전 지정

> **B★ = argmax over {B7, B9} of family Recall@100 on dev(197질의).**
> **|ΔR@100| < 0.005 이면 B7(BGE-M3)을 택한다** — 동점에서의 임의 선택을 막기 위한 사전 우선순위이며,
> 근거는 두 모델 가운데 공개 다국어 검색 벤치마크 이력이 더 길다는 사실이다.

**test·test_b 는 선정에 사용하지 않는다.** 개봉된 분할로 본문 구성을 고르는 것은 사후 조정이다.
가중치를 개발셋에서만 고른 P1 의 규율(§3.4)과 같은 규칙을 적용한다.

### 4.3 보수 보고 규칙 (§8.2 와 짝)

**test·test_b 에서 B7 과 B9 가운데 더 강한 쪽**을 `B_max` 라 하고, 온톨로지 이득은 **B★ 대비와
`B_max` 대비를 함께** 적는다. 둘이 다르면 **`B_max` 대비 값을 앞에 쓴다.** 이 규칙은 이득을 크게
보이게 하는 방향이 아니라 **작게** 보이게 하는 방향이므로, 결과를 본 뒤 유리하게 쓸 여지가 없다.

### 8.1 본문에 쓸 문장 (표 7 의 2행 + 아래 형식)

> 다국어 기준선(B★)에서도 부차 구성의 깊은 회수 이득은 **부호가 유지되었다 / 유지되지 않았다.**

**어느 쪽이 나오든 이 형식으로 쓰고, 그대로 싣는다**(§1-2). 결과가 불리하여도 마찬가지다 —
이 실험은 우리 결과를 방어하려는 것이 아니라 **기준선이 정당한지 확인하려는 것**이다.

### 8.2 결과 유형별 허용 문장 (§0.8 문구 사전 준수)

| 관측 | **허용** | **금지** |
|---|---|---|
| B★ > B3 (기준선이 더 강함) | "다국어 인코더로 융합한 기준선이 더 강하며, 본 논문의 이득은 그 기준선 대비 재평가되어야 한다" | 기존 §6 판정의 소급 수정 |
| B★ ≈ B3 | "인코더 교체로 기준선 강도가 유의하게 변하지 않았다" | "다국어 기준선이 불필요함이 입증되었다" |
| 두 인코더의 결과가 갈림 | "두 다국어 인코더에서 결과가 갈렸다"(양쪽 수치를 함께) | 강한 쪽만 인용 · 약한 쪽의 사후 탈락 |

| 외국어 회수 개선 | "다국어 인코더가 외국어 정답을 회수한다(하위풀 기저율과 함께 해석)" | **기저율 없는 단독 인용** |

**어느 경우에도 H3·H5·T1–T4 의 판정 기록은 바뀌지 않는다.** 본 실험은 별도 사전등록 아래의
탐색적 점검이며, 기존 판정은 각자의 사전등록 기록으로 남는다(§1-3).

### 8.3 후보 풀 편향의 필수 통제

**영어 문서의 72.5%, 일본어 문서의 70.9%가 정답이다**(원고 §6.4.4). 외국어 하위풀에는 방해 문서가
희소하므로 **거기서는 어떤 검색기든 좋아 보인다.** 따라서 언어별 회수는 **반드시**

1. 해당 하위풀의 **정답 기저율**과 나란히 보고하고,
2. **무작위 선택 참조선**을 함께 제시한다.

**이 둘 없이 언어별 회수를 단독 인용하는 것은 본 사전등록 위반으로 다룬다.** 통제 없는 인용은
통계적 착시를 성능 개선으로 보고하는 것이 된다.

| 두 모델 중 하나가 로컬에서 뜨지 않음 | 뜨는 쪽만 실행하고 **다른 쪽은 미실행으로 명시**한다. 대체 모델을 즉석에서 고르지 않는다 |
| B6·B8 결정성 위반 | 원인 규명 전까지 결과를 쓰지 않는다 |
| B★ 이 B3 보다 **강함** | 그대로 보고하고 §8.2 의 해당 행 문장을 쓴다. **기존 판정은 수정하지 않는다** |
| 두 인코더의 결론이 **갈림** | 갈렸다고 적는다. 강한 쪽으로 서술을 정리하지 않는다 |
| P1′ 이득 **소멸** | 그대로 보고한다. 이 논문의 결론은 *"이득은 조건부이며 경계가 있다"* 이므로 **논지와 모순되지 않는다** |
| 외국어 회수가 여전히 0 | §6.4.4 의 *"설계의 귀결"* 해석이 **강화된다.** 그대로 보고한다 |

**마지막 세 행이 이 사전등록의 요점이다.** 이 논문의 논지는 층 사이의 지표 불일치와 이득의 경계이지
"온톨로지가 검색을 개선한다"가 아니므로, **불리한 결과도 논지를 훼손하지 않는다.** 그것이 결과를
보기 전에 보고 문장을 고정할 수 있는 이유다.
