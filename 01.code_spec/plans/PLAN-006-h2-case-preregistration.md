# PLAN-006 · H2 검정 — 사례 사전등록과 조기탐지 시차

*상태: **승인 대기(설계까지 합의됨 · 구현 미착수)** · 작성 2026-07-13 · 지지 대상: RQ2 / H2 (논문 §3.4.4 · §4.4)*

> 새 세션은 이 문서만 읽고 H2 구현에 들어갈 수 있다. 전제(개념 시계열·대조군)는 PLAN-004 에서
> 이미 동결됐고, 이 문서는 **사례 수를 3 → 7 로 늘리는 사전등록**과 검정 설계를 담는다.

---

## 왜 이 계획이 필요한가 — K=3 으로는 검정이 불가능하다

논문 §3.4.4 는 탐지 시차를 "대응표본 검정"으로 비교한다고 쓴다. 그런데 PLAN-004 가 동결한
사례는 HBM·GAA·FinFET **3건**뿐이고, 단측 부호검정은 **3/3 전부 개념이 앞서도 p = 0.125** 다 —
α=0.05 에 **구조적으로 도달할 수 없다.** 결과를 보기 전에 이미 정해진 사실이다.

따라서 두 갈래뿐이다: (a) K=3 을 유지하고 H2 를 사례 기술(descriptive)로만 보고하거나,
(b) **시계열을 보기 전에** 사례를 사전등록으로 확장하거나. 사용자 결정(2026-07-13): **(b)**.

사전등록이 정당한 이유: 아직 어떤 개념·코드 시계열도 계산하지 않았다. 사례 선정은 우리 데이터
분포가 아니라 **SDKB 어휘 + CPC 2026.01 스킴 원문 + 외부 부상 근거**만으로 이루어진다.

---

## 사례 선정 기준 (a priori · 결과 무관)

1. **개념이 SDKB 에 실재한다** (Device 34 ∪ Process 49). 새 어휘를 만들지 않는다 (CLAUDE.md §1.4).
2. **부상이 사후적으로 확인된다** — 외부 근거(표준 제정·양산 발표)로 2010년 이후 급부상.
3. **CPC 2026.01 스킴 원문이 기술명을 제목에 명시한 전용 단일 코드가 존재한다.**
   제목은 캐시된 스킴 HTML 직접 파싱본이다 (`mappings/PROVENANCE.md` 규율 — 요약 모델 경유 금지).
4. **두 출원인(삼성·SK하이닉스)의 포트폴리오 범위**(메모리·로직·패키징) 안이다.

## ⚠️ H2 의 구조적 비대칭 (H1 의 rank-biserial 문제와 같은 종류)

7건 중 **5건(GAA·FinFET·3D NAND·MRAM·TSV)은 대조 코드가 개념의 룰 안에 이미 들어 있다** —
개념 집합 ⊇ 코드 집합이므로 **개념이 코드보다 늦게 탐지되는 것이 구조적으로 불가능**하다.
HBM(룰 0건 · 조합 정의)과 FOWLP(대조 코드가 룰에 없음)만이 개념이 늦을 수도 있는 진짜 양방향 사례다.

숨기지 않는다. 두 가지로 대응한다.
1. 사례 표에 `subset_flag` 를 싣고, 부분집합 사례와 양방향 사례를 **나눠 보고**한다.
2. **§4.5 민감도에 "대조 코드를 개념 시계열에서 제거한 재검정"을 사전 규정**한다 —
   부분집합 관계가 결론을 만들지 않았음을 보이기 위해서다.

## 설계 (결과 보기 전 고정)

**말뭉치.** 수집 34,521건 **전체**. 두 시계열을 같은 행 위에서 계산한다.
G₁ 병합분 24,053건만 쓰면 대조 코드만 달린 미매핑 특허가 빠져 **코드 측이 불리해진다** — 그것은
H2 에 유리한 편향이다. 개념 시계열이 G₁ SPARQL 질의 결과와 일치함은 통합 테스트로 고정한다.

**신호 규칙.**
- 관측창 **2010–2023**. 2024–2025 는 18개월 비공개로 인한 **절단**이므로 탐지 판정에서 제외
  (2024: 3,884 → 2025: 423 은 출원 감소가 아니다). 그림에는 회색 음영으로 표시한다.
- 최초 탐지 연도 = `y(t) ≥ 3` **이고** `y(t) ≥ 2.0 × mean(y(t-3..t-1))` 인 최초의 t.
  직전 3년 평균이 0이면(무에서 출현) `y(t) ≥ 3` 만으로 충족. 후행창 확보를 위해 탐색은 **2013년부터**.
- 어느 해도 만족하지 않으면 **"탐지되지 않음"** — 우편향 절단으로 표기하고 임의의 큰 값으로
  대체하지 않는다 (논문 §3.4.4 의 사전 약속).
- 시차 L = (코드 탐지연도) − (개념 탐지연도). 양수 = 개념이 앞섬.

**판정 규칙 (사전).**
| 상황 | 처리 |
|---|---|
| 양쪽 미탐지 | 정보 없는 쌍 → 부호검정에서 **제외** (사례 표에는 남긴다) |
| 코드만 미탐지 | 개념 승 (우편향 절단, `lead ≥ 2023 − concept_year`) |
| 개념만 미탐지 | 코드 승 |
| 동률(같은 해) | 동점 → 부호검정에서 제외 (H1 의 Wilcoxon 동점 처리와 같은 규약) |

주 분석: `base` 변이 · θ=2.0 · n_min=3. 검정: 단측 정확 부호검정(`scipy.stats.binomtest`, greater).

**검정력.** 7/7 이면 p = 0.0078. 동률·미탐지로 유효쌍이 4건 이하로 줄면 α=0.05 도달이 불가능해지며,
**그 경우 그대로 "검정력 부족"으로 보고한다** (결과를 만들지 않는다 — CLAUDE.md §1.2).

**민감도 (§4.5, 같은 코드로 산출).** θ ∈ {1.5, 2.0, 3.0} × n_min ∈ {1, 3, 5} · 조합 정의
strict/base/loose · 출원인 분리(삼성 / SK하이닉스) · **대조 코드 제거 재검정**.
