## 1. 목적 — 무엇을 해결하려 하는가

**이 벤치마크의 정답은 부분 정답이다.** 심사관은 거절에 필요한 만큼만 인용하므로, 상위 100건 가운데
인용되지 않은 문서가 관련 문헌인지 아닌지는 **관측된 적이 없다.** PLAN-055 는 그 미관측이 결론을
얼마나 흔드는지를 재어 **전복 문턱 n\*(LB₉₅) = 4**(확증 분할 A · `n*/U < .001`)를 얻었다. 필요는
제거되지 않았다.

**표준 해법은 전문가 판정이지만 규모가 성립하지 않는다(실측).**

| | 건수 |
|---|---:|
| 확증 분할 하나를 상위 100까지 전량 판정 | **19,800** (198질의 × 100) |
| 그중 한쪽 구성에만 있고 미판정 | 14,456 |
| 그중 정답 1~2건 질의에 속한 것(지렛대가 큰 자리) | **9,232** |

> **묻는 것 한 문장 — 사람을 부르지 않고 정답지의 결손을 줄일 수 있는가.**

**답의 착상은 하나다. 같은 발명을 다른 나라 심사관이 이미 읽었다.** 우리 정답은 KR 심사관 인용이고,
같은 DOCDB 가족의 US·EP·JP 대응 출원에는 **그쪽 심사관이 단 인용**이 따로 있다. 그것을 병합하면
정답지가 넓어진다.

### 1.1 왜 이것이 전문가 판정의 자리를 대신할 수 있는가

전문가 판정이 만족시키는 핵심 조건은 *"사람이 읽었다"* 가 아니라 **"우리 시스템과 무관하게
생성된 관련성 라벨"** 이다(PLAN-055 §2.1 외생성 논증). 타 관할 심사관 인용은 그 조건을 그대로
만족한다 — 본 연구의 어떤 시스템보다 먼저, 그와 무관하게 생성되었다.

**비용은 사람 시간이 아니라 조회다.** 배선도 이미 있다 — `collect/bq_family_ir.py` 가 DOCDB 가족
지도를 만들며, 질의 1,200 중 **1,006건(83.8 %)이 DOCDB 가족 식별자를 보유**한다(2026-08-18 실측 ·
`docdb-app` 1,006 · `fallback-self` 2 · 미매칭 192).

### 1.2 이 계획이 **하지 않는** 일 — 지위의 사전 확정

**기존 판정을 다시 쓰지 않는다.** 정답지가 바뀌면 그것은 **다른 벤치마크**다. 기존 qrel 위의
H3·H5·T1–T4 판정과 §5 의 모든 수치는 **각자의 사전등록 기록 그대로 남으며 재산출하지 않는다**
(§1-3). 병합 정답지 위의 결과는 **별도 사전등록 아래 별도의 표**로 서고, 두 정답지의 값을 한 표에
섞지 않는다.

**따라서 이 실험의 지위는 탐색적 강건성 점검이다.** 개봉된 분할 위에서 우월성을 다시 확증하는
것은 금지된다(§2.1 말미).

## 2. 무엇을 산출하는가 — 셋

### 2.1 A · 병합 가능성의 계량 (2단계에서 먼저 답할 것)

세 비율을 순서대로 센다. **앞의 것이 작으면 뒤는 볼 필요가 없다.**

| | 묻는 것 |
|---|---|
| **α** | 질의 가족에 **해외 멤버가 실재하는 비율** |
| **β** | 그 멤버에 **심사관 인용이 달린 비율** |
| **γ** | 그 인용 문헌이 **우리 후보 코퍼스 안에 있는 비율** |

**γ 가 결정적이다.** 후보 코퍼스에 없는 문서는 어떤 시스템도 회수할 수 없으므로, 정답에 넣으면
모든 시스템의 Recall 을 함께 떨어뜨릴 뿐 비교에 정보를 주지 않는다. 기존 qrel 이 같은 이유로
**고유 정답 2,321 → 노드 도달 2,211** 로 걸러진 것과 같은 규율이다(§8.4 분모 규율).

### 2.2 B · 병합 정답지의 산출과 그 성질

`qrel_family_merged` 를 **새 파일명으로** 만든다. 기존 `qrel_examiner.parquet`
(sha `10ab67f21cc1…`)는 **바이트 단위로 불변**이다.

병합 정답에 적용하는 필터는 기존 정답과 **완전히 동일**하다 — ① 시점 유효(공개일 < 질의 출원일
기준 cutoff) ② 질의 자신·동일 패밀리 배제 ③ 후보 코퍼스 도달성 ④ 금지 간선 마스킹(§1-4).
**하나라도 다르면 두 정답지가 비교 불가능해진다.**

### 2.3 C · 병합 전후의 짝지은 차이 대조

**이 실험의 답은 여기 한 줄에 있다.**

| 관측 | 뜻 |
|---|---|
| 병합 후에도 Δ 의 부호와 유의성이 유지 | 결론이 정답지 확장에 **견딘다** — 미판정 결손이 비교를 좌우하지 않았다는 **관측 증거** |
| 병합 후 Δ 가 소멸하거나 뒤집힘 | 결손이 실제로 비교를 좌우했다 — **PLAN-055 의 전복 문턱이 이론이 아니었음**이 확인된다 |

**어느 쪽이든 답이다.** 그래서 결과를 보기 전에 두 문장을 모두 고정할 수 있다.

### 3.1 왜 이것이 기존 판정을 바꿀 수 없는가 (구조적 보증)

- **기존 qrel 을 열지 않는다** — 읽기만 하고, 병합본은 **새 파일**이다.
- **run 을 다시 만들지 않는다** — 동결 run 위에서 채점만 다시 한다. 재검색·재색인·재임베딩 0건.
- **지표를 바꾸지 않는다** — family-level Recall@100 과 부트스트랩 절차가 그대로다.
- **두 정답지의 값을 한 표에 섞지 않는다**(§8.4 분모 규율의 확장).

## 5. 다음 단계에서 확인할 것 (2단계 분석 · 🛑 별도 승인)

**코드를 쓰기 전에 데이터를 먼저 본다**(§2 2단계). BigQuery 조회는 **dry-run 으로 스캔량을 먼저
보고**한다.

1. **α·β·γ** — §2.1. 특히 γ 가 낮으면 이 계획은 **여기서 종료**하고 그 사실을 결손 명세에 적는다.
2. 질의 미매칭 **192건**의 정체 — 가족 지도가 구 코퍼스(40,552행) 시점 산출물이라 신규 문서
   (B층 479건)를 담지 못한 것인지, 실제로 가족이 없는 것인지.
3. 병합 라벨과 기존 라벨의 **중복률** — 이미 아는 것을 다시 넣으면 결손이 줄지 않는다.
4. 병합이 **질의별로 고르게 분포하는지** — 소수 질의에 몰리면 그 질의들이 결과를 지배한다.
5. **시점 유효 위반 후보** — 타 관할 인용은 KR 출원보다 늦게 달릴 수 있으나, 판정 기준은
   **인용 문헌의 공개일**이다. 이 구분을 코드가 아니라 문서로 먼저 못 박는다.

## 6. 비목표

1. **기존 판정의 수정** — H3·H5·T1–T4 는 각자의 사전등록 기록 그대로다.
2. **전문가 판정의 대체 주장** — 이 방법은 결손을 **줄이는** 것이지 *"인용되지 않음 = 관련 없음"* 을
   얻지 못한다. **양성 전용이라는 성질은 그대로 남는다.**
3. **출원인 인용의 병합** — 심사관 인용과 생성 주체가 다르므로 이번 범위 밖이다.
4. **LLM 판정자 도입** — 하지 않는다(§1-11).
5. **새 검색 실행** — 동결 run 위에서 채점만 다시 한다.
6. **기존 표의 재산출** — 0건.

## 8. 이 계획이 성공해도 남는 것 (정직한 기록)

| 남는 것 | 이유 |
|---|---|
| **양성 전용** 성질 | 타 관할 인용도 "인용된 것"만 말한다 |
| nDCG 의 **이진 이득** | 등급 판정이 아니므로 해소되지 않는다 |
| 상위 미인용 후보의 **실제 관련성 미관측** | 줄어들 뿐 사라지지 않는다 |

**바뀌는 것은 결손의 크기이지 종류가 아니다.** 그래서 결손 ⑧ 은 **삭제되지 않고 상태가 갱신된다** —
*"미수행"* 에서 *"외생 라벨로 부분 축소 · 잔여는 표본 판정 필요"* 로.
