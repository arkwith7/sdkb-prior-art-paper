| | |
|---|---|
| 대상 | 개념 도식 `src/sdkb_paper/viz/concept.py` 7장 + 데이터 플롯 `ir_metrics.svg` · 그 캡션이 실리는 산문 소스 `paper/manuscript/stage3_source.md`(국문)·영문 파생본 · 규격 [paper/FIGURE-SPEC.md](../../paper/FIGURE-SPEC.md) |

| 상태 | **요구정의 · 승인 대기 (2026-09-04)** |

> **결론 먼저.** 그림은 여덟 장이고 그 가운데 넷(1·3·4·5)이 설정 도해다. 반면 이 논문에서
> 가장 강한 사실 — **형식 검증 네 층을 전부 통과한 변경이 태스크 조건 하나에서 거부되었다** —
> 은 자기 그림을 갖지 못한 채 그림 4의 오른쪽 열, 그림 6의 한 행, 그림 7에 흩어져 있다.
> 기여 셋 가운데 **교훈 셋(기여 ③)에는 도판이 하나도 없다**(§6 전체의 그림 0). 그래서 그림만
> 이어 읽으면 *"무엇을 만들었고 어떻게 쟀는가"*까지는 읽히지만 *"그래서 무엇이 관측되었고
> 무엇을 배웠는가"*가 읽히지 않는다. **처방은 도판을 늘리는 것이 아니라 담당 주장을 재배정하는
> 것이며, 판정과 수치는 한 글자도 바뀌지 않는다.**

## 1. 진단 — 실측

### 1.1 그림만 읽는 경로에서 무엇이 빠지는가

캡션 첫 문장만 이어 읽은 결과(`paper/SKIM.md` · 파생본 기준).

| 그림 | 캡션 첫 문장이 진술하는 것 | 성격 |
|---|---|---|
| 1 | 거절특허 한 건의 사실이 세 태스크가 공유하는 노드에 모인다 | 구조 |
| 2 | 자원 층의 지표가 2.4배로 향상되는 동안 검색 지표는 저하되었다 | **관측** |
| 3 | 세 태스크 뷰는 같은 공정 노드를 서로 다른 술어로 지나는 질의 경로다 | 구조 |
| 4 | 형식 검증 네 층을 통과한 변경도 태스크 조건에서 멈춘다 | 절차 |
| 5 | 질의 특허 자신의 인용 간선을 제거한 뒤 남는 신호만으로 정렬한다 | 방법 |
| 6 | 다섯 에피소드는 승인식의 서로 다른 항을 검증한다 | 지도 |
| 7 | 검색 이득은 깊은 회수에 한정되었다 | **관측** |
| 8 | 교차 태스크 조건은 형식 층이 놓친 결함을 단독 검출하였다 | 경계 |

**설정 넷(1·3·4·5) 대 관측 둘(2·7)** 이다. 기여와 대조하면 결손이 두 자리에서 드러난다.

| 기여(CLAUDE.md §0.5) | 담당 도판 |
|---|---|
| ① 산출물 — SDKB 와 릴리스 게이트 | 그림 1·3·4 (**셋**) |
| ② **통제된 거부 사례 1건**(존재 증명) | **없음** — 그림 4의 한 열 · 그림 6의 한 행에 분산 |
| ③ **교훈 셋** | **없음** — §6 의 그림 0 |

`paper/SKIM.md` 실측으로 **§6(논의와 교훈) 전체에 그림이 0장**이고, 존재 증명을 서술하는
**§5.2 에는 자기 그림이 없다**(그림 6·7의 재참조로 K1 을 통과한다).

### 1.2 지면 기준 글자 크기 — 규격 F2 가 소스에서만 지켜지고 있다

규격 F2 는 *"라벨 8pt 미만을 쓰지 않는다"*로 정한다. 그런데 캔버스는 11인치이고 지면 폭은
6.5–7.5인치이므로 **축소율 약 0.6이 곱해진다.** 소스에서 8pt인 라벨은 지면에서 4.8pt다.

| 그림 | 8pt 미만 라벨 / 전체 |
|---|---|
| 6 에피소드 매트릭스 | **35 / 78** |
| 1 개요도 | **13 / 39** |
| 3 T-Box 뷰 | **13 / 27** |
| 2 층간 불일치 | 3 / 24 |
| 5 실무↔실험 | 2 / 26 |
| 8 검출·이식 경계 | 2 / 18 |
| 4 승인 절차 | 1 / 26 |
| 7 시스템×지표 (데이터 플롯) | **0 / 35** |

**데이터 플롯만 규격을 지킨다.** 개념 도식이 어기는 이유는 글꼴 선택이 아니라 **칸당
정보량**이며, 그래서 글자를 키우는 것으로는 해결되지 않는다 — 담을 것을 줄여야 한다.

### 1.3 도판을 줄일 때의 제약

`skim_outline.py` 의 **K1** 은 §3–§5 의 모든 `##` 절에 그림·예시·명시적 재참조가 하나
이상 있을 것을 요구한다. 그림 참조 분포 실측은 아래와 같다.

| 그림 | 참조 절 수 | 절 |
|---|---|---|
| 5 | 4 | §3.6 · §4 · §4.1 · §4.3 |
| 3 | 3 | §3.1 · §3.2 · §3.3 |
| 6 | 3 | §4.5 · §5 · §5.1 |
| 8 | 3 | §4.6 · §5.4 · §5.5 |
| 1·2·4·7 | 각 2 | — |

**그러므로 도판을 단순히 삭제할 수 없다.** 없애면 그 절의 시각 장치가 사라져 K1 이 깨진다.
줄이려면 **병합**이어야 하고, 병합된 도판은 두 절 모두에서 재참조되어야 한다.

## 2. 요구정의

**목적.** 그림 캡션만 이어 읽어도 ⓐ 논지 ⓑ 기여 셋 ⓒ 주요 발견이 읽히게 한다.
대응 주장은 **C4(설계지식)와 C2·C3의 전달**이며, 산출물은 원고의 도판과 캡션이다.

**성공기준 (검정 가능).**

- **G1** 그림 캡션 첫 문장만 이은 목록에 기여 셋이 **각각 하나 이상** 대응한다 — 기계 검사.
- **G2** 본문 그림이 D5 상한(4–8) 안이고 `submission-check` 가 통과한다.
- **G3** 개념 도식의 8pt 미만 라벨이 **0** 이다(소스 기준 13pt 하한 = 지면 8pt).
- **G4** `skim_outline.py --check` 의 K1–K3 가 통과한다(재편으로 깨지지 않는다).
- **G5** 국문판 도판의 상자 겹침 0 · 캔버스 이탈 0 이 유지된다(커밋 `a388da3` 의 상태).
- **G6** `verdicts` · `crossref-check`(X2·X3·X5) · `claims-check` 전량 통과.

**비목표.** 새 수치의 산출 · 새 실험 · 판정 변경 · 데이터 플롯(`ir_*.svg`)의 재설계 ·
투고처를 전제한 규격 도입.

## 3. 설계 — 두 안

### 안 A · 담당 주장 재배정 (7장 · **권고**)

| | 담당 주장 | 재료 | 기여 |
|---|---|---|---|
| F1 | 공유 T-Box 하나에 세 뷰가 걸려 있고 자원은 계속 갱신된다 — **그래서 변경이 위험하다** | 구 그림 1 위 띠 + 구 그림 3 **병합** | ① |
| F2 | 자원 층과 검색 층의 지표가 어긋난다 | 구 그림 2 | 발견 |
| F3 | 승인은 형식 검증이 아니라 **한 층 아래 태스크 조건**이 낸다 | 구 그림 4 | ① |
| F4 | 평가는 실무 절차를 모사하며 **대응이 없는 자리 둘**을 드러낸다 | 구 그림 5 | 방법 |
| F5 | **존재 증명** — 자원 지표는 2.4배 올랐고 형식 검증 네 층을 전부 통과했으며 태스크 조건이 거부하였다 | **신설** — 구 그림 6의 EP3 행 + 구 그림 4의 판정 열을 한 장으로 | ② |
| F6 | 다섯 에피소드가 승인식의 어느 항을 검증했고 판정이 무엇인가 | 구 그림 6 (EP3 열 정리 · 밀도 감축) | 지도 |
| F7 | 검색 이득은 깊은 회수에 한정되었다 | 구 그림 7 (데이터 플롯 · 불변) | 발견 |
| F8 | 이전된 것은 기제이고 명세는 재접지가 필요하다 — **교훈 셋** | 구 그림 8 + 교훈 띠 | ③ |

여덟이지만 **구 그림 1·3의 병합으로 한 장이 빠지고 존재 증명 한 장이 들어온다** — 순
증감은 0 이며 D5 상한 안이다. K1 은 병합 도판을 §3.1–§3.3 에서 재참조하여 유지한다.

**왜 이 배정인가.** 지금 설정 도해가 넷인데 그중 그림 1과 그림 3은 **같은 것을 두 번
그린다** — 그림 1의 위 띠가 이미 세 태스크 뷰와 공유 코어 어휘를 담고 있다. 그 중복을
없애면 존재 증명 한 장이 들어올 자리가 생긴다.

### 안 B · 캡션과 재배치만 (8장 유지)

도판 구성을 그대로 두고 캡션 첫 문장을 전부 판정문으로 통일한다. 비용이 작고 위험이
낮으나 **기여 ②·③의 도판 결손은 남는다** — G1 을 충족하지 못한다.

**권고는 안 A다.** 안 B 는 §1.1 이 진단한 결손을 그대로 두므로 목적을 달성하지 못한다.

## 5. 검사기 — 그림만 읽는 경로를 기계가 본다

`scripts/skim_outline.py` 에 **K4** 를 신설한다.

- **K4** 그림 캡션 첫 문장만 모은 목록이 기여 셋에 **각각 하나 이상** 대응한다. 대응은
  캡션 안의 표지 낱말이 아니라 **`paper/figures-claims.yaml` 의 명시적 선언**으로 판정한다
  — 캡션 문구를 정규식으로 추측하면 문구가 바뀔 때마다 검사가 거짓 통과한다.
- 실행 형태는 `--figures-only` 로, 캡션만 이은 목록을 표준출력에 낸다. **사람이 그
  목록을 읽고 논지가 서는지 보는 것이 최종 판정이며, 기계는 결손만 잡는다.**
- **경고 모드로 시작한다** — 착수 시점의 위반이 0 이 아니다(기여 ②·③ 대응 도판 없음).
  차단 승격 조건은 G1 실측 0 이며, 그때까지 *"그림 경로 검사 통과"*를 근거로 쓰지 않는다.

## 6. 실행 순서와 DoD

1. **규격 먼저**(요건 5) — FIGURE-SPEC 의 로드맵 표와 F2 의 지면 기준을 고친다.
2. `figures-claims.yaml` 신설 + `skim_outline.py` K4(경고).
3. F1 병합 · F5 신설 · F6 밀도 감축 · F8 교훈 띠 — **`concept_values.json` 은 읽기만 한다.**
4. 캡션 첫 문장을 판정문으로 통일 — **§0.8 문구 사전을 그대로 따른다**(예: F7 은
   *"전달되지 않았다"*가 아니라 *"비열등 기준을 충족하지 못하였다"*).
