## 1. 왜 했는가

원고가 §3.2·§4.5 에서 **패밀리 중복 제거를 약속했으나 실제로는 수행하지 않았다.** 한 발명이
여러 출원(국내 중복·분할)으로 말뭉치에 중복 계상되면 H1 의 커버리지·H2′ 의 시계열이 부풀 수 있다.
약속을 이행하고, 결론이 그것에 의존하는지 점검한다.

## 2. 무엇을 했는가

- BigQuery `patents.publications` 로 KR 출원 **64,936건**(델타 34,521 ∪ 2005–09 29,415 ∪ G₀ 1,000)의
  `family_id` 를 조회. 조인율 **63,679 / 64,936 = 98.1%** (`raw/bigquery/family_map.parquet`).
- **한 출원에 `family_id` 가 둘 붙는 경우 9.6%(6,119건)** — 공유 id 로 이어지는 출원을 **연결성분**으로
  묶어 같은 발명이 두 패밀리로 쪼개지는 것을 막았다 (`preprocess/family.py`).
- 패밀리당 대표 1건만 남기고 H1·H2′ 를 재검정.

## 3. 결과 — 결론 전부 불변

- **패밀리당 말뭉치 출원 평균 1.00건** (KR 단일 관할이라 대부분 자기 패밀리의 유일한 KR 구성원).
- dedup 이 지운 것: 델타 34,521 중 **178건(0.52%)**, H2′ 유니온 63,936 중 **198건(0.31%)**.
- **H1·H2′ 의 결론은 하나도 바뀌지 않았다.** dedup 이 불필요하다는 뜻이 아니라, **해봤더니 결론이
  그것에 의존하지 않더라**는 뜻이다.
