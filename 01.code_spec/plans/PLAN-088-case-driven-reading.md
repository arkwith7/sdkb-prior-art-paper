**이 사례가 말하지 않는 것**.

### C · 한 사례 환산을 병기한다
같은 생성기가 산출한다. `ΔR@100 = −0.0293` → 두 팔 run 에서 센 질의 수 · `T3 단독 12/45` →
어느 태스크의 질의가 답을 잃는가. **판정 문구는 그대로 두고 환산을 옆에 붙인다.**
