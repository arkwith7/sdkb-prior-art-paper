## 1. 목적 — 어느 주장을 지지하는가

**C2.** 이 논문의 검색 비교는 **양성 전용 정답**(심사관 인용) 위에 서 있다. 외부 검토가 지적한
*"전문가 관련성 판정이 미수행"* 은 이 성질을 겨눈 것이다.

**본 계획은 판정을 수행하여 결손을 메우지 않는다. 판정이 필요한지를 먼저 묻는다.**

> **묻는 것 한 문장 — 짝지은 비교의 결론이 미판정 문헌의 관련성에 의존하는가.**

의존하지 않음을 보이면 판정은 결손이 아니라 **범위의 명세**가 되고, 의존함이 드러나면 그것은
정직한 한계로 남는다. **어느 쪽이든 사람 판정자를 부르지 않는다.**

### 1.1 왜 지금 다시 설계하는가 — 앞선 판의 오류를 먼저 고친다

이 계획의 초기 구상은 *"구성별 상위 K 의 **미판정 비율**을 비교한다"* 였다. **그 통계는 퇴화한다.**
정답이 양성 전용이고 판정된 비적합 집합이 없으므로, 상위 K 의 미판정 비율은

```
unjudged@K = 1 − Precision@K
```

로 **정확히 항등**이다. 즉 새 정보가 아니라 정밀도를 다르게 부른 것뿐이다. **이 항등을 모른 채
"대칭성을 확인했다"고 적으면 아무것도 확인하지 않고 확인했다고 적는 것이 된다.**

같은 이유로 `bpref` 도 쓰지 않는다 — 판정 비적합 집합이 없어 고전적 정의가 성립하지 않는다
(CLAUDE.md §0.8 이 이미 삭제 또는 개명을 지시).

**그래서 아래 §2 는 다른 세 가지를 잰다.**

## 2. 무엇을 산출하는가 — 셋

### 2.1 A · 정답 집합의 **외생성** (계산이 아니라 논증)

**정보검색에서 정답 불완전성이 비교를 편향시키는 표준 기제는 풀 편향(pool bias)이다** — 정답이
비교 대상 시스템들의 상위 결과를 모아 판정해 만들어지면, 풀에 기여하지 않은 시스템이 구조적으로
불리해진다.

**본 벤치마크에는 그 기제가 원리적으로 존재하지 않는다.** 정답은 **심사관 인용**이며,
특허 심사 과정에서 **본 연구의 어떤 시스템보다 먼저, 그와 무관하게** 생성되었다. 풀링 판정이
아니므로 정답 집합은 구성에 대해 **외생적**이다.

**따라서 결손이 구성과 상관될 경로는 하나로 좁혀진다** — 구성들이 서로 **다른 종류**의 문헌을 상위에
올리고, 그 종류에 대한 **심사관의 인용 성향이 다를 때**. 이것이 남은 유일한 위협이며 §2.2 가 잰다.

> **이 절의 산출물은 문장이지 수치가 아니다.** 원고 §2.1·§8.2 에 들어간다. 논증을 수치인 것처럼
> 적지 않는다.

### 2.2 B · 잔여 위협의 계량 — 상위 미판정 집합의 **조성 대조**

각 구성이 상위 K 에 올린 **미판정 문서들이 서로 같은 종류인가**를 잰다. 종류가 같으면 §2.1 이
남긴 경로가 좁아지고, 다르면 그 축을 이름으로 지목할 수 있다.

| 축 | 왜 이 축인가 | 재사용 |
|---|---|---|
| **언어** (한/영/일) | 영어 정답 334건 중 0건 회수라는 기존 관측이 정확히 이 축에 있다 | [`analysis/lang_recall.py`](../../src/sdkb_paper/analysis/lang_recall.py) |
| **공개 연도** | 인용 성향의 시대 편차 | 코퍼스 메타 |
| **CPC/IPC 주분류** | 분류 밀집이 실패 유형 코딩에서 최빈이었다 | 코퍼스 메타 |
| **개념 링크 보유** | 온톨로지 구성의 가시성 축 그 자체 | 코퍼스 메타 |

**대조 대상 구성:** B3 ↔ P1 (주 비교) · 승인 시 B3 ↔ P0★.
**보고:** 축별 분포와 차이. **가설검정을 붙이지 않는다** — 기술통계이며, 검정을 붙이면 새 확증
주장이 생긴다.

**해석 규칙을 미리 고정한다.**

| 관측 | 허용 | 금지 |
|---|---|---|
| 축 전반에서 조성이 유사 | "상위 미판정 집합의 조성은 두 구성에서 유사하며, 종류 상관 결손의 여지가 좁다" | "정답 불완전성이 비교에 영향을 주지 않음이 입증되었다" |
| 특정 축에서 조성이 상이 | "○○ 축에서 두 구성의 미판정 조성이 다르며, 이 축은 잔여 위협으로 남는다" | 그 축을 근거로 기존 판정을 수정 |

### 2.3 C · **판정 전복 문턱** — 결론의 취약도를 한 수로

> **묻는 것:** 지금 미판정인 문헌 가운데 **몇 건이 실제로 관련 문헌이면서 한쪽 구성에만 유리하게
> 분포해야** 이 비교의 결론이 뒤집히는가.

**정의 (family-level Recall@100 기준 · 최악 배치).**
질의 \(q\) 의 정답 패밀리 수를 \(R_q\), 구성 \(a\) 가 상위 100 에서 회수한 정답 패밀리 수를
\(r_{q,a}\) 라 하면 \(Recall_{q,a} = r_{q,a}/R_q\) 이다. 여기에 **P1 에 최대로 불리한** 방식으로
미판정 패밀리를 정답으로 추가한다 — 즉 **B3 의 상위 100 에는 있고 P1 의 상위 100 에는 없는**
패밀리만 추가한다. 한 건 추가할 때마다

- \(R_q \mathbin{+}= 1\) (두 구성 공통으로 분모 증가)
- \(r_{q,B3} \mathbin{+}= 1\) · \(r_{q,P1}\) 불변

이 되어 짝지은 차이가 단조 감소한다. **전복 문턱 \(n^\*\)** 는 사전 지정 판정량(부트스트랩 95 %
신뢰구간 하한, 그리고 별도로 점추정)이 0 에 도달하는 **최소 추가 건수**다.

**함께 보고하는 상대량:** \(n^\* / U\). 여기서 \(U\) 는 그러한 적대적 추가가 실제로 가능한
후보 수(= B3 상위 100 에는 있고 P1 상위 100 에는 없는 미판정 패밀리의 총수)다. **절대 건수만
보고하지 않는다** — 분모 없이는 크고 작음을 말할 수 없다.

**가정을 명시한다(§8 보고 방식).**
① 추가된 패밀리가 기존 정답과 같은 단위로 센다. ② 적대적 배치는 **최악의 경우**이며 실제 분포의
추정이 아니다. ③ 따라서 \(n^\*\) 는 *"이만큼 견딘다"* 의 **하한**이지 확률 진술이 아니다.

**해석 규칙 (결과 보기 전 고정).**

| 관측 | 허용 |
|---|---|
| \(n^\*\) 가 크고 \(n^\*/U\) 가 높다 | "결론을 뒤집으려면 미판정 문헌 중 상당수가 한쪽 구성에만 유리하게 관련 문헌이어야 한다" |
| \(n^\*\) 가 작다 | "결론은 미판정 문헌의 소수 조성에 취약하며, 이는 표본 판정 없이는 해소되지 않는다" |

**금지:** \(n^\*\) 를 근거로 *"효과가 확실하다"* 로 이동하는 것(§0.3 의 다섯 조건은 그대로다).

### 3.1 왜 이것이 판정을 바꿀 수 없는가 (구조적 보증)

- **읽기 전용이다.** run·qrel·코퍼스를 **읽기만** 한다. 재검색·재색인·재임베딩 0건.
- **지표를 바꾸지 않는다.** family-level Recall@100 의 정의도, 부트스트랩 절차도 그대로다.
- **임계를 만들지 않는다.** \(n^\*\) 에 합격선을 두지 않는다. 문턱을 두는 순간 새 판정이 생긴다.
- **봉인 개봉 0회.** 이미 개봉된 분할의 이미 산출된 run 만 쓴다.

**그러므로 이 산출물은 어떤 가설의 지지·기각도 진술할 수 없다.** 지위는 **탐색적 강건성 분석**이다.

## 5. 다음 단계에서 확인할 것 (2단계 분석 · 🛑 별도 승인)

**코드를 쓰기 전에 데이터를 먼저 본다**(§2 2단계).

1. `qrel_examiner` 의 패밀리 단위 집계가 `metrics._fold` 와 **정확히 같은 규칙**인가.
2. 코퍼스 메타에 네 축이 실제로 있는가 — **언어·연도·CPC 는 확인됐고, 개념 링크 보유 열은 미확인**.
   없으면 그 축은 **버린다.** 파생해 만들지 않는다.
3. \(U\)(적대적 추가 가능 후보 수)가 질의별로 얼마나 되는가 — 0 에 가까운 질의가 많으면
   \(n^\*\) 의 해석이 달라진다.
4. **자원 조건 확인** — 디스크 자원은 O′ 이고 원고 §6 은 O 조건이다. 본 분석은 **run 파일만** 읽으므로
   자원 조건의 영향을 받지 않지만, 읽는 run 이 원고 §6 을 산출한 그 run 인지 sha256 으로 확인한다.

## 8. 이 계획이 성공해도 남는 것 (정직한 기록)

| 남는 것 | 이유 |
|---|---|
| nDCG 의 **이진 이득** | 등급 판정이 없으므로 해소되지 않는다 |
| 상위 미인용 후보의 **실제 관련성 미관측** | 판정을 하지 않기로 한 결과다 |
| **절대 성능** 주장의 불가 | 이미 §0.3 이 금지하고 있다(현재 2/5 충족) |

**바뀌는 것은 이 미관측이 위협하는 주장의 범위가 한정된다는 점이다** — 절대 성능 주장은 위협받고,
짝지은 차이·게이트 판정·설계원리는 위협받지 않는다. 그리고 이 논문은 **절대 성능을 주장하지
않는다.** 그것이 사람 판정자를 부르지 않아도 되는 이유의 전부다.
