# PLAN-048 부속 A — CLAUDE.md 개정·재구조화 방안

> 원칙: **판정·수치·동결 사실은 한 글자도 건드리지 않는다.** 개정은 전부 (a) 투고 경로의 부재를
> 메우는 신설, (b) 원고 재구성과 규약의 충돌 해소, (c) 판정 규율의 기계화다. §2.2 요건 5에 따라

## 개정 1 — 서두 "정본 회귀" 블록에 투고 경로 1문단 추가 (충돌 해소)

현행 "투고본은 재실험 후 **v2.0**으로 새로 쓴다"는 문장이 파생 절차 없이 남아 있어, 투고 준비
작업이 규약상 근거를 갖지 못한다. 아래를 덧붙인다.

```
> **투고 파생 경로 (2026-08-10 · PLAN-048).** 작업 정본(v0.9 통합초안)은 감사 가능한 전체
> 기록으로 유지하고, 투고본은 `paper/submission/` 아래 **파생물**로 만든다. 파생은 PLAN-048
> 이동 대장에 따른 이관·축약·재조준만 허용하며, 수치 재산출과 판정 변경은 포함하지 않는다.
> 파생물과 정본의 판정 문구 정합은 `make verdicts`(§2.3)가 강제한다. 잘라낸 전문은 전부
> `paper/supplementary/`에 남아 링크로 도달 가능해야 한다.
```

## 개정 2 — §0.7 DRQ 표: DRQ3·DRQ4 통합, 결번 보존 (기조 정합)

DRQ3′로 통합하되 **DRQ4 라벨은 결번으로 보존**한다(재사용 금지 — RQ·S 라벨 규칙과 동일).

```
| DRQ3′ | 산출물 평가에서 어떤 효용·실패 경계·층간 지표 불일치가 관측되며, 거기서 어떤
  이전 가능한 설계원리가 도출되는가 (구 DRQ3+DRQ4 통합 · DRQ4는 결번 보존) | C2 · C2′ · C4 |
```

## 개정 3 — §0.7 DP 표에 "계층" 열 추가 (등급 불변 · 표기만 2계층)

DP1–DP4 = **코어 원리**(승인 게이트의 본체) · DP5–DP6 = **범위 원리**(적용 경계를 정하는 원리).
§0.6 등급(확립/제안)은 전량 불변 — 바뀌는 것은 본문 7장에서의 **싣는 자리**뿐이다(코어는 원리
절, 범위는 경계·후속 절). 이 구분이 없으면 원리 6개가 동열로 나열되어 검토①이 지적한 "겹침"
인상을 만든다.

## 개정 5 — §2.3 신설: 투고 준비 절차 (게이트 1개 + 기계 검증 2개)

```
## 2.3 투고 파생본 절차 — 정지 게이트 1개, 검증은 기계가 (2026-08-10 신설 · PLAN-048)

**게이트(1개):** PLAN-048 류의 마스터 계획(§2.2 요건 5종 포함)을 커밋·승인받은 뒤 파생을
시작한다. 이후 단계별 재승인은 요구하지 않는다 — 대신 아래 둘이 커밋마다 돈다.

1. **`make verdicts`** — paper/verdicts.yaml(판정 SSOT)과 정본·파생본의 판정 문구 정합 검사.
   위반 시 CI 실패. yaml 수정은 §1-2와 동급으로 다룬다(사용자 승인 필수).
2. **`make submission-check`** — 데스크 리젝 요인 검사: 플레이스홀더 0 · 영문 제목/초록 존재 ·
   본문 표/그림 상한 · 내부 링크 도달성 · 분량 목표. 규칙은 scripts/submission_check.py 에 코드로.

**이관은 삭제가 아니다** — supplementary 로 나간 전문은 파생본에서 링크로 도달 가능해야 하며,
링크 단절은 submission-check 가 실패시킨다.
```

## 개정 6 — §8.1에 투고본 서술 규칙 2행 추가 (감사보고서 톤 제거)

```
- **투고 파생본에서는** 사전등록·봉인·개봉·정정의 절차 서술을 Methods 1문단으로 한 번만 쓰고,
  이력·대장·원장 전문은 supplementary 참조로 대체한다(정직성은 반복이 아니라 도달 가능성으로).
- 독자 해석 통제형 메타 문장("섞어 읽지 않는다" 류)은 파생본에서 쓰지 않는다 — 절 구성이 그
  일을 하게 한다.
```

## 개정 7 — §7 산출물 대응에 EP 라벨 등록 (라벨 충돌 예방)

```
평가 에피소드 라벨 **EP1(표현 감사)·EP2(게이트 판별력)·EP3(통제된 자원 교체)·EP4(검색 효용과
경계)** 를 결과 장의 정식 이름공간으로 등록한다. `E1–E7`(PLAN-035 적격심사)·`EC`(외부 검토①
용례)와 구분하며, EP 번호는 재사용하지 않는다.
```
