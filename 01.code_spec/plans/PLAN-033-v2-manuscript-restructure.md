## 0. 결론 먼저 — 지금 하는 것은 "분량 재배분"이지 "결과 재해석"이 아니다

현재 정본은 **104,497자**(공백 제외)로 AEI 투고 분량의 약 2.3배다. 목표는 **45,700자(43.7 %·약 22쪽)**.
줄이는 방법은 결과를 지우는 것이 아니라 **축을 둘로 좁히고, 축 밖 결과의 지위를 강등**하는 것이다.

- **주장 축**: C1(공유 T-Box 자원) + C2(선행기술 검색 유용성) + 태스크 결합.
- **확증 가설 2개**: **H3**(하이브리드 효과) · **H5**(특이성 — 음성 대조군). RQ도 2개.
- **라벨은 바꾸지 않는다.** H3/H5는 PLAN-031이 "H3·H5 재확증"으로 사전등록한 이름이다. 여기서
  H1/H2로 번호를 다시 매기면 **사전등록 기록과의 추적성이 끊긴다.** 개수만 줄이고 이름은 그대로 둔다.
- **H1·H2·H4는 삭제가 아니라 지위 강등**이다 — 판정은 그대로 두고 싣는 자리와 분량만 바꾼다(§3.2).

**1단계(이 문서의 실행 범위)는 B층 재실험과 무관한 절감분**이다(§5). §6.2–6.4의 새 결과 반영은

## 3. 설계 — 축과 강등 (결과를 본 뒤 바꾸지 않는다)

### 3.1 확정된 축

- **RQ2 검색 유용성 → H3(하이브리드 효과)** = C2 의 핵심증명.
- **RQ3 계층 특이성 → H5(음성 대조군)** = C2·C3 경계, 그리고 **태스크 결합**의 근거.
- 이 둘이 **확증 가설의 전부**다. 나머지는 탐색적·설계 서술·한계로 배치된다.
- **번호 재부여 금지.** "H3·H5" 라는 이름은 PLAN-031 이 사전등록에 쓴 이름이므로 유지한다.
  §1.4 는 "확증 가설은 둘이며, 사전등록 라벨을 그대로 유지한다(H3·H5)"를 명시한다.

### 3.2 강등 대장 — 삭제가 아니라 지위 강등

| 가설 | 현재 지위 | 새 지위 | 이동처 |
|---|---|---|---|
| **H1** (게이트 판별력) | 확증 (4회차 재판정 · §6.5 10,921자) | **설계 + 홀드아웃 확증 1문단** | §4(설계) · §6.5(1,200자) · 4회차 과정 전량 → supplementary |
| **H2** (승인 안전성) | 확증 (실은 **미검정**) | **운용 사례** | §6 에서 사례 서술 · **T-Box 델타가 존재한 적 없다는 구조적 이유(D-12) → §9 한계 1문단** |
| **H4** (계층 기여) | 확증 (기각) | **ablation 표의 두 행** | §6.4 표의 A4/A5 행으로 흡수 |

**강등의 규율(중요).** 이것은 §1-2·§1-3 위반이 아니다 — 위반은 *판정을 바꾸는 것*이고, 여기서
바꾸는 것은 *싣는 자리와 분량*뿐이다. 따라서:

1. **기각은 기각으로 남는다.** H4 는 ablation 표에서도 "기각"으로 표기된다.
2. **H2 는 "확증"이라고 쓰지 않는다.** 현재 원고 §1.5-2 의 "안전성은 동결 테스트셋에서 지지되었고(H2)"
   는 **오기**다(CLAUDE.md §0 경계표 · STATUS §0: H2 는 미검정). 이 문장은 "게이트가 승인한 델타의
   운용 사례"로 정정하고, 미검정 사유를 §9 로 보낸다. **이는 판정의 완화가 아니라 과주장의 철회다.**
3. **삭제 검증**: 강등된 세 가설의 판정 문장이 원고에 남아 있는지 §7 의 체크로 확인한다.

### 3.3 용어 분리 — pin ≠ freeze

지금은 자원과 평가가 둘 다 "동결"이라 **데이터셋이 유물로 읽힌다.** 분리한다.

| 대상 | 용어 | 뜻 |
|---|---|---|
| SDKB 자원 (릴리스·스냅샷) | **릴리스 버전 고정(pin)** | 본 논문이 쓴 것은 릴리스 vX 의 커밋 SHA + sha256 스냅샷. **데이터셋은 이후에도 버전을 올려 개선된다** |
| 평가 (임계·분할·프로토콜) | **사전등록 동결(preregistration freeze)** | 개봉 전 고정 · 사후 변경 금지 |

원고 전역에서 자원 문맥의 "동결"을 "고정(pin)"으로 바꾼다. **평가 문맥의 "동결"은 건드리지 않는다.**

## 6. 2단계는 막혀 있다 — B층 코퍼스 시점 문제 (미결)

§6.2–6.4 를 B층 결과로 재작성하려면 **B층에서 H3 를 A층과 같은 의미로 잴 수 있어야** 한다.
현재는 그렇지 않다.

- PLAN-032 파일럿이 채택한 **B층 200건이 전부 2005-01-03 ~ 2005-02-28 출원**이다
  (PLAN-032 §8.4 · `data/profiles/ir_split_b_pilot.md` §3.3).
- §4.4 시점 유효성 마스크(공개일 < cutoff)를 적용하면 후보 풀이 **4,494건**으로 줄고,
  그중 **4,492 가 공개일 결측**이라 **연대가 확인된 방해문서는 2건**뿐이다.
- 즉 건초더미가 사라진다 — **이 상태의 R@100 은 A층의 R@100 과 같은 양이 아니다.**

**2단계 착수 전에 이 결정이 선행돼야 한다.** 1단계는 이것과 무관하게 진행한다.

## 8. 이 계획이 넘지 않는 선
