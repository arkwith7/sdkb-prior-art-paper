# 선택적 기업 사례 프로토콜 — 전문가 평가 보강안 (초안 · 미확정)

> **지위:** 선택 보강. **참여는 확정되지 않았다.** 기본 연구(PLAN-094)는 심사관 기록만으로 성립하며,
> 이 사례가 없어도 주장이 무너지지 않도록 설계한다. 이 문서는 참여가 성립할 때 바로 쓸 수 있게 미리 동결할
> 절차를 적는다.
> **비식별 원칙:** 기업 실명·성명·연락처는 이 저장소의 어떤 문서에도 적지 않는다. 사례 기업은 "A사",
> 평가자는 "평가자 1·2"로만 적는다.

## 1. 목적과 지위

- 심사관 인용이 **완전한 정답이 아니라는 한계**(미인용 관련 문헌 · 관점 차이)를 실무 관점에서 보완한다.
- 측정하는 것: 확보된 근거의 정확성·누락·요소 대비 적절성·후속 조사 필요성에 대한 **전문가 판단**.
- 측정하지 않는 것: 기업 의사결정 개선 · 시간 절감 · 법적 결론.
- 결과는 **사례 연구(보조 증거)** 로 싣고, 주 판정(PLAN-094)을 대체하거나 뒤집지 않는다.

## 2. 평가자 적합성

| 기준 | 최소 요건(사전 동결) |
|---|---|
| 기술 분야 | 평가 사례의 IPC 분야(반도체 공정·소자 등)에서 연구개발 또는 IP 실무 경력 |
| 경력 | 분야 경력 ≥ N년(수치는 섭외 전 동결) · 선행기술조사 수행 경험 |
| 독립성 | 평가 대상 출원의 발명자·대리인이 아님 |
| 인원 | **2인 이상**이면 κ·합의율 산출(§1-12). 1인이면 "단일 평가자 사례"로 표기하고 일반화하지 않음 |

적합성 판단 근거는 **분야·경력 범주**로만 기록한다(재식별 가능한 이력은 적지 않는다).

## 3. 사례 구성 — 파일럿과 본 사례의 분리

| 단계 | 자료 | 용도 | 결과 사용 |
|---|---|---|---|
| **파일럿** | **공개 특허** 3–5건(평가 집합과 불교차) | 평가 양식·소요 시간·지시문 점검 | 양식 수정에만 · 본문 수치로 쓰지 않음 |
| **본 사례** | (a) 공개 특허 기반 사례 N건 또는 (b) A사가 제공하는 기술대안 기술서(비공개) | 평가 | 사례 연구 결과 |

(b) 를 쓰는 경우: 자료는 A사 통제 하에 두고, 이 저장소에는 **식별자 해시·집계 점수만** 남긴다.

## 4. 평가 항목(척도는 파일럿 후 동결)

| 항목 | 질문 | 척도 |
|---|---|---|
| 근거 정확성 | 제시된 문헌이 해당 요소를 실제로 개시하는가 | 개시 / 부분 개시 / 비개시 |
| 누락 | 평가자가 알고 있거나 추가 검색으로 찾은 핵심 근거가 빠졌는가 | 누락 건수 + 중요도(상·중·하) |
| 요소 대비 | 요소–문헌 대응이 판단에 쓸 수 있는 수준인가 | 4점 |
| 후속 조사 필요성 | 이 결과로 검토를 종료할 수 있는가, 추가 조사가 필요한가 | 종료 가능 / 일부 추가 / 전면 재조사 |

## 5. 편향 통제

- **사전 동결:** 사례 선정 규칙(무작위 또는 층화) · 평가 항목·척도 · 집계 방식을 결과 전 커밋.
- **맹검:** 팔(A①–A④) 이름을 가리고, 팔 산출물을 무작위 순서로 제시(순서는 시드로 동결 · 평가자별 균형).
- **제시 순서 통제:** 심사관 인용을 먼저 보여주지 않는다. 독립 판정 → 그 다음 심사관 인용과 대조(2단계).
- 2인 이상이면 독립 평가 후 합의 단계를 분리 기록. κ < 0.4 이면 본문 제외 후 부록(§1-12).

## 6. 지위·이해관계 공개

- 평가자가 공동연구자 또는 공동저자 후보인 경우 **"공동연구자에 의한 평가"** 임을 본문에 명시한다.
- 이해관계(소속 기업의 기술 분야·경쟁 관계 등) 공개 문구를 결과와 함께 싣는다.
- **공동저자 여부는 실제 기여와 본인 동의로 정한다**(ICMJE 류 기준 · 평가 참여만으로 자동 부여하지 않음).

## 7. 비식별·자료 사용 범위

| 위험 | 점검 |
|---|---|
| 기업 실명 | 공개 문서·커밋·그림에 기재 금지 |
| 공개 특허번호에 의한 재식별 | 출원인이 A사인 공개 특허를 사례로 쓰면 특허번호로 기업이 드러난다 → 본문에는 번호 대신 사례 ID, 번호는 비공개 대장 |
| 공동저자 소속 × 기술 분야 | 저자 소속과 사례 분야 조합으로 기업이 추정될 수 있음 → 투고 전 재식별 점검 1회 |
| 비공개 기술서 | A사 통제 · 반출 금지 · LLM 외부 전송 여부는 A사 동의 범위로 한정 |

**동의서 항목(초안):** 자료 사용 목적 · 보관 위치·기간 · 공개 범위(집계만) · LLM 처리 여부 · 철회 방법 · 저자 표기.
IRB 해당 여부는 소속 기관 기준으로 사전 확인한다(개인 정보 수집이 없더라도 확인 기록을 남긴다).

## 8. 결과 제시

- 사례 표: 사례 ID · 팔 · 항목별 점수 · 평가자 간 일치.
- 주 판정과 어긋나는 사례를 우선 서술(§8 보고 방식).
- "전문가가 효과를 확인했다"가 아니라 "N건 사례에서 평가자 k인의 판단은 …"의 형태로만 쓴다.
