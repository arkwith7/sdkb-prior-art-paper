> **색인(SCIE/SSCI/ESCI)은 Clarivate Master Journal List 를 직접 열지 못했으므로 전부 2차 확인이다.** 최종 후보 확정 때

## 2. 경로 분기 — 같은 원고를 두 곳에 내지 않는다

| | IEEE-TEM 경로 | AEI 경로 |
|---|---|---|
| 중심 기여 | 전문가 판단 지식과 AI 의 결합이 조사 업무를 어떻게 바꾸는가(발견 · 적용 조건) | 명시적 판단 지식의 표현·제공 방식이 Agent 검색을 어떻게 바꾸는가(방법 · 기제) |
| 필수 증거 | 기제 설명 · Managerial Relevance · **사람의 업무 변화를 주장하려면** 참여자 평가(확인 시간 · 계획 타당성 · 사용 가능성) | 강한 기준선 · 로그 행동 지표 · 정량·정성 |
| 참여자 평가가 없으면 | 업무 변화 주장을 **빼고** 남은 증거(시스템 실험 + 기제)로 적합성 재평가 — 자동으로 AEI 로 가는 규칙은 없다 | 영향 없음 |
| 분량·형식 | 공식 투고 안내 **미확인** — 확정 시 `scripts/submission_check.py` 주석에 출처 | 〃 |
| 결정 시점 | PLAN-094 결과 + 전문가 참여 성립 여부 확인 후 | 〃 |

**조언에 있었으나 확인하지 못한 것.** "IEEE-TEM 은 기술 도구나 알고리즘 설명이 중심인 논문은 범위 밖이라고 명시" — 공식
