## 2. 델타 자격 — E7 은 "abox" 로 분류할 것이다 (실행 전 선언)

`runset.classify_delta` 는 **파일 sha256 만 본다.** `ABOX_FILE_MARKERS = ("abox-patents",
"abox-prior-art")` 가 둘 다 움직였으므로 분류는 **`abox`** 이고, `H2_ELIGIBLE_DELTA_TYPES =
("tbox", "concept")` 에 들지 않으므로 **E7 실격 · 종료코드 2 · 미검정**이 예상된다.

**그럼에도 이 실험은 성립한다 — 판정 대상이 H2 가 아니라 CR 검증기준 ⑥ 이기 때문이다.**
두 가지를 함께 적는다.

1. **E7 의 판정을 존중한다.** 이 실행으로 **H2 는 검정되지 않는다.** §0 C-표의 *"H2 미검정"*
   상태는 그대로다. 분류기의 규칙을 이 델타를 보고 고치지 않는다(§1-2).
2. **분류기가 가르지 못하는 것을 실측으로 밝힌다.** 두 A-Box 파일의 변화가 **문서집합·정답지의
   변화인지 개념 링크의 변화인지**를 P-4·P-5 가 잰다. 두 검사가 통과하면 *"바이트 기준으로는
   ③, 내용 기준으로는 ②"* 라고 적고, 통과하지 못하면 **③A-Box 오염으로 적고 ΔR₁₀₀ 비교를
   산출하지 않는다.**

### 2.3 미구분 선언 — 이 실험이 가르지 못하는 것

한 스냅샷에 **CR-001B(어휘 +14 표면형 · R7 상한)** 와 **CR-020(프로파일 배선)** 이 함께 들어왔다.
D-49 는 상류 구현에서 둘을 섞지 말라고 요구했고 그것은 지켜졌으나(CR 두 건 · 커밋 두 건),
**하류에는 하나의 스냅샷으로 도착한다.** 그러므로 ΔR₁₀₀ 이 어느 쪽에서 왔는지 이 실험은
**가르지 못한다** — 결과를 어느 방향으로 쓰든 **"미구분"** 을 함께 적는다(§1-12 둘째 금지 · DP4).

### 3.1 판정식

```
CR 기준 ⑥ = (ΔR₁₀₀(B5) > 0)  ∧  (LB₉₅(ΔR₁₀₀(P1)) > −ε)          # ε = 0.02

승인 규칙(적용은 하되 H2 로 읽지 않는다):
Accept(O→O′) = (L0 = L1 = L2 = L3 = pass)
             ∧ (LB₉₅(ΔR₁₀₀) > −ε)                       # T1
             ∧ (max_s drop_s < δ)                        # T2
             ∧ (∀f ∈ {em, tf, core}: pass_f(O′) ≥ pass_f(O))   # T3
```

- **T1 은 누출 감사 통과를 전제로만 유효하다.** `make leakage` 위반이 0 이 아니면 T1 판정을
  산출하지 않고 실패로 보고한다(§1-4).
- **T3 는 통계 검정이 아니라 결정론적 통과율 비교다.** 하락 시 즉시 실패.
- **자원 가시성**(§2.1 2′)을 함께 읽는다. `tgate_report.json` 의 `resource_visibility.note` 가
  `invisible` 이면 그 실행의 ΔR₁₀₀ 은 **측정된 0 이 아니라 구성상 0** 이며, 그때는 통과를
  근거로 쓰지 않는다. **직전 실행의 값은 `invisible` 이었다**(파이프라인 서명 `9745a7d932c9`).

## 6. 실행 순서 — 중간 승인 없이 끝까지 돌린다 (§2.1 2단계)


`leakage` 와 `gate` 를 주변 검증으로 빼지 않는다 — 전자는 T1 판정의 전제이고 후자의 T1·T2

## 7. 방향에 대한 사전 선언

**어느 방향이든 결과대로 적는다.** 다만 사전에 밝혀 둘 기대는 둘이다.

1. **개념 0개 한정요소 비율이 71.7 % → 66.9 % 로 내려갔다**(상류 실측). 즉 **더 많은 한정요소가
   개념을 얻는다** — 그것이 변별력의 증가인지 잡음의 증가인지는 **점수식이 비가중 Jaccard 인
   한 사전에 알 수 없다**(D-23 · D-48 의 미구분).
2. **D-48 의 하류 시뮬레이션은 `B5 +0.0105 · P0★ −0.0107 · P1 −0.0188` 이었다**(dev · 점수식
   무변경). R7 상한과 프로파일 배선이 그 형태를 바꾸는지가 이 실험의 관심이며, **같은 형태가
   재현되면 기준 ⑥ 은 실패**다.

**금지 문구.** 개선이 나와도 *"온톨로지 보강이 검색을 개선한다"* 로 쓰지 않는다(§0.8 · test 는
개봉된 표본이다). 악화가 나와도 *"온톨로지 보강은 무익하다"* 로 쓰지 않는다(§0 ⓐ).
