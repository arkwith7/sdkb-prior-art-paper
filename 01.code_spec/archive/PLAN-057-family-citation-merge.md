## 1. 목적 — 무엇을 해결하려 하는가

**이 벤치마크의 정답은 부분 정답이다.** 심사관은 거절에 필요한 만큼만 인용하므로, 상위 100건 가운데
인용되지 않은 문서가 관련 문헌인지 아닌지는 **관측된 적이 없다.** PLAN-055 는 그 미관측이 결론을
얼마나 흔드는지를 재어 **전복 문턱 n\*(LB₉₅) = 4**(확증 분할 A · `n*/U < .001`)를 얻었다. 필요는
제거되지 않았다.

**표준 해법은 전문가 판정이지만 규모가 성립하지 않는다(실측).**

| | 건수 |
|---|---:|
| 확증 분할 하나를 상위 100까지 전량 판정 | **19,800** (198질의 × 100) |
| 그중 한쪽 구성에만 있고 미판정 | 14,456 |
| 그중 정답 1~2건 질의에 속한 것(지렛대가 큰 자리) | **9,232** |

> **묻는 것 한 문장 — 사람을 부르지 않고 정답지의 결손을 줄일 수 있는가.**

**답의 착상은 하나다. 같은 발명을 다른 나라 심사관이 이미 읽었다.** 우리 정답은 KR 심사관 인용이고,
같은 DOCDB 가족의 US·EP·JP 대응 출원에는 **그쪽 심사관이 단 인용**이 따로 있다. 그것을 병합하면
정답지가 넓어진다.

### 1.1 왜 이것이 전문가 판정의 자리를 대신할 수 있는가

전문가 판정이 만족시키는 핵심 조건은 *"사람이 읽었다"* 가 아니라 **"우리 시스템과 무관하게
생성된 관련성 라벨"** 이다(PLAN-055 §2.1 외생성 논증). 타 관할 심사관 인용은 그 조건을 그대로
만족한다 — 본 연구의 어떤 시스템보다 먼저, 그와 무관하게 생성되었다.

**비용은 사람 시간이 아니라 조회다.** 배선도 이미 있다 — `collect/bq_family_ir.py` 가 DOCDB 가족
지도를 만들며, 질의 1,200 중 **1,006건(83.8 %)이 DOCDB 가족 식별자를 보유**한다(2026-08-18 실측 ·
`docdb-app` 1,006 · `fallback-self` 2 · 미매칭 192).

### 1.2 이 계획이 **하지 않는** 일 — 지위의 사전 확정

**기존 판정을 다시 쓰지 않는다.** 정답지가 바뀌면 그것은 **다른 벤치마크**다. 기존 qrel 위의
H3·H5·T1–T4 판정과 §5 의 모든 수치는 **각자의 사전등록 기록 그대로 남으며 재산출하지 않는다**
(§1-3). 병합 정답지 위의 결과는 **별도 사전등록 아래 별도의 표**로 서고, 두 정답지의 값을 한 표에
섞지 않는다.

**따라서 이 실험의 지위는 탐색적 강건성 점검이다.** 개봉된 분할 위에서 우월성을 다시 확증하는
것은 금지된다(§2.1 말미).

## 2. 무엇을 산출하는가 — 셋

### 2.1 A · 병합 가능성의 계량 (2단계에서 먼저 답할 것)

세 비율을 순서대로 센다. **앞의 것이 작으면 뒤는 볼 필요가 없다.**

| | 묻는 것 |
|---|---|
| **α** | 질의 가족에 **해외 멤버가 실재하는 비율** |
| **β** | 그 멤버에 **심사관 인용이 달린 비율** |
| **γ** | 그 인용 문헌이 **우리 후보 코퍼스 안에 있는 비율** |

**γ 가 결정적이다.** 후보 코퍼스에 없는 문서는 어떤 시스템도 회수할 수 없으므로, 정답에 넣으면
모든 시스템의 Recall 을 함께 떨어뜨릴 뿐 비교에 정보를 주지 않는다. 기존 qrel 이 같은 이유로
**고유 정답 2,321 → 노드 도달 2,211** 로 걸러진 것과 같은 규율이다(§8.4 분모 규율).

### 2.2 B · 병합 정답지의 산출과 그 성질

`qrel_family_merged` 를 **새 파일명으로** 만든다. 기존 `qrel_examiner.parquet`
(sha `10ab67f21cc1…`)는 **바이트 단위로 불변**이다.

병합 정답에 적용하는 필터는 기존 정답과 **완전히 동일**하다 — ① 시점 유효(공개일 < 질의 출원일
기준 cutoff) ② 질의 자신·동일 패밀리 배제 ③ 후보 코퍼스 도달성 ④ 금지 간선 마스킹(§1-4).
**하나라도 다르면 두 정답지가 비교 불가능해진다.**

### 2.3 C · 병합 전후의 짝지은 차이 대조

**이 실험의 답은 여기 한 줄에 있다.**

| 관측 | 뜻 |
|---|---|
| 병합 후에도 Δ 의 부호와 유의성이 유지 | 결론이 정답지 확장에 **견딘다** — 미판정 결손이 비교를 좌우하지 않았다는 **관측 증거** |
| 병합 후 Δ 가 소멸하거나 뒤집힘 | 결손이 실제로 비교를 좌우했다 — **PLAN-055 의 전복 문턱이 이론이 아니었음**이 확인된다 |

**어느 쪽이든 답이다.** 그래서 결과를 보기 전에 두 문장을 모두 고정할 수 있다.

### 3.1 왜 이것이 기존 판정을 바꿀 수 없는가 (구조적 보증)

- **기존 qrel 을 열지 않는다** — 읽기만 하고, 병합본은 **새 파일**이다.
- **run 을 다시 만들지 않는다** — 동결 run 위에서 채점만 다시 한다. 재검색·재색인·재임베딩 0건.
- **지표를 바꾸지 않는다** — family-level Recall@100 과 부트스트랩 절차가 그대로다.
- **두 정답지의 값을 한 표에 섞지 않는다**(§8.4 분모 규율의 확장).

## 5. 다음 단계에서 확인할 것 (2단계 분석 · 🛑 별도 승인)

**코드를 쓰기 전에 데이터를 먼저 본다**(§2 2단계). BigQuery 조회는 **dry-run 으로 스캔량을 먼저
보고**한다.

1. **α·β·γ** — §2.1. 특히 γ 가 낮으면 이 계획은 **여기서 종료**하고 그 사실을 결손 명세에 적는다.
2. 질의 미매칭 **192건**의 정체 — 가족 지도가 구 코퍼스(40,552행) 시점 산출물이라 신규 문서
   (B층 479건)를 담지 못한 것인지, 실제로 가족이 없는 것인지.
3. 병합 라벨과 기존 라벨의 **중복률** — 이미 아는 것을 다시 넣으면 결손이 줄지 않는다.
4. 병합이 **질의별로 고르게 분포하는지** — 소수 질의에 몰리면 그 질의들이 결과를 지배한다.
5. **시점 유효 위반 후보** — 타 관할 인용은 KR 출원보다 늦게 달릴 수 있으나, 판정 기준은
   **인용 문헌의 공개일**이다. 이 구분을 코드가 아니라 문서로 먼저 못 박는다.

### 5.1 관찰 결과 (2026-08-18 실측 · BigQuery 1회 · `src/` 무변경)

**A · 조회 규모.** 질의 1,200 중 DOCDB 가족 보유 1,006건 → 고유 가족 **965개**. 그 가족의 공보에
달린 인용 **92,962행**을 받았다(스캔 13.3 GB · $0.08). `citation.type` 은 EPO 검색보고서 범주로
오며(X 701 · Y 1,837 · A 3,548 · XY 207 …), **X·Y 가 거절 근거 범주**이므로 우리 KR 심사관 인용과
성격이 같다. **A·I 는 쓰지 않는다** — 기술 배경이지 거절 근거가 아니다.

**B · α — 해외 멤버의 실재.** 인용을 가진 가족 **641 / 965 (66.4 %)** · 그중 **비KR 멤버**가 인용을
가진 가족 **548 / 965 (56.8 %)**. 성립한다.

**C · γ — 코퍼스 도달률이 낮고, 그 원인은 대조 실패가 아니라 실제 부재다.**

| | 값 |
|---|---:|
| X/Y 비KR 인용 | 3,167행 |
| 후보 코퍼스 도달 | **537행 (17.0 %)** · 고유 문서 314 |
| 피인용 문헌의 국가 | JP 1,142 · US 1,096 · CN 456 · WO 277 · KR 107 · EP 48 |

**도달 실패는 우리 코퍼스가 한국어 중심이기 때문이다** — 후보 41,031건 중 비한국어는 1,552건뿐인데,
해외 심사관은 JP·US·CN 문헌을 인용한다. 대조 자체가 불가능한 몫도 있으나(후보의 91.5 %가 출원번호
형식 `doc_id` 라 공개번호 키를 만들 수 없다) **그 몫은 전부 한국어 문서이고, X/Y 인용 중 KR 을
가리키는 것은 107행뿐**이므로 상한이 작다. **γ 가 낮은 것은 측정의 한계가 아니라 사실이다.**

**D · 예상 못한 소득 — 독립 교차 확인.** 도달한 X/Y 인용을 (질의, 문서) 쌍으로 펴면 **408쌍**이고,
그중 **297쌍(72.8 %)이 이미 기존 qrel 에 있다.** 서로 다른 관할의 심사관이 **독립적으로 같은 선행
문헌에 도달했다**는 뜻이다. 이것은 정답지가 한 심사관의 자의가 아님을 보이는 **외생적 증거**이며,
병합의 성패와 무관하게 남는다.

**E · 실제 증분 — 확증 분할에 14쌍.**

| 단계 | 쌍 |
|---|---:|
| 도달한 X/Y 병합 후보 | 408 |
| 기존 qrel 과 중복 | −297 |
| **신규** | **111** |
| F10 마스크(시점 유효·자기 가족 배제) 통과 | **111** (전량 통과) |
| 분할 분해 | train 69 · dev 28 · **test 13 · test_b 1** |

**확증 분할의 기존 정답은 test 479 · test_b 503 이므로 증분은 +2.7 % · +0.2 % 다.**
마스크를 전량 통과한 것은 예상대로다 — 심사관 인용은 정의상 시점 선행이고 타 가족이다.

### 5.2 이 결과를 어떻게 읽는가 (§5-1 의 종료 조건 판단)

**§5-1 은 "γ 가 낮으면 여기서 종료"라고 정했다.** γ = 17.0 % 는 낮다. 그러나 **종료를 권하지
않는다** — 판단 근거는 셋이다.

1. **증분 14쌍이 무의미한 크기가 아니다.** PLAN-055 의 전복 문턱은 **n\*(LB₉₅) = 4**(test)였다.
   같은 자릿수의 실제 라벨이 들어왔으므로, Δ 가 움직이는지 여부가 **그 자체로 답**이다.
2. **남은 작업이 저렴하다.** 동결 run 위에서 **채점만 다시** 하면 된다(새 검색 0 · 재색인 0).
3. **어느 방향이든 보고할 문장이 §4.1 에 이미 고정되어 있다.**

**다만 주장의 크기는 미리 낮춘다.** 이 병합으로는 *"정답 불완전성이 결론을 좌우하지 않는다"* 를
**입증할 수 없다** — 표본이 작고 도달률이 낮기 때문이다. 얻을 수 있는 최대치는
*"이만큼의 외생 라벨을 더해도 짝지은 차이가 움직이지 않았다"* 라는 **한 조각의 관측**이다.

## 5.3 설계 — 병합 규칙의 동결 (🔒 3단계 승인 2026-08-18 · 이후 한 글자도 바꾸지 않는다)

**결과를 보기 전에 못 박는다. 아래 규칙은 §5.1 의 관찰만을 근거로 정했고 Δ 는 아직 계산하지 않았다.**

| | 규칙 | 근거 |
|---|---|---|
| **R1 · 라벨 출처** | `citation.type` 에 **X 또는 Y 가 포함된 인용만** 채택한다(`X`·`Y`·`XY`·`YX`·`XI`·`XA`·`YA`·`XYI`·`XAI`). **`A` 단독·`I` 단독은 제외** | X·Y 는 신규성·진보성 부정 근거이며 KR 심사관의 거절 인용과 성격이 같다. A 는 기술 배경이다 |
| **R2 · 가족 사상** | DOCDB `family_id` 공유로만 질의에 붙인다. `method` 가 `docdb-app`·`docdb-pub` 인 것만 쓰고 **`fallback-self` 는 제외** | 자기 자신을 가족으로 둔 문서에 타 관할 인용을 붙일 근거가 없다 |
| **R3 · 문서 대조** | `normalize_pub`(국가+앞0제거 숫자부)로 후보 코퍼스와 대조한다. **새 정규화 규칙을 만들지 않는다** | 기존 가족 지도와 같은 키를 써야 두 라벨이 같은 공간에 선다 |
| **R4 · 필터** | **`CandidateMask`(F10) 를 그대로 호출**한다 — 시점 유효 · 자기 및 동일 가족 배제. 여기에 후보 코퍼스 도달성을 더한다 | 기존 정답과 **완전히 동일한 필터**여야 두 정답지가 비교 가능하다(§2.2) |
| **R5 · 중복 처리** | 기존 qrel 과 같은 (질의, 문서) 쌍은 **더하지 않는다**. `relevance` 는 기존과 같이 **1** | 등급을 만들지 않는다 — 등급 자원은 없다 |
| **R6 · 산출 파일** | `data/processed/ir/qrel_family_merged.parquet`(**신규 파일** · 스키마 `query_id·doc_id·relevance` 동일). 기존 `qrel_examiner.parquet` 는 **읽기 전용** | §3.1 구조적 보증 |
| **R7 · 평가 대상 분할** | **test(A) 만 병합해 대조한다.** `dev` 는 참고로만 산출하고, **`test_b` 는 병합하지 않는다** | 아래 근거 |
| **R8 · 검정** | 짝지은 부트스트랩 10,000회 · **기존 시드** · 주 대조 **B3 ↔ P1**, 부차 **B3 ↔ P0★** · 지표 family Recall@100 | 기존 절차와 동일 |
| **R9 · 결정성** | 2회 실행 시 병합 qrel 과 산출 수치가 동일할 것 | — |

**R7 의 근거를 결과 보기 전에 적는다.** `test_b` 의 증분은 **1쌍**이다(§5.1 E · Δ 계산 이전에
관측된 값). ① 한 쌍은 198질의 매크로 평균을 유의미하게 움직일 수 없고 ② 병합하려면 **봉인된 B층
정답지의 파생본**을 디스크에 만들어야 하는데, 그것은 봉인 규율이 피하려던 바로 그 상태다.
**따라서 test_b 는 병합하지 않고, 증분이 1쌍이었다는 사실을 그대로 보고한다.**

**이 설계로 산출되는 것은 표 하나와 문장 둘이다.** 표 = 기존 qrel 대 병합 qrel 에서의
Δ·CI·*p* 대조. 문장 = §4.1 이 이미 고정한 두 갈래 중 하나 + 독립 교차 확인 72.8 %.

**판정은 생성하지 않는다.** 이 산출물은 어떤 가설의 지지·기각도 진술하지 않는다(§1.2).
