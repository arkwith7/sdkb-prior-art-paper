# 트랙 B — E1 · 저하 원인의 분리 (새 사전등록 · §2 정지 게이트 4개)

## B-0. 왜 이 실험인가 — 사후 설계가 아니라 등재된 검증기준의 이행

**세 가지가 동시에 성립한다.**

ⓐ **§1-12 를 정면으로 통과한다** — 검증기준(D-23 ②)이 결과보다 먼저 등재되어 있다.
ⓑ **원고가 스스로 이 실험을 명세한다**(§5.3 ②).
ⓒ **C0(상류 환류)의 완주 사례가 처음으로 생긴다** — 결함 등재 → CR 발행 → 상류 교정 → 하류
재측정. **현 논문에는 이 완주가 하나도 없고**, C0 는 이 저장소의 존재 이유다.

**어느 결과가 나와도 논문에 유리하다 — 그것이 이 실험을 고른 이유다.**

| 결과 | 논문에서의 뜻 |
|---|---|
| df 가중 하에서도 저하 **유지** | 원인은 자원 쪽 → DP1 의 근거 축이 자원에서 확정되고 C0 의 다음 요구가 명확해진다 |
| df 가중 하에서 저하 **소멸** | 원인은 소비 방식 쪽 → **층간 지표 불일치의 두 번째 사례**이며, 자원 지표도 태스크 지표도 아닌 **결합 방식**이 승인의 변수라는 더 강한 진술이 선다 |

## B-1. 설계 — 2×2 (자원 2 × 점수식 2)

| | 현행(비가중 Jaccard) | df 가중 |
|---|---|---|
| **O** (교정 전) | 0.4849 · **동결값** (`runsets/O_pre_linker`) | 신규 산출 |
| **O′** (교정 후) | 0.4556 · **동결값** (`runsets/Oprime_2839afb`) | 신규 산출 |

- 위 두 동결 칸은 **재산출하지 않고 동결 run 을 읽는다.**
- 판정량: `ΔR₁₀₀(현행) = −0.0293` 대 `ΔR₁₀₀(df)`. 질의 단위 paired bootstrap 10,000회로 각각의
  95 % 신뢰구간을 산출하고 **두 Δ의 차이**에도 신뢰구간을 붙인다.

**§4.5 는 자르지 않았다.** 부트스트랩·홀름·low-overlap 경계·재현성 결손은 심사자가 요구하는
방법론 서술이며, 여기를 깎는 것은 §2.3 이 D6 2단 규칙을 만들며 경계한 바로 그 행위다 —
*"편집 품질을 관리하는 것이 아니라 설명의 보강을 차단"*.

### A-6 — D6 임계 결정이 사용자 판단을 요한다

| | 값 | 현재(72,495) |
|---|---:|---|
| 구 권고 목표 0.61 | 69,827 | **+2,668 초과** |
| 구 차단 상한 0.63 | 72,117 | **+378 초과** |
| 현 임계 0.68 / 0.70 | 77,840 / 80,130 | 통과 |

**0.61/0.63 을 그대로 원복하면 CI 가 차단된다.** 남은 −378 을 만들려면 §4.5 방법론이나 §5.4.1
확실성 조건(§0.3 준수의 유일한 본문 근거) 같은 **논거를 깎아야 하며, 그것은 이 계획의 취지와
반대다.** 한편 EP5 가 +2,600자의 새 *결과*를 더한 것은 0.61 을 산정한 뒤의 일이다.

선택지 둘 — ⓐ **0.61 / 0.635**(권고 목표는 원래대로 두고 차단만 현 상태에 맞춤 · 상시 경고 ·
투고 전 −2,668 을 트랙 B 반영과 함께 마련) ⓑ **0.63 / 0.65**(구 차단선을 새 권고 목표로).
**ⓐ 를 권고한다** — 권고 목표를 낮추지 않으므로 규율이 유지되고, 경고 구간은 §2.3 이 정의한
"편집 중 작업 여유"의 용법 그대로다.
