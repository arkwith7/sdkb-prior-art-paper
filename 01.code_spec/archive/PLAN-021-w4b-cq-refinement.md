## 0. 왜 이 실험인가 — 그리고 무엇을 주장할 수 없는가

W4 에서 **H1 은 사전등록대로 기각**됐다(교차결함 T3 단독검출 0/18 · McNemar 방향이 가설의
반대). 원인은 교차 태스크 조건이 아니라 **CQ 의 판정 해상도**임이 T3′ 진단으로 특정됐다 —
같은 결함·같은 스위트에서 판정을 결과행 수로 바꾸면 55/108 이 검출되고 오탐은 0 이었다.

부록 F 는 **실행 전에** 이 경우의 처방을 "CQ 세분화 후 재실행"으로 예고했다. W4b 는 그 예고된
처방의 수행이다. 그러나 처방을 수행했다고 기각이 취소되지는 않는다:

| 라벨 | 지위 | 보고 방식 |
|---|---|---|
| **H1 (사전등록 · CQ 규칙 v1)** | **기각 — 확정.** 소급 변경 없음 | 표 7.1·§6.5 그대로 유지 |
| **H1′ (개정 규칙 v2)** | **사후 재설계 검정 · 탐색적.** 같은 데이터의 재판정이므로 독립 증거가 아니다 | §6.5 에 v1/v2 두 줄 · 확증은 차기 세대 델타의 몫 |

T3′ 가 이미 55/108 을 보여준 뒤에 v2 를 만들었다. 이 순서를 숨기면 p-hacking 과 구분되지
않는다 — §6.5 에 **"기대효과를 먼저 측정하고 규칙을 그에 맞춰 바꿨다"** 를 명시한다.

## 1. 동결 규칙 — CQ 판정 v2

```
pass_v2(i) = (rows_i ≥ expect_min_i)          # v1 존재검사 — 유지
           ∧ ¬regress_i
regress_i  = rows_i < (1−τ)·base_i            # monotone: up
           = rows_i > (1+τ)·base_i            # monotone: down
           = |rows_i − base_i| > τ·base_i     # monotone: flat
```

- `base_i` = 기준 세대 아티팩트(`data/cq_generations/cq_<gen>.json`)의 `per_cq[i].rows`.
- **주 τ = 0.05.** 사전 동결 민감도 격자 **τ ∈ {0, 0.05, 0.10}** 전량 보고(CLAUDE.md §1-2).
- `base_i = 0` 이면 분포 검사는 적용하지 않는다(비율 정의 불가) — 존재검사만 남는다.
  현행 대상: CQ27(FTO 준비도 · G₀ 0행 · pa 스위트).
- **T3 의 분모는 불변**이다 — {em, tf, core} · pa 5·em 6·tf 5·core 12. PLAN-019 §4.1 의 스위트
  배정 동결과 충돌하지 않는다(바뀌는 것은 배정이 아니라 판정 규칙이다).
- 규칙 버전은 세대 아티팩트에 `rule_version` 으로 기록한다 — **표 6.6 은 스위트 버전 이력을
  함께 싣는다**(부록 F 요구).

## 2. 극성 선언 (`# monotone:` · 28개 전량 · 동결)

정본은 각 `.rq` 헤더다. 요약: **`down` 2개 = CQ03(미커버 공정단계) · CQ06(최근출원 없는 개념)**,
나머지 26개 `up`. `flat` 은 문법에 있으나 현재 선언된 CQ 가 없다.

**왜 극성이 필요한가 (착수 전 실측).** CQ03·CQ06 은 `expect-min: 0` 의 **공백 탐색 질의**이고
행 수 감소가 곧 커버리지 개선이다. 극성 없이 "행수 하락 = 회귀"를 쓰면 정당한 보강이 게이트에
걸린다. 이는 T3′ 진단의 F09 검출 4/9 가 CQ03·CQ06 경유였다는 사실과 직접 맞물린다 —
**v2 에서 그 4건은 검출로 계상되지 않으며, 그만큼 v2 의 검출 수는 T3′ 보다 낮게 나올 수 있다.**
결과를 보기 전에 기록한다.

## 3. 위양성 분모 보강 — N03 정당 중복 병합

기존 분모 N01·N02 는 행 수를 사실상 건드리지 않아 τ 규칙에 대해 무자극이다. v2 의 진짜 시험대는
**행 수를 정당하게 줄이는 델타**다.

**N03 = 완전중복 개체 병합.** 같은 클래스 안에서 **IRI 를 제외한 트리플 집합이 완전히 동일한**
개체들을 하나로 합친다. 정당성이 데이터로 자동 검증되므로 병합 판단을 발명하지 않는다
(CLAUDE.md §1-6). 이는 실제 큐레이션이 하는 일이며 **어느 층도 거부해서는 안 된다.**

**착수 전 실측 — 후보 탐색과 기각한 후보.**

| 후보 | 실측 | 채택 |
|---|---|---|
| `skos:exactMatch`/`broader` 로 선언된 동의어 | G₀ 에 **0건**(술어 자체가 없다) | ✗ |
| 정규화 라벨 중복 (Skill·Material·Equipment·Process·FailureMode) | **0건** | ✗ |
| 정규화 라벨 중복 (Vendor) | 2쌍 — 그러나 **동의어가 아니다.** `raon_tech`(장비·㈜라온테크) vs `raontech_inc`(설계·㈜라온텍)는 **서로 다른 회사**이고 ASCII 정규화가 충돌시켰을 뿐이다. 병합하면 그것이 결함이다 | ✗ **기각** |
| **완전중복 개체 (Problem)** | PROB_071 ≡ PROB_074 … 트리플 집합이 IRI 만 빼고 **바이트 동일** | ✅ 채택 |

Vendor 후보를 실물 확인 없이 채택했다면 **결함을 정상 델타로 라벨해 위양성률을 조작**하는
결과가 됐다. 라벨 유사도는 동의어의 증거가 아니다 — 트리플 동일성만 자동 검증 가능한 근거다.

부수 관측(C1 자원 상태로 보고): G₀ 에 완전중복 `Problem` 개체가 실재한다 — 상류 SDKB 의
데이터 품질 항목이며 본 저장소에서 고치지 않는다(CLAUDE.md §0.1 · 결함은 상류에서).

## 4. 실행 설계 — 결함 재주입 없음

바뀌는 것은 **판정 규칙뿐**이므로 W4 의 격리 결함 그래프 126개를 **읽기만 해서** 재판정한다.

- 같은 인스턴스에 대한 **대응 비교(v1 vs v2)** 가 되어 McNemar 가 정당해진다.
- 1,908초 배치·47GB 재생성이 사라진다. 정본·격리본 모두 불변(0444 잠금 유지).
- **새로 주입하는 것은 N03 9 인스턴스뿐**(정상 델타 · 강도 3 × 반복 3).
- L0·L1·L2·누출·T1·T2 판정은 W4 인스턴스의 저장값을 **그대로 승계**한다 — v2 는 L3·T3 만
  바꾸므로 재계산이 불필요하고, 재계산하면 오히려 비교가 흐려진다.

`hasSubprocess` 를 뒤집어도 행 수가 보존되므로 T3′ 로도 v2 로도 검출되지 않는다. 처방은

## 9. 실측 결과 (2026-07-28 · `data/processed/fault_matrix_v2.json` · `make faults-rejudge`)

### 9.1 H1′ — 기각. 그러나 기각의 이유가 v1 과 다르다

| 판정 기준 | v1 (사전등록) | **v2 (τ=0.05)** |
|---|---:|---:|
| T3 검출 (결함 108) | 0/108 | **34/108** |
| L3 검출 (결함 108) | 0/108 | **34/108** |
| 미검출 결함군 | 8/12 | **5/12** (F05·F07·F09·F10·F12) |
| 교차결함 T3 검출 | 0/18 | **6/18** (F11 6/9 · F12 0/9) |
| **교차결함 T3 단독검출** | 0/18 | **0/18** ✗ |
| McNemar b/c | 19/0 · p<.0001 | **14/0 · p=0.0001** (방향 불변) |
| 위양성 (N01·N02·N03 = 27) | 0/18 | **1/27 = 3.7%** (≤5% 충족) |

v2 는 **T3 를 0 에서 34/108 로 살려냈다** — 판정 해상도가 원인이라는 T3′ 진단은 확증됐다.
그럼에도 H1′ 은 기각이다. 이유가 v1 과 다르며, 그 차이가 이번 실험의 본론이다.

### 9.2 ★ 구조적 발견 — "T3 단독검출"은 층 정의상 달성 불가능한 기준이었다

**T3 가 발화하고 L3 가 발화하지 않은 인스턴스는 τ 세 값 어디에서도 0건이다**(135 인스턴스 전량
확인). 우연이 아니라 정의의 귀결이다: L3 는 **전 스위트(pa 포함) CQ 통과 수**가 기준보다 낮은가를
보고, T3 는 그 부분집합인 {em, tf, core} 의 통과율 하락을 본다. 교차 태스크 CQ 가 하나라도
회귀하면 전체 통과 수도 함께 줄어들므로 **L3 ⊇ T3 가 구조적으로 성립**한다.

따라서 H1 의 판정식 "교차결함이 **T3 에서만** 검출된다"는 CQ 스위트를 아무리 세분화해도 충족될
수 없다. **기각된 것은 T3 의 유용성이 아니라 H1 의 판정 기준 설계다.** 이것은 v1 실측(0/108)
에서는 보이지 않았다 — T3 도 L3 도 아무것도 잡지 못해 포함 관계가 드러나지 않았기 때문이다.

**사후 규칙 변경을 하지 않는다.** L3 를 pa 스위트로 좁히면 T3 단독검출이 곧바로 나오겠지만,
그것은 결과를 본 뒤 판정층의 정의를 바꾸는 것이다(CLAUDE.md §1-2·§1-3). 차기 사전등록의 항목
으로 등재하고, 이번 원고에는 **관측과 그 함의**만 싣는다.

### 9.3 규칙 v1 → v2 가 실제로 바꾼 것

새로 검출된 결함군은 **F02·F03·F04·F06·F08·F11** 여섯이다. 특히

- **F03(논리 모순)이 9/9** — L2(HermiT)는 여전히 0 이다. TBox 에 `owl:disjointWith`·카디널리티가
  없어 검출 표면이 비어 있다는 W4 의 관측(PLAN-020 §8.2-1)은 그대로이나, **같은 결함이 CQ 분포에
  흔적을 남긴다**. 순환 주입이 공백 탐색 질의(CQ03·CQ06)의 행 수를 늘렸고, `down` 극성이 그 증가를
  회귀로 잡았다 — 극성 선언이 양방향으로 작동함을 실측이 보인다.
- **F11(동의어 오병합) 6/9 · CQ18(전문가매칭)** — T3′ 가 예고한 경로가 그대로 재현됐다.

예고대로 잃은 것도 있다. **F09(시간 누출)의 T3 검출은 0** 이다 — T3′ 에서 4/9 였던 검출은 전부
CQ03·CQ06 경유였고, 그 하락은 `down` 극성에서 **개선**이므로 회귀로 계상하지 않는다(§6-2 에서
결과를 보기 전에 예고했다). F09 는 누출 층이 9/9 로 잡으므로 게이트 전체로는 손실이 없다.

### 9.4 ★ 불리한 실측 — v2 는 정당한 중복 병합을 차단한다 (위양성)

τ=0.05 에서 **N03 이 1/9 거부됐다**(강도 5% · rep 0 · `CQ17` 재료–문제–전문가 질의). τ=0 에서는
**3/9**(강도 1%·5%·10% 각 1건 · `CQ12`·`CQ17`)로 늘어 전체 위양성률이 3/27 = **11.1%** 가 되어
사전등록 기준 5% 를 넘는다.

원인은 명확하다. 완전중복 개체를 병합하면 그 개체를 경유하던 **조합 행이 사라진다** — 중복이
만들던 허수 행이므로 정보 손실은 없지만, 행 수만 보는 판정은 그것을 회귀로 읽는다. **v2 는
"행이 줄어든 이유"를 구분하지 못한다.** 이는 분포 검사의 원리적 한계이며, 처방은 τ 를 올리는 것이
아니라(그러면 검출력이 55→34→18 로 무너진다) **중복 제거를 델타 유형으로 선언해 면제하는 것**
이다 — 차기 사전등록 항목.

### 9.5 τ 민감도 (사전 동결 격자 · 결과를 보고 고르지 않았다)

| τ | T3 검출/108 | L3 검출/108 | 위양성/27 | H1′ T3 단독/18 |
|---:|---:|---:|---:|---:|
| 0.00 | **55** | 64 | 3 (11.1%) | 0 |
| **0.05 (주값)** | **34** | 34 | 1 (3.7%) | 0 |
| 0.10 | 18 | 20 | 1 (3.7%) | 0 |

**검출력과 위양성이 정면으로 상충한다.** τ=0 은 T3′ 와 정확히 같은 55/108 을 재현하지만 위양성이
사전등록 기준을 넘고, τ=0.10 은 위양성이 낮으나 검출이 18 로 주저앉는다. 동결 주값 0.05 가
둘 사이에 있는 것은 **사전 선택의 결과이지 사후 최적화가 아니다** — 격자 3값을 전량 싣는 이유다.

### 9.6 N03 자체의 실측 (C1 자원 상태)

완전중복 개체는 G₀ 에 **13군 · 126개체**다(엄격 기준: 나가는 간선 + 들어오는 간선 동일).
`Problem` 11군 · `CitedPatent` 2군. 나가는 간선만 보면 23군으로 잡히는데 그중 10군은 **인용 주체가
달라** 실제로는 별개 개체다 — 서명에 들어오는 간선을 넣지 않았다면 별개 개체를 병합해 위양성
분모를 조작했을 것이다. 강도 1%/5%/10% 모두 `n = max(1, round(rate·13)) = 1` 이라 세 강도가
사실상 같은 크기의 델타가 된다(모수가 작은 축의 하한 규칙 · PLAN-020 §2.1).
