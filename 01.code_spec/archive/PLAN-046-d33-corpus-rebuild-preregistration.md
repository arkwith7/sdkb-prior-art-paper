## 0. 이 문서가 하는 일 한 문장

**CR-014 가 상류에 세운 공개일 200/200 을 코퍼스가 아직 읽지 않아 후보 6건이 "공개되기 전에"
후보로 서 있다(D-33 · §1-4 시점유효 위반). 그것을 재조립 1회로 닫는다.**

**여기서 열리는 것은 없다.** 봉인 `984f8ef3…`(A층 test) · `127a138f…`(B층) 는 이 계획 전체에서
닫혀 있고, H3·H4·H5 판정은 한 개도 산출하지 않는다.

## 4. 실행 (무정지 연속 · 중간 승인 없음)

```
make corpus → make split → make index → make leakage → make gate
```

- `make vendor`·`make baseline` 은 **다시 돌리지 않는다** — 이미 `212fe62` 상태다(§2.1 은
  스냅샷 서명이 바뀐 뒤의 하류 재측정을 말하고, 서명은 이미 바뀌어 커밋돼 있다).
- `make retrieve`·`make eval` 은 **돌리지 않는다.** 이 실행의 목적은 자원 상태 교정이고,
  검색 판정은 판독 B 사전등록(PLAN-040 §4 · PLAN-038 §16.6-2) 아래 **개봉 1회**로만 낸다.
  여기서 돌리면 개봉된 표본 위의 재확증이 되어 §2.1 말미 안전장치를 어긴다.
- `make figures` 도 돌리지 않는다 — 원고 그림은 구 스냅샷 관측이고 소급 수정하지 않는다(§1-3).

### 7.3 코퍼스에서 실제로 바뀐 것은 두 칸뿐이다

**전 컬럼 대조 결과 변경 컬럼은 둘**: `publication_date` **198건** · `publication_number` **200건**.
**전부 `query_layer='B'`**이고, 값→다른값 변경은 **0건**(전부 결측→값). 그중 `is_candidate=True` 인
것이 **6건** — D-33 이 겨눈 바로 그 여섯이다. 나머지 192건은 후보가 아니므로 검색에 닿지 않는다.

### 7.4 게이트

`make gate` — L0–L3 ✅ · 누출감사 ✅ · **T1 PASS**(LB₉₅ −0.0134 > −ε) · **T2 PASS**(max drop
+0.0193 < δ) · **T3 PASS** ⇒ **Accept(ΔG) = 1**.

> **이 T1 값을 판정으로 인용하지 않는다.** `mode=system` 의 P1 대 B3 비교이고 **개봉된 A층 test**
> 위에서 돌았다. 여기 실린 이유는 게이트가 완주했음을 보이기 위해서지 재확증이 아니다(§2.1 말미).
> 참고로 P1 family R@100 은 **0.4556 으로 재조립 전과 동일**했다 — 배제된 여섯은 상위 100 안에
> 들어와 있지 않았다는 뜻이다. **"영향이 없었다"로 일반화하지 않는다**(관측 1회).
