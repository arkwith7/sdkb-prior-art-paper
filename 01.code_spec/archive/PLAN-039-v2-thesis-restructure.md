# PLAN-039 — §2.2 사전 점검: v2.0 논지로의 원고 재구조화 (제목·초록·§1·§2.6·§4.9·§6.7·§7.3·§10)

> **상태: 동결 — 이 파일이 [CLAUDE.md §2.2](../../CLAUDE.md) 가 요구하는 유일한 정지 게이트다.**
> 다섯 요건을 여기 적고 커밋한 뒤 원고 편집을 시작한다. **여기 적힌 판정은 편집으로 바뀌지 않는다.**
>
> **왜 §2.2 인가.** 이 작업은 **논지 문장 · 장 구성 · 기여 문장 · 제목**을 건드린다. 문구 다듬기가
> 아니므로 §2 의 규모 예외에 해당하지 않는다.
>
> **선행:** [PLAN-037](PLAN-037-i1-promotion-precheck.md) 이 §7.5 를 신설해 I1 을 **논의 장**으로
> 올렸다. 이 계획은 그 다음 한 걸음이다 — **제목·초록·서론·결론이 아직 v0.9 의 목소리로 말하고
> 있는 것**을 v2.0 논지에 맞춘다.

## 0. 한 문장

**원고가 현재 가장 약한 주장(H5 · §7.3 스스로 "미구분"으로 내린 것)을 헤드라인으로 걸고, 가장 강한
주장(I1 · §0.2 가 "진보성의 본체"로 지정한 것)을 한계 장에 두고 있는 배치를 뒤집는다. 판정도 수치도
가설 개수도 기여 개수도 바꾸지 않는다 — 바꾸는 것은 무엇을 앞에 놓고 말하느냐다.**

> 일반화 가능"이라 부른다.

## 4. 동결 사실 점검 — 건드리지 않았다

| 항목 | 상태 |
|---|---|
| 주지표 family-level Recall@100 | **불변** |
| ε=0.02 · δ=0.05 | **불변** |
| 시점·패밀리 분할 경계 · low-overlap 정의 | **불변** |
| 가설 라벨 H1–H5 · RQ 번호(RQ5 는 신규 · 재사용 아님) | **불변** |
| 게이트 이름 L0–L3 · T1–T3 (T4 는 신규 · **승인식 미포함**) | **불변** |
| 토큰화 · Dense 모델 · 검색 설정 | **불변** |
| 봉인 qrel | **열지 않는다** |

**새 수치를 하나도 계산하지 않는다.** 코드를 실행하지 않으므로 §2 도 §2.1 도 발동하지 않는다.
표·그림 파일은 재생성하지 않는다 — 특히 `make tables` 를 돌리지 않는다(디스크 자원이 O′ 이므로
§6.2 확증 표가 갈린다).

## 5. 역방향 점검 — 규약과의 충돌 **1건, 규약을 먼저 고친다**

**충돌:** CLAUDE.md 서두 v2.0 전환 문단이 *"신설 조항 넷"* 이라고 쓰면서 **일곱 개**를 나열한다
(§0.2 · §0.3 · §0.4 · §0.5 · §1-11 · §2.2 · §5 T4). 직전 커밋 메시지는 "신설 조항 7개"였다.
→ **원고 편집 전에 규약의 "넷"을 "일곱"으로 고친다.** 원고가 규약을 앞질러 가면 다음 세션이 낡은
규약을 근거로 되돌린다(§2.2-5).

**충돌 없음을 확인한 것:**

- §0.2 N3("검색과 생성 두 층에서 함께 측정한 벤치마크")는 **미확보**다 → 원고는 N3 를 **주장하지
  않는다.** §4.9 T4 는 "설계만·미발효"로만 쓴다(CLAUDE.md §5 와 일치).
- §0.3 "확실"의 다섯 요건은 현재 **2/5** → 재작성된 초록·결론에서 **"확실"·"입증"을 쓰지 않는다.**
  허용 표현은 "조건부"·"부분 지지"·"깊은 회수에 한정"이다.
- §0.4 금지 표현 표(시간·비용 절감 · FTO 위험 감소 등)는 이번 편집에서 **새로 도입되지 않는다** —
  §7.6 결론 규칙 표가 그대로 유지된다.
- §7 산출물 대응: 신설 절 셋 중 **표·그림을 새로 만드는 것은 없다** → "수기 기입 없음" 규칙 유지.

## 6. 실행 순서 (편집 4단계 · 각 단계는 §1 판정 대장을 다시 읽고 시작한다)

1. **규약 교정** — CLAUDE.md 서두 "넷" → "일곱".
2. **참조 결함 닫기** — §4.9 T4 설계 항 신설(§7.5 의 깨진 참조가 여기서 닫힌다).
3. **증거 재배치** — §6.7 신설 + §8.1.2 축약(판정 문장은 §8.1 잔류).
4. **서사 재작성** — 제목 → 초록 → §1.1–1.5 → §2.6 1행 → §7.3 도입문 → §10.

**완료 판정:** ① §1 판정 대장의 다섯 판정이 원고에서 문자 그대로 재확인될 것 ② §6.2–6.4 의
diff 가 **0줄**일 것 ③ `T4`·`§6.7`·`§7.5` 상호 참조가 전부 실재하는 절을 가리킬 것.
