## 1. 요구정의 (CLAUDE §2-1)

**목적 — C2 방어.** 현재 주장 "온톨로지 재순위화가 최강 텍스트 기준선 대비 family R@100 +0.0534"의
유일한 실험적 취약점은 **기준선 B3의 밀집 팔(B2 = Titan v2)이 약하다**는 것이다. 실측:
B2 R@100 **0.3031** < B0(BM25) **0.4126** ([ir_performance_test.md](../../paper/tables/ir_performance_test.md)).
심사자의 예상 반론은 하나다 — *"강한 밀집 기준선을 쓰면 그 이득이 남는가?"*

**검정 대상.** B2를 더 강한 밀집 모델 B2′로 교체해 재구성한 기준선 **B3′ = B0 ⊕ B2′ (RRF)** 에 대해
P1·P0★의 이득이 유지되는지. 즉 재검정하는 것은 **H3(하이브리드 검색 유용성)의 강건성**이다.

**성공기준(검정가능).** 사전지정 주 비교 = ΔR@100(P1 − B3′)의 95% CI. 부수 = P0★ − B3′.
**비목표.** T-gate·H2·결함주입은 건드리지 않는다. 온톨로지 가중치(τ·α·w₄)를 재선택하지 않는다.
새 온톨로지 피처를 만들지 않는다. 코퍼스·qrel·분할·마스크는 불변이다.

## 2. 분석 — 착수 전 확정해야 할 사실 🛑

**관측 1 (2026-07-28 실측).** 코퍼스 언어 분포는 **ko 39,246 · en 1,189 · ja 117**이고 질의 1,000건은
전량 한국어다. 따라서 **PatentSBERTa·PaECTER는 그대로 주 기준선이 될 수 없다** — 둘 다 영문 특허
모델이고, 적용하려면 40k 문서 번역이 필요한데 이는 [PLAN-019](PLAN-019-v09-completeness-crosslingual.md)
W2에서 이미 축소·폐기 판정된 경로(T-D 1,306건으로 축소, T-Q 폐기)다.
**→ 원고 §4.5의 모델명 지목은 수정 대상이다**(수치 변경 아님 · 서술 정합).

**관측 2.** 밀집 팔 교체는 코드 경계 안에 있다 — [dense.py](../../src/sdkb_paper/retrieval/dense.py)는
`text_main`(문서)·`claims_independent`(질의)를 임베딩해 FAISS flat으로 검색하고 run만 낸다(qrel 미열람).
교체 지점은 임베딩 함수 하나이며 RRF·마스크·평가는 그대로다.

**선택지 (승인 전 결정 필요 🛑).**

| 안 | 모델 | 장점 | 비용·위험 |
|---|---|---|---|
| **A (권고)** | 한국어 가능 다국어 임베딩 (BGE-M3 / multilingual-e5-large / KURE 계열 중 1종) | 질의·문서 97%가 한국어 — 실제로 강한 기준선이 된다. 로컬 실행·재현 가능·비용 0 | 신규 의존성(`sentence-transformers`+`torch` ≈ 2–3GB) · 40k 문서 임베딩 GPU 없으면 수 시간 |
| B | Bedrock 상 다국어 임베딩 (Cohere multilingual v3 등) | 기존 Bedrock 경로·캐시 재사용 | 호출 비용 · 외부 의존 · 모델 동결성 |
| C | PaECTER/PatentSBERTa를 **영문 부분집합(en 1,189)에서만** 보조 분석 | 원고 §4.5 문구를 문자 그대로 충족 | 주 기준선이 못 됨 — 보조 각주용 |

**권고: A를 주로, C를 보조 각주로.** B는 A가 환경 제약으로 막힐 때의 대안.
모델 선정은 **개발 분할에서만** 수행하고, 선정 규칙을 §3에서 미리 고정한다.

## 3. 설계 — 결정성·검정방법 (결과를 본 뒤 바꾸지 않는다)

### 3.1 모델 선정 규칙 (개발 분할 전용 · 확증 개봉 전 동결)
- 후보 ≤ 3종을 **개발 197질의**에서만 평가하고, **R@100 최고 1종**을 B2′로 동결한다. 동점 시 파라미터
  수가 작은 쪽. 선정 후 모델·리비전 해시·정규화·풀링·최대토큰을 `[동결 시 기입]`에 적는다.
- 임베딩은 텍스트 해시 캐시로 결정적 재현(기존 dense 캐시 규약 준수). 시드 고정, 배치 순서 무관.

### 3.2 확증 분할 사용 규칙 🛑 **(이 계획의 핵심 규율)**
확증 분할은 이미 두 번 열렸다(`5e65fa5` H3–H5 · PLAN-024 T-gate 재판정). 이 계획은 **세 번째 사용**이다.
- **등록하는 비교는 정확히 2건**: ΔR@100(P1 − B3′) [주] · ΔR@100(P0★ − B3′) [부수]. 그 외 어떤
  추가 비교도 확증 분할에서 하지 않는다.
- 보조지표(nDCG@20·MRR@500·R@50/500·Success@100)는 **기술 보고만** 하고 판정에 쓰지 않는다.
- **다중성 미보정을 명시한다** — 이 결과는 H3의 **강건성 재확인**이지 새 확증이 아니라고 원고에 적는다.
- 파이프라인·가중치·임계는 B2′ 선정 이후 **일절 변경 금지**(정지 규칙 R3).

### 3.3 양방향 서술 고정 (결과를 보기 전에)

| 결과 | 원고 서술 (§5.2 · §7 내부타당도) |
|---|---|
| P1 − B3′ CI가 0을 넘김 (이득 유지) | "온톨로지 이득은 특허·다국어 특화 강한 밀집 기준선에서도 유지된다" — 원 수치와 병기 |
| CI가 0을 포함 (이득 소멸) | **H3 강건성 실패로 보고한다.** §5.2의 +0.0534를 유지하되 "약한 밀집 성분에 조건부"임을 결론·초록에 반영하고, C2 주장을 그만큼 좁힌다. 기존 수치를 삭제·재해석하지 않는다 |
| B3′ < B3 (새 모델이 더 약함) | 교체를 채택하지 않고 **선정 실패로 보고**한다. 기준선을 유리하게 고르지 않는다 |

### 3.4 정지 규칙
- **R1.** B2′ 임베딩 캐시 해시 불일치·비결정성 → 중단.
- **R2.** 누출 검사(`make leakage`) 실패 → 중단.
- **R3.** 확증 실행 후 파이프라인·임계·비교 목록 변경 금지. 재분석은 새 사전등록으로만.

## 7. 위협과 한계 (사전 자인)
1. **확증 분할 3차 사용** — 다중성 미보정. 강건성 재확인으로만 해석한다.
2. **모델 선정이 개발 분할에 적합될 위험** — 후보 ≤3, 규칙 사전 고정으로 제한하되 잔여 위험 인정.
3. **재순위화 천장 불변** — B2′는 후보 풀을 바꾸므로 P1의 상한도 함께 움직인다. 이득 변화는 "온톨로지
   기여 변화"와 "후보 풀 변화"의 합이며 이 실험은 둘을 분리하지 못한다.
4. **한국어 특화 ≠ 특허 특화** — 안 A는 도메인 특화가 아니라 언어 적합성 개선이다. 원고는 이 구분을
   명시하고, 영문 부분집합의 PaECTER 보조 분석(안 C)으로 특허 특화 축을 별도 각주 처리한다.
