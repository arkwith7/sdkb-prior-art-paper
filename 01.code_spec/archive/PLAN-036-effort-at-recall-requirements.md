## 4. 반드시 사전 동결할 것 — 우측 절단(right-censoring) 처리 규칙

**왜 이것이 요구정의 항목인가.** `K_q(R) = min{K : Recall@K(q) ≥ R}` 는 **run 깊이 안에서 R 에
도달하지 못한 질의에 대해 정의되지 않는다.** 실측상 질의당 run 깊이는 319–906 으로 가변이고 1,000
미만이므로, 절단은 예외가 아니라 **상시 발생**한다. 미정의 질의를 버리면 **어려운 질의가 사라져
쉬운 질의만 남고, 두 시스템 모두 이익이 부풀려진다.** 규칙을 코드보다 먼저 못박는다.

### 4.1 후보 규칙 (3단계에서 하나를 동결)

| | 규칙 | 성질 |
|---|---|---|
| (a) | 미도달 질의 **배제** | **채택하지 않는다** — 선택 편향. 사용자 지적 그대로. |
| (b) | 공통 상한 D 에서 **보수적 대입** `K_q := D+1` | 두 시스템에 동일 적용 · 중앙값은 절단율<50% 면 대입값에 **불변** |
| (c) | 생존분석식 보고(Kaplan–Meier 중앙값) | 통계적으로 가장 정확하나 §6 의 "탐색적 기술통계" 지위에 과하다 |

**권고: (b) + 3중 병기.** ① **공통 상한 D 를 고정**한다(전 질의 공통 · 최소 run 깊이 이하로 잡아
질의별 깊이 차이가 시스템 비교에 새는 것을 막는다 — 값은 3단계에서 관찰 후 동결). ② **주 보고량은
중앙값만** — 평균은 대입값에 좌우되므로 보고하지 않는다. ③ **절단율을 시스템별로 반드시 병기**한다.

### 4.2 Candidate Reduction 의 절단 처리 — 2×2 교차표를 반드시 싣는다

`CR_q = (K_q^{B3} − K_q^{P1}) / K_q^{B3}` 는 **둘 다 도달한 질의에서만** 정의된다. 그러나 한쪽만
도달한 질의야말로 **가장 유리하거나 가장 불리한 사례**이므로, 조용히 빠지면 안 된다.

| | P1 도달 | P1 미도달 |
|---|---|---|
| **B3 도달** | CR 계산 대상 | **P1 이 진 사례** — 건수 명시 |
| **B3 미도달** | **P1 이 이긴 사례** — 건수 명시 | 둘 다 실패 — 건수 명시 |

**중앙값은 CR 계산 대상 칸에서만 내고, 나머지 세 칸의 건수를 같은 표에 붙인다.** 이 교차표가 없으면
숫자 하나로는 절단이 보이지 않는다.

### 4.3 그 밖의 동결 항목

- **단위: family**(fold-then-cut) — 주지표와 같게. "K 건 검토"가 "K 개 서로 다른 발명 검토"를 뜻하게 된다.
- **집계: 매크로 중앙값**(질의별 값의 중앙값). 질의 난이도 편차가 커 평균은 소수 질의가 지배한다.
- **평가 대상 질의: 정답 ≥1** — 기존 `metrics.evaluate` 와 동일 분모. **분모 규율(§0) 준수 · 혼용 금지.**
- **목표 회수 격자 R · 공통 상한 D** — 2단계 관찰 후 3단계에서 동결.

5. 원고 §6.3 "운용 효율" 행이 **코드 산출 값으로 교체**되고, 수기 숫자가 0 개다.

### 9.2 미결 2 해소 — 질의당 정답이 너무 적어 **R 격자가 붕괴한다**

test 198질의 · family 정답 합 478. 질의당 **중앙값 2건**.

| \|Rel\| | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 9 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 질의 수 | 47 | 75 | 42 | 24 | 5 | 3 | 1 | 1 |

- `|Rel|=1` 인 47질의(23.7%)에서는 R=0.5 와 R=1.0 이 같은 값이다. 표에 명시한다.

### 9.3 run 깊이 — 시스템마다 다르고, 재랭크 3팔은 **완전히 같다**

| 시스템 | 문서 깊이 min/중앙/max | family 깊이 min/중앙/max |
|---|---|---|
| B0 (BM25) | 319 / 713 / 901 | 314 / 694 / 881 |
| B2 (Dense) | 210 / 737 / 912 | 208 / 717 / 902 |
| **B3 · P0★ · P1** | **319 / 729 / 906** | **313 / 708 / 894** |
| B5 (개념 단독) | **26** / 1000 / 1000 | 26 / 987 / 1000 |

- P0★·P1 은 B3 의 풀을 재정렬할 뿐이라 **깊이가 B3 와 완전히 동일**하다 — 세 시스템의 Effort 비교는
  깊이 차이가 아니라 **순서 차이만** 반영한다. Effort@Recall 이 성립하는 이상적 조건이다.
- **B5 는 깊이가 26까지 내려간다.** B5 를 같은 공통 상한에 넣으면 D=26 이 되어 표가 무의미해진다.
  → **주 비교는 재랭크 3팔(B3·P0★·P1)로 한정**하고, B0·B2·B5 는 **깊이별 회수 곡선(③)에만** 싣는다.
  곡선은 Recall@K 라서 절단 문제가 없다(풀이 마르면 평평해질 뿐이다).

### 9.4 절단은 예외가 아니라 **다수 사건**이다 — 그리고 R=1.0 에서 중앙값이 **식별되지 않는다**

목표 회수 미도달 질의 비율(재랭크 3팔):

| 공통 상한 D | R=0.5 (B3 / P0★ / P1) | R=1.0 (B3 / P0★ / P1) |
|---|---|---|
| 100 | 46.5% / 44.9% / 41.4% | 78.3% / 73.7% / 72.7% |
| 200 | 39.4% / 33.3% / 33.3% | 72.2% / 66.2% / 67.7% |
| 313 | 32.8% / 30.8% / 29.8% | 67.2% / 61.1% / 63.6% |
| **500** | **28.3% / 27.8% / 27.3%** | 61.6% / 58.1% / 59.1% |
| 상한 없음 | 26.8% / 26.8% / 26.8% | 55.1% / 55.1% / 55.1% |

**두 가지가 확정된다.**
1. **R=0.5 에서는 규칙 (b)가 성립한다** — 절단율이 어느 D 에서도 50% 미만이므로 **중앙값은 대입값에
   무관하게 식별된다.** 이것이 (b)를 쓸 수 있는 조건 그 자체다.
2. **R=1.0 에서는 (b)가 성립하지 않는다** — 절단율이 **모든 D 에서 55% 이상**이다. 절단율>50% 면
   중앙값은 대입값이 결정하므로 **숫자가 아니라 D+1 을 보고하는 꼴이 된다.** 대입 중앙값을 쓰면
   그 자체가 §1-1 에 가까운 허위 수치다. **R=1.0 의 중앙값은 보고하지 않는다.**

부수 관찰: 상한이 없으면 세 시스템의 절단율이 **동일**하다(26.8% · 55.1%) — 재랭크는 풀을 바꾸지
않으므로 무한 깊이에서 회수 집합이 같다. **Effort 이득은 전부 "같은 것을 더 얕은 곳에서 찾는다"이며,
"더 많이 찾는다"가 아니다.** 이 문장은 결과와 무관하게 참이므로 지금 적어 둔다.

공통 깊이 여유: 세 팔 공통 최소 family 깊이 = **313**. `D=500` 으로 잡으면 풀이 500 이전에 마르는
질의가 **8/198** 이며, 이 8건은 절단이 아니라 **풀 고갈**이므로 별도 계상한다.

### 10.2 산출 정의 (확정)

1. **Effort@Recall(R)** = `median_q min{K ≤ D : Recall@K(q) ≥ R}`, 미도달 시 `D+1` 대입.
   `R=first` 는 `need=1`, `R=0.5` 는 `need=⌈0.5·|Rel(q)|⌉`.
2. **Candidate Reduction** = `median_q (K_q^{B3} − K_q^{P1}) / K_q^{B3}`, **둘 다 도달한 질의만**,
   그리고 §4.2 **2×2 교차표 네 칸 건수를 같은 표에** 싣는다.
3. **깊이별 회수 곡선** — 시스템 × K∈{20,50,100,200,500} family Recall. K=100 열은 `make eval` 의
   R@100 과 **일치해야 한다**(회귀 테스트 · §5 성공기준 6).
4. **질의당 추가 발견 문헌 수** = `|Rel∩TopK(P1)| − |Rel∩TopK(B3)|` (건수 · 중앙값과 사분위).
   **절단의 영향을 받지 않는 유일한 지표**이므로 §6.3 본문 문장은 이 값을 우선 인용한다.

  ③ 절단 대입 경계(도달 K=D 와 미도달 D+1 구분) ④ 결정성(2회 실행 동일).
- **`metrics.py` 는 읽기만 하고 수정하지 않는다**(§7 비목표 5).
