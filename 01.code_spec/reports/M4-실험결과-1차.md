**핵심 서사:** 온톨로지의 검색 이득은 **"질의와 정답이 같은 기술개념을 공유할 때 끌어올리는 것"**이며
실제로 그렇게 작동한다(부분 지지). 그러나 **① 청구항 한정요소·계층경로는 기여 0**(H4 기각), **② 텍스트가
못 찾은 문서는 못 살림**(재랭크 천장·교차언어), **③ 전문가 계층까지 검색에 얽힘**(H5→결합). 이득의
본체는 ConceptOverlap 하나이며 PathSim·IPC와 공선이다. **버그가 아니라 진짜 발견**(양성대조군 통과).

## 1. 실험 조건 (동결)
- 주지표: **family-level Recall@100**(oracle-free 주모드·F10 시점·패밀리·자기 마스크).
- 질의: 거절특허 독립항(F8) · 코퍼스 ~40,000 · 정답: 심사관 인용(약한 양성).
- 분할: dev 200(정답≥1: 197) 선택용 · **test 200(정답≥1: 198) 봉인 개봉 1회**(재선택 없음).
- 텍스트 기준선 B3 = BM25(nori+SDKB사전) ⊕ Dense(Titan v2) RRF. 통계: 페어드 부트스트랩 10k·Holm.
- 선택 설정(dev 격자): **P0★** α=0.75·(w_c,w_h,w_i)=(0.5,0,0.5) · **P1** τ=0.7·(0.25,0,0.25,0.5).

## 4. 왜 이런 결과인가 — 진단 (탐색적)

### 4.1 신호 분리(양성대조군) — 파이프라인은 정상
풀 내 정답 vs 비정답 평균 점수차(>0이면 항이 정답을 높게 점수): ConceptOverlap **+0.234** · PathSim
+0.173 · IpcSim +0.132 · FeatureCoverage **+0.049**. **앞 세 항은 정답을 확실히 분리**(파이프라인 정상
작동 증명) · FeatureCoverage만 거의 분리 못 함(쌍의 **82%가 0** — 관련 선행기술도 청구항 한정요소
문구는 달라 임베딩 매칭 실패).

### 4.2 D1 밀도 vs 깊이 — PathSim 사망 원인
PathSim-only Recall@100은 개념 태깅 밀도와 함께 상승(밀도Q1 0.124→Q3 0.385)하나 전 분위 텍스트 하회.
→ 병목은 **저밀도 붕괴(개념 커버리지 부족) + 거친 경로신호** 둘 다. **계층 심화 단독으론 한계.**

### 4.3 D3 near-miss — 진짜 어려운 케이스
온톨로지 이득은 **개념이 이미 겹치는 질의(Q3/Q4)에 집중**(기존 신호 증폭), **개념 안 겹치는 near-miss
(Q1)은 B3≈P0★≈P1로 아무 항도 못 살림.** FeatureCoverage 임베딩도 PathSim 자리를 못 메운다.

### 4.4 기존 KG 연구는 검색이 좋아졌는데 왜 여기선 기여가 작은가
1. **기존 KG 이득의 상당수가 "인용 그래프" 신호** — 우리는 누출통제로 **마스킹**(그들이 이긴 무기를 제거).
2. **PaECTER·IPRally는 "학습된 dense 그래프 임베딩"** — 우리의 141개 평면 심볼릭 개념태그와 메커니즘이 다름.
3. **의미층이 얇음:** 개념 141·문서당 1.58·개념간 관계 4·계층 깊이 4 · 한정요소 매칭 82% 0(입도 과세).
4. **재랭크-only 천장:** B3가 못 찾은 문서(교차언어·near-miss)는 못 살림.
→ 온톨로지가 틀린 게 아니라, **더 엄격한 조건(누출통제·순수 심볼릭)에서 도메인 온톨로지의 검색 기여는
개념 수준에 국한된다**는 발견.

## 6. 실험이 논문에 주는 함의 (문서화 · 원고 반영은 별도 결정)

- **C2(검색 성능)는 조건부·비차별적:** 이득의 유효 신호가 개념태그+분류로 환원 → "온톨로지가 검색을
  개선한다"를 강하게 주장하기 어렵다. **"성능 보장"이 아니라 "온톨로지 계층 기여를 재는 통제된 프로브"**로
  자리매김하는 것이 정직.
- **C3(거버넌스)가 진짜 신규성:** **H5→태스크 결합 발견**이 T3(교차태스크 게이트) 필요성을 실측으로
  직접 뒷받침. 인용 관련연구 어디도 다태스크 온톨로지 결합을 실증하지 않음.
- **게이트가 "다음 보강 우선순위"를 가리킨다:** 진단(D1/D3)이 계층 심화보다 **개념 커버리지·교차언어**가
  우선임을 시사(상류 SDKB 판단 대상 · 임의 실행 금지).
- **방법론적 엄밀성이 셀링포인트:** 누출통제·사전등록·음성대조군+우발규칙·정직한 null 보고.
