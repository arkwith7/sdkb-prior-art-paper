  올린다** — R@100은 오르고 nDCG@20·MRR·bpref는 내려가는 정확한 기전이다.
- **G₁·G₂는 "세대"가 아니다 (2026-07-29 · D-12).** 셋의 T-Box가 완전히 동일해 세대 비교가 성립하지
