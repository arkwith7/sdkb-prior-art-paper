## 지금 어디에 있는가

**G₀(보강 전 그래프)를 확정하는 국면이다.** 삼성 특허는 아직 수집하지 않았다.
순서는 고정: **SDKB 정비 → 재vendor → G₀ 동결 → 삼성 수집 → H1 → H2.**
G₀ 를 동결한 뒤에는 상류 SDKB 를 건드리지 않는다 — before 가 움직이면 H1 이 재현되지 않는다.
