## 완료 — (C) N4 해소

**부호가 반대인 게 아니라 단위가 달랐다.** 매핑은 **행 수**, 병합은 **노드 수**다.

```

                  −  중복 출원번호 21행  =  12,339 노드
```

중복의 정체는 **KSIA 회원사 간 공동출원**이다(예: 오로스테크놀로지 ∥ 에프에스티, SFA ∥ 뉴파워프라즈마).
소부장은 **회사별로** 수집하므로 두 회원사가 함께 낸 특허는 양쪽 질의에 각각 잡히고 — 층별 검정에는
두 회사 실적으로 다 계상되어야 하므로 이는 옳다 — 그래프는 출원번호가 키라 **특허 하나 = 노드 하나**다.
정제 델타 21,887행 중 중복 출원번호 35건, 그중 매핑된 것이 21건.
G₁ 에 상쇄가 없던 이유도 실측했다: 삼성·SK하이닉스는 서로 공동출원하지 않아 **34,521행의 출원번호가
