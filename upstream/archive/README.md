# upstream/archive — 종료된 CR (인용 가능 · 재송부 금지)

여기 있는 CR 은 **상류 구현이 끝났고, 상류에 더 요구할 것이 없는 것**이다. 삭제하지 않는 이유는
하나다 — 대장(`DEFECT-LEDGER.md`)과 원고가 이 문서의 결정 항목을 참조하고, 재실험의 서사가
"무엇을 어떤 근거로 정했는가"를 되짚을 수 있어야 하기 때문이다.

**여기 있는 것을 상류에 다시 보내지 않는다.** `HANDOFF-QUEUE.md` §3 의 세션 프롬프트에서도
제거돼 있다.

> **"아카이브"를 "결함이 닫혔다"로 읽지 않는다(2026-08-08 명시).** 이 폴더가 뜻하는 것은
> **상류 트랙의 종료**뿐이다. 하류 소비가 남은 CR 이 여기 있을 수 있고, 그 경우 해당 항목의
> **하류 소비 행에 미결로 적는다.** 대장에서 결함이 닫혔는지는 `DEFECT-LEDGER.md` 가 정하지
> 이 폴더가 정하지 않는다.
>
> **갱신 (2026-08-08 · 9차) — 지금은 미결인 항목이 없다.** CR-012 의 검증기준 ①⑤ 는
> PLAN-045 완주로 닫혔고(아래 CR-012 항목 갱신), 마지막 후속인 D-33 도 PLAN-046 으로 닫혔다.
